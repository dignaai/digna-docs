{#- Visible breadcrumb trail. `navigation.path` is listed in mkdocs.yml, but breadcrumbs are an Insiders feature: the community package ships no partials/path.html and never references the flag, so that line renders nothing. This partial supplies the trail instead, walking the same page.parent chain that the BreadcrumbList JSON-LD in main.html already reports to search engines — so what crawlers are told and what readers see finally agree. Titles come from the nav, which mkdocs-static-i18n translates per locale, so this needs no per-language content.   1. {{ config.site_name }}
    2. {% for crumb in ns.crumbs %} {% set target = section_url(crumb) | trim %}
  2. {% if target %} {{ crumb.title }} {% else %} {{ crumb.title }} {% endif %}
    3. {% endfor %}
{% endif %}

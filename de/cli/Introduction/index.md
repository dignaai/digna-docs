## Zweck der Command Line Interface (CLI)

Die ***digna*** Command Line Interface (CLI) ist ein leistungsstarkes Werkzeug, das darauf ausgelegt ist, die Interaktionen mit der ***digna***-Plattform zu vereinfachen. Sie bietet eine textbasierte Schnittstelle, mit der Benutzer eine Vielzahl von Aufgaben effizient ausführen können, ohne auf eine grafische Benutzeroberfläche angewiesen zu sein.

### Hauptfunktionen:

- **Effizienz und Flexibilität:** Die CLI ermöglicht die schnelle Ausführung von Befehlen und steigert so die Produktivität.
- **Automatisierung:** Unterstützt Scripting zur Automatisierung wiederkehrender Aufgaben.
- **Remote-Zugriff:** Verwalten Sie ***digna***-Ressourcen von überall.
- **Konsistenz und Zuverlässigkeit:** Sorgt für zuverlässige Abläufe mit dokumentierten, versionskontrollierten Befehlen.
- **Skalierbarkeit:** Bewältigt großangelegte Operationen für Enterprise-Aufgaben.
- **Einarbeitung und Beherrschung:** Vermittelt ein tieferes Verständnis der Funktionalität von ***digna***.
- **Integration mit anderen Tools:** Nahtlose Integration mit Automatisierungstools wie Control-M, UC4, AutomateNOW!

## Installationsanleitung für Windows

Um loszulegen, befolgen Sie die nachfolgenden Schritte, um die erforderlichen Dateien zu entpacken, den *dignacli*-Ordner bereitzustellen und Ihre Verbindung zum ***digna***-Repository zu konfigurieren. Stellen Sie sicher, dass Sie Ihre Repository-Zugangsdaten und alle erforderlichen Konfigurationsdetails bereit haben, bevor Sie beginnen.

1. **Entpacken der ***digna*** CLI:**
   - Beschaffen Sie die `.zip`-Datei, die die ***digna*** CLI enthält.
   - Entpacken Sie die Datei in das gewünschte Verzeichnis.

2. **Bereitstellen des `dignacli`-Ordners:**
   - Kopieren Sie den Ordner `dignacli` an Ihren bevorzugten Installationsort (z. B. `C:\Program Files\***digna***`).

3. **Konfigurieren der `config.toml`:**
   - Prüfen Sie, ob sich `config.toml` innerhalb von `dignacli` befindet.
   - Benennen Sie bei Bedarf `config_template.toml` in `config.toml` um und konfigurieren Sie diese anhand der bereitgestellten Dokumentation.

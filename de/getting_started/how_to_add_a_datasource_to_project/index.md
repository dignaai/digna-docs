Diese Anleitung zeigt die minimalen Schritte, um eine Datasource zu Ihrem Projekt hinzuzufügen.

### Schritte

1. **Öffnen Sie Ihr Projekt**  
   Verwenden Sie die linke Navigation, klicken Sie auf **Projects** und wählen Sie das Zielprojekt aus.

2. **Datasource hinzufügen**  
   Gehen Sie zu **Datasources** und klicken Sie auf **Add Datasource**.

3. **Wählen Sie den Datasource-Typ**  
   Wählen Sie den Datenbanktyp: **Table** oder **View**.

4. **Finden Sie Ihre Datasource in der Liste**  
   Wählen Sie Ihre Datasource aus der Liste aus.

5. **Snapshot Query definieren**  
   Definieren Sie die Snapshot Query. Die Snapshot Query legt fest, wie *digna* auf einen Tag Ihrer Daten zugreift.

6. **Preview**  
   Klicken Sie auf **Preview**, um zu überprüfen, ob die Snapshot Query korrekt definiert wurde.

7. **Create datasource**  
   Wenn alles richtig konfiguriert ist, können Sie Ihre Konfiguration speichern.

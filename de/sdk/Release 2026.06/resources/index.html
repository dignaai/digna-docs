    digna Python SDK Resources 2026.06¶

    This page documents the resource clients exposed by the digna Python SDK. Each resource wraps the corresponding stable API endpoints with a consistent, pythonic interface and predictable method names.

    DignaClient exposes one resource object per API area. Each resource wraps the corresponding endpoints of the stable API with pythonic method names.

    Resource Attribute Endpoints
    ProjectsResource client.projects /v1/projects
    DataSourcesResource client.data_sources /v1/data-sources
    DataSetsResource client.data_sets /v1/data-sets
    AttributesResource client.attributes /v1/attributes
    CheckDefinitionsResource client.check_definitions /v1/check-definitions
    DbConnectionsResource client.db_connections /v1/db-connections
    InspectionRequestsResource client.inspection_requests /v1/inspection-requests
    InspectionStatusesResource client.inspection_statuses /v1/inspection-statuses/*

    digna_sdk.resources.inspection_requests.InspectionRequestsResource(client) ¶

    Resource client for /v1/inspection-requests.

    get_status(inspection_request_id) ¶

    Poll the status of a previously submitted inspection request.

    Parameters:

    Name Type Description Default
    inspection_request_id int

    Inspection request ID.

    		 required

    submit(*, project_id, data_source_ids, start_date, end_date, mode, include_all_data_sources=False, use_notification=False, monthly_mode_days=None, weekly_mode_weekdays=None, inspection_job_id=None) ¶

    Submit a new inspection request for a project's data sources.

    Parameters:

    Name Type Description Default
    project_id int

    The project the data sources belong to.

    		 required
    data_source_ids list[int]

    IDs of the data sources to inspect. Ignored when include_all_data_sources is True.

    		 required
    start_date date

    First date to inspect (inclusive).

    		 required
    end_date date

    Last date to inspect (inclusive).

    		 required
    mode StableInspectionRequestMode

    How the requested date range should be scheduled (daily, weekly, monthly).

    		 required
    include_all_data_sources bool

    Inspect every data source in the project instead of just data_source_ids.

    		 False
    use_notification bool

    Whether to send notifications for this request.

    		 False
    monthly_mode_days list[int] | None

    Days of the month to run on, when mode is MONTHLY.

    		 None
    weekly_mode_weekdays list[StableInspectionRequestWeekday] | None

    Weekdays to run on, when mode is WEEKLY.

    		 None
    inspection_job_id int | None

    Optional ID linking this request to an existing inspection job.

    		 None

    wait_until_finished(inspection_request_id, *, poll_interval=2.0, timeout=300.0) ¶

    Repeatedly call get_status until the request reaches a terminal state.

    Parameters:

    Name Type Description Default
    inspection_request_id int

    Inspection request ID, as returned by submit.

    		 required
    poll_interval float

    Seconds to sleep between status checks.

    		 2.0
    timeout float

    Maximum seconds to wait before giving up.

    		 300.0

    Raises:

    Type Description
    DignaInspectionRequestFailed

    if the request ends as FAILED, ABORTED, or CANCELLED.
    TimeoutError

    if timeout seconds elapse before a terminal state is reached.

# Подключение ИИ-агентов к digna

**digna MCP Server** позволяет ИИ-агентам работать с *digna* через
[Model Context Protocol](https://modelcontextprotocol.io) (MCP) — открытый стандарт, который
поддерживают Claude, Gemini и многие другие ИИ-инструменты. Агент, подключённый к *digna*, может
отвечать на вопросы о ваших данных, расследовать оповещения и помогать настраивать *digna*.
Что умеют агенты, описано в [digna Agentic](../platform/agentic/Introduction.md).

Эта страница описывает сторону *digna*, одинаковую для всех ИИ-клиентов. Руководства для клиентов
затем показывают, куда эти данные ввести:

- [Claude](claude_mcp_guide.md): Claude Code, Claude Desktop и пользовательские коннекторы
- [Gemini](gemini_mcp_guide.md): Antigravity и Gemini CLI

!!! info "Бета-версия"

    digna Agentic, а вместе с ним и digna MCP Server, поставляется как бета-версия в
    [Release 2026.11](../changelog/Release_202611.md).

---

## Прежде чем начать {: #before-you-start }

Вам понадобятся:

- *digna* Release 2026.11 или новее
- Лицензия, включающая **digna Agentic**. Без неё сервер MCP отклоняет каждый запрос
- Учётная запись пользователя *digna*. Агент действует с правами этого пользователя в каждом
  проекте, см. [Права доступа](../platform/agentic/how_it_works.md#permissions)
- ИИ-клиент, который подключается к удалённым серверам MCP по **streamable HTTP** и может
  отправлять заголовок `Authorization`

---

## 1. Найдите конечную точку MCP {: #1-find-the-mcp-endpoint }

Сервер MCP входит в состав бэкенда *digna*, поэтому ничего дополнительно устанавливать или
запускать не нужно. Его конечная точка — это адрес бэкенда, к которому добавлен `/mcp`:

```text
https://digna.example.com/mcp
```

Если бэкенд работает напрямую на хосте и порту, например после
`digna serve --address 0.0.0.0 --port 8082`, конечная точка — это этот адрес с `/mcp`:

```text
http://digna-host:8082/mcp
```

Если перед бэкендом стоит обратный прокси, он должен пересылать `/mcp` на бэкенд вместе с
заголовком `Authorization`.

!!! warning "Используйте HTTPS в сети"

    Каждый запрос содержит ключ API. Используйте HTTPS всегда, когда ИИ-клиент и *digna* работают
    не на одной машине.

### Откуда идёт подключение {: #where-the-connection-comes-from }

Большинство ИИ-клиентов подключаются с машины, на которой они работают: Claude Code, Claude
Desktop с локальным мостом, Antigravity и Gemini CLI. Для них *digna* достаточно быть доступной с
этой машины, например внутри корпоративной сети.

**Пользовательские коннекторы** Claude устроены иначе: к конечной точке подключается облако
Anthropic. Они работают, только если конечная точка доступна из интернета по HTTPS. Для
инсталляции *digna*, доступной лишь внутри вашей сети, используйте клиент, работающий на вашей
машине.

## 2. Создайте ключ API {: #2-create-an-api-key }

ИИ-клиент проходит аутентификацию с помощью ключа API пользователя *digna*.

1. Войдите в *digna*.
2. Откройте свой профиль пользователя в левом нижнем углу.
3. Нажмите **API Keys**, затем **Add API Key**.
4. Введите имя, поясняющее назначение ключа, например *Claude Code – Marcin*, и выберите, когда
   истекает срок его действия.
5. Скопируйте ключ. Он показывается только один раз.

Каждый запрос к серверу MCP передаёт ключ в таком заголовке:

```text
Authorization: Bearer <api key>
```

Слово `Bearer` и пробел после него являются частью значения заголовка.

## 3. Подключите свой ИИ-клиент {: #3-connect-your-ai-client }

| ИИ-клиент | Откуда подключается | Руководство |
|---|---|---|
| Claude Code | Ваша машина | [Claude](claude_mcp_guide.md#claude-code) |
| Claude Desktop с локальным мостом | Ваша машина | [Claude](claude_mcp_guide.md#claude-desktop-with-a-local-bridge) |
| Пользовательский коннектор Claude (claude.ai, Claude Desktop, Claude mobile) | Облако Anthropic | [Claude](claude_mcp_guide.md#custom-connector) |
| Antigravity CLI, IDE и приложение | Ваша машина | [Gemini](gemini_mcp_guide.md#antigravity) |
| Gemini CLI | Ваша машина | [Gemini](gemini_mcp_guide.md#gemini-cli) |

Другие клиенты MCP тоже работают, если поддерживают удалённые серверы по streamable HTTP с
собственным заголовком. Большинство из них читают конфигурацию наподобие этой. Точные имена файла
и ключей смотрите в документации своего клиента:

```json
{
  "mcpServers": {
    "digna": {
      "type": "http",
      "url": "https://digna.example.com/mcp",
      "headers": {
        "Authorization": "Bearer <api key>"
      }
    }
  }
}
```

---

## 4. Проверьте {: #4-try-it }

Спросите агента о том, на что может ответить только *digna*:

- *"Покажи список моих проектов в digna."*
- *"Какие источники данных в проекте X сегодня не зелёные?"*
- *"Объясни последнюю неудачную проверку источника данных Y."*

Если агент показывает ваши проекты, подключение работает.

## Безопасность {: #security }

- **Один ключ на каждого человека и каждый клиент.** Тогда можно отозвать отдельный ключ с помощью
  **Delete API Key**, не затрагивая никого другого.
- **Выбирайте пользователя осознанно.** Агент может делать всё, что может пользователь ключа.
  Только для исследования данных используйте пользователя с ролью читателя в проектах.
- **Не храните ключи в общих файлах.** Не коммитьте файл конфигурации, содержащий ключ. Если
  клиент это поддерживает, читайте ключ из переменной окружения.
- **Задавайте срок действия.** Создайте новый ключ до истечения срока действия старого и обновите
  клиент.
- **Проверяйте вызовы инструментов.** Не отключайте в клиенте подтверждение вызовов инструментов,
  по крайней мере для вызовов, которые изменяют конфигурацию.

## Устранение неполадок {: #troubleshooting }

### 401 Unauthorized

Ответ указывает причину:

| Сообщение | Причина |
|---|---|
| `Missing or malformed Authorization header` | Заголовок не отправлен, или значение не начинается с `Bearer ` |
| `Invalid API key` | Ключ неверен или был удалён |
| `API key expired` | Срок действия ключа истёк. Создайте новый |

### 403 Forbidden: `The license does not include the agentic (MCP) feature`

В лицензии *digna* нет записи digna Agentic, или срок действия этой записи истёк. Попросите
команду digna предоставить лицензию, включающую digna Agentic, и установите её, как описано в
руководстве по установке для вашей операционной системы.

### Каждый запрос завершается ошибкой недействительной лицензии

Истёк срок действия самой лицензии *digna*. Сервер MCP перестаёт отвечать вместе с панелью, пока
не будет установлена новая лицензия.

### Агент может читать, но не изменять конфигурацию

У пользователя, которому принадлежит ключ API, нет роли редактора в этом проекте. Используйте ключ
пользователя с ролью редактора или попросите администратора проекта изменить роль.

### Клиент вообще не может подключиться

Машина, которая подключается, не может достичь конечной точки. Откройте адрес конечной точки с этой
машины и проверьте межсетевые экраны, прокси и сертификат. Для пользовательского коннектора Claude
эта машина находится в облаке Anthropic, см. [Откуда идёт подключение](#where-the-connection-comes-from).

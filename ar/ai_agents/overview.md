# ربط وكلاء الذكاء الاصطناعي بـ digna

يتيح **digna MCP Server** لوكلاء الذكاء الاصطناعي العمل مع *digna* عبر
[Model Context Protocol](https://modelcontextprotocol.io) (MCP)، وهو معيار مفتوح يدعمه Claude وGemini والعديد
من أدوات الذكاء الاصطناعي الأخرى. يستطيع الوكيل المتصل بـ *digna* الإجابة عن أسئلة حول بياناتك، والتحقيق في
التنبيهات، والمساعدة في تهيئة *digna*. راجع [digna Agentic](../platform/agentic/Introduction.md) لمعرفة ما
يمكن للوكلاء فعله.

تغطي هذه الصفحة جانب *digna*، وهو نفسه لكل عملاء الذكاء الاصطناعي. ثم توضح أدلة العملاء أين يتم إدخاله:

- [Claude](claude_mcp_guide.md): Claude Code وClaude Desktop والموصلات المخصصة
- [Gemini](gemini_mcp_guide.md): Antigravity وGemini CLI

!!! info "إصدار تجريبي"

    يتم تقديم digna Agentic، ومعه digna MCP Server، كإصدار تجريبي (beta) في
    [Release 2026.11](../changelog/Release_202611.md).

---

## قبل أن تبدأ {: #before-you-start }

تحتاج إلى:

- *digna* Release 2026.11 أو أحدث
- ترخيص يتضمن **digna Agentic**. بدونه يرفض خادم MCP كل طلب
- حساب مستخدم في *digna*. يعمل الوكيل بصلاحيات هذا المستخدم في كل مشروع، راجع
  [Permissions](../platform/agentic/how_it_works.md#permissions)
- عميل ذكاء اصطناعي يتصل بخوادم MCP البعيدة عبر **streamable HTTP** ويمكنه إرسال الترويسة `Authorization`

## 1. العثور على نقطة نهاية MCP {: #1-find-the-mcp-endpoint }

خادم MCP جزء من الواجهة الخلفية (backend) لـ *digna*، لذلك لا يوجد شيء إضافي لتثبيته أو تشغيله. نقطة النهاية
الخاصة به هي عنوان الواجهة الخلفية متبوعًا بـ `/mcp`:

```text
https://digna.example.com/mcp
```

إذا كانت الواجهة الخلفية تعمل مباشرة على مضيف ومنفذ، على سبيل المثال بعد
`digna serve --address 0.0.0.0 --port 8082`، فإن نقطة النهاية هي ذلك العنوان مع `/mcp`:

```text
http://digna-host:8082/mcp
```

إذا كان هناك وكيل عكسي (reverse proxy) أمام الواجهة الخلفية، فيجب أن يمرر `/mcp` إلى الواجهة الخلفية مع
الترويسة `Authorization`.

!!! warning "استخدم HTTPS على الشبكة"

    يحمل كل طلب مفتاح API. استخدم HTTPS كلما لم يكن عميل الذكاء الاصطناعي و*digna* على الجهاز نفسه.

### من أين يأتي الاتصال {: #where-the-connection-comes-from }

يتصل معظم عملاء الذكاء الاصطناعي من الجهاز الذي يعملون عليه: Claude Code، وClaude Desktop مع جسر محلي،
وAntigravity، وGemini CLI. بالنسبة لهم، يكفي أن يكون *digna* قابلًا للوصول من ذلك الجهاز، على سبيل المثال داخل
شبكة شركتك.

أما **الموصلات المخصصة** في Claude فمختلفة: سحابة Anthropic هي التي تتصل بنقطة النهاية. لذلك لا تعمل إلا عندما
تكون نقطة النهاية قابلة للوصول من الإنترنت عبر HTTPS. بالنسبة لتثبيت *digna* لا يمكن الوصول إليه إلا داخل شبكتك،
استخدم عميلًا يعمل على جهازك.

## 2. إنشاء مفتاح API {: #2-create-an-api-key }

يصادق عميل الذكاء الاصطناعي باستخدام مفتاح API لمستخدم في *digna*.

1. سجّل الدخول إلى *digna*.
2. افتح ملفك الشخصي في الزاوية السفلية اليسرى.
3. انقر على **API Keys**، ثم على **Add API Key**.
4. أدخل اسمًا يوضح الغرض من المفتاح، مثل *Claude Code – Marcin*، واختر موعد انتهاء صلاحيته.
5. انسخ المفتاح. لا يُعرض إلا مرة واحدة.

يرسل كل طلب إلى خادم MCP المفتاح في هذه الترويسة:

```text
Authorization: Bearer <api key>
```

كلمة `Bearer` والمسافة التي تليها جزء من قيمة الترويسة.

## 3. ربط عميل الذكاء الاصطناعي {: #3-connect-your-ai-client }

| عميل الذكاء الاصطناعي | يتصل من | الدليل |
|---|---|---|
| Claude Code | جهازك | [Claude](claude_mcp_guide.md#claude-code) |
| Claude Desktop مع جسر محلي | جهازك | [Claude](claude_mcp_guide.md#claude-desktop-with-a-local-bridge) |
| موصل Claude المخصص (claude.ai وClaude Desktop وClaude للأجهزة المحمولة) | سحابة Anthropic | [Claude](claude_mcp_guide.md#custom-connector) |
| Antigravity CLI وIDE والتطبيق | جهازك | [Gemini](gemini_mcp_guide.md#antigravity) |
| Gemini CLI | جهازك | [Gemini](gemini_mcp_guide.md#gemini-cli) |

تعمل عملاء MCP الأخرى أيضًا إذا كانت تدعم الخوادم البعيدة عبر streamable HTTP مع ترويسة مخصصة. يقرأ معظمها
تهيئة مثل هذه. راجع توثيق العميل لديك لمعرفة الأسماء الدقيقة للملف والمفاتيح:

```json
{
  "mcpServers": {
    "digna": {
      "type": "http",
      "url": "https://digna.example.com/mcp",
      "headers": {
        "Authorization": "Bearer <api key>"
      }
    }
  }
}
```

## 4. جرّبه {: #4-try-it }

اسأل الوكيل عن شيء لا يستطيع الإجابة عنه سوى *digna*:

- *"اعرض قائمة مشاريعي في digna."*
- *"ما مصادر البيانات في المشروع X التي ليست خضراء اليوم؟"*
- *"اشرح آخر فحص فاشل لمصدر البيانات Y."*

إذا عرض الوكيل مشاريعك، فإن الاتصال يعمل.

## الأمان {: #security }

- **مفتاح واحد لكل شخص وعميل.** بذلك يمكنك إلغاء مفتاح واحد فقط، باستخدام **Delete API Key**، دون التأثير على
  أي شخص آخر.
- **اختر المستخدم بعناية.** يستطيع الوكيل فعل كل ما يستطيع مستخدم المفتاح فعله. للتحقيق في البيانات فقط، استخدم
  مستخدمًا لديه دور reader في المشاريع.
- **أبقِ المفاتيح خارج الملفات المشتركة.** لا تُودِع (commit) ملف تهيئة يحتوي على مفتاح. حيثما يدعم العميل ذلك،
  اقرأ المفتاح من متغير بيئة.
- **حدد تاريخ انتهاء صلاحية.** أنشئ مفتاحًا جديدًا قبل انتهاء صلاحية المفتاح القديم، وحدّث العميل.
- **راجع استدعاءات الأدوات.** أبقِ تأكيد العميل لاستدعاءات الأدوات مفعّلًا، على الأقل للاستدعاءات التي تغيّر
  التهيئة.

## استكشاف الأخطاء وإصلاحها {: #troubleshooting }

### 401 Unauthorized

توضح الاستجابة السبب:

| الرسالة | السبب |
|---|---|
| `Missing or malformed Authorization header` | لم تُرسل أي ترويسة، أو أن القيمة لا تبدأ بـ `Bearer ` |
| `Invalid API key` | المفتاح خاطئ، أو تم حذفه |
| `API key expired` | انتهت صلاحية المفتاح. أنشئ مفتاحًا جديدًا |

### 403 Forbidden: `The license does not include the agentic (MCP) feature`

لا يحتوي ترخيص *digna* على إدخال digna Agentic، أو أن هذا الإدخال قد انتهت صلاحيته. اطلب من فريق digna ترخيصًا
يتضمن digna Agentic، وثبّته كما يصف دليل التثبيت الخاص بنظام التشغيل لديك.

### يفشل كل طلب بخطأ ترخيص غير صالح

انتهت صلاحية ترخيص *digna* نفسه. يتوقف خادم MCP عن الاستجابة مع لوحة القيادة إلى أن يتم تثبيت ترخيص جديد.

### يستطيع الوكيل القراءة لكن لا يستطيع تغيير التهيئة

لا يملك المستخدم المرتبط بمفتاح API دور editor في ذلك المشروع. استخدم مفتاح مستخدم لديه دور editor، أو اطلب من
مسؤول المشروع تغيير الدور.

### لا يستطيع العميل الاتصال إطلاقًا

الجهاز الذي يتصل لا يستطيع الوصول إلى نقطة النهاية. افتح عنوان نقطة النهاية من ذلك الجهاز، وتحقق من جدران الحماية
والوكلاء والشهادة. بالنسبة لموصل Claude المخصص، يكون ذلك الجهاز في سحابة Anthropic، راجع
[من أين يأتي الاتصال](#where-the-connection-comes-from).

# digna Python SDK-ressurser 2026.06

Denne siden dokumenterer ressursklientene som ***digna*** Python SDK eksponerer. Hver ressurs pakker inn de tilsvarende endepunktene i det stabile API-et bak et enhetlig, pythonisk grensesnitt med forutsigbare metodenavn.

`DignaClient` eksponerer ett ressursobjekt per API-område. Hver ressurs pakker inn
de tilsvarende endepunktene i det stabile API-et med pythoniske metodenavn.

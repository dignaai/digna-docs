# 체인지로그 – 릴리스 2025.04

릴리스 2025.04와 함께 digna는 데이터 품질 및 관측 가능성 관리를 더 쉬워지게 하고, 팀들에게 더 투명하게 만들며, 전 세계 사용자들이 접근할 수 있도록 큰 도약을 합니다.  
이번 릴리스는 **강력한 신규 기능**, **워크플로 자동화 개선**, 그리고 **사용자 경험 개선**을 결합합니다.  

---

## 새로운 기능

### Inspection Hub – 새로운 지휘 센터
**Inspection Hub**는 이제 모든 검사(inspection) 작업을 관리하는 중앙 장소로 제공됩니다. 여러 모듈을 오가거나 커맨드라인 실행에만 의존하는 대신, 이제 하나의 간소화된 인터페이스에서 검사 작업을 모니터링하고 제어할 수 있습니다.  

주요 기능:  
- 온디맨드 검사: 필요한 순간에 즉시 새 작업을 시작해 최신 결과를 얻을 수 있습니다.  
- 검사 이력: 언제, 누가 어떤 검사를 실행했는지 타임라인으로 확인할 수 있습니다.  
- 상태 추적: 작업은 완료, 진행 중, 대기 중 등으로 명확히 표시됩니다.  
- 실행자 정보: 검사가 사용자, 스케줄러 또는 CLI에 의해 트리거되었는지 빠르게 확인할 수 있습니다.  
- 정리 도구: 오래되거나 불필요한 작업을 삭제하여 작업 공간을 깔끔하게 유지할 수 있습니다.  
- 상세 로그: 각 작업에 대해 소요 시간, 포함된 소스, 기준 적용 방식 등을 자세히 확인할 수 있습니다.  

Inspection Hub는 팀에 **종단 간 가시성과 제어**를 제공하여 대규모 프로젝트에서의 검사 관리를 더 쉽게 만듭니다.  

---

### 다국어 지원 – digna가 당신의 언어로 말합니다
digna는 이제 **다국어 지원** 도입으로 국제화된 팀을 위해 준비되었습니다.  

이번 릴리스에서는 사용자 설정에서 **선호 인터페이스 언어**를 직접 설정할 수 있습니다. 지원 언어는 다음과 같습니다:  
- 영어 (UK, US, CA, AU)  
- 독일어 (DE, AT, CH)  
- 폴란드어 (PL)  

이를 통해 다국적 조직에서 digna 사용이 쉬워지고, 서로 다른 지역에서 일하는 팀 간 도입이 원활해집니다. 향후 릴리스에서 더 많은 언어가 추가될 예정입니다.  

---

### 데이터 소스 가져오기 & 내보내기 – 구성 관리를 단순화
엔터프라이즈 배포에서는 환경 간 일관성이 필수입니다. 2025.04에서는 고급 사용자를 위한 커맨드라인 도구인 **dignacli**를 통해 **데이터 소스의 가져오기/내보내기(import/export)** 기능을 도입합니다.  

장점:  
- 데이터 소스 구성을 한 번 내보내고 Development, Test, Production 환경에서 재사용할 수 있습니다.  
- 수동 재구성을 제거하고 비용이 큰 오류를 방지합니다.  
- 간단한 CLI 명령(`export-ds` 및 `import-ds`)으로 자동화된 워크플로와 CI/CD 파이프라인을 지원합니다.  
- 프로젝트 간 데이터 소스 복사를 빠르게 수행하여 협업을 쉽게 만듭니다.  

이 기능은 팀이 각 환경에서 구성의 일관성을 보장하면서 자신 있게 배포할 수 있도록 합니다.

### Module Analytics (v1) – 감지에서 이해로
digna는 이상치 감지와 데이터 품질 모니터링을 위한 플랫폼으로 시작했습니다. 릴리스 2025.04에서는 **Module Analytics의 첫 버전**을 통해 한 단계 더 발전합니다.  

Module Analytics는 사용자가 문제에 단순히 반응하는 것을 넘어서 **데이터를 이해**할 수 있도록 돕습니다. 이 새로운 모듈을 통해 다음을 할 수 있습니다:  
- 데이터 세트의 장기 추세 추적  
- 변동성 감지를 통해 변동 원인 파악  
- 시간에 따른 데이터 행동을 탐색하여 더 깊은 맥락 확보  

예를 들어, digna는 자동으로 *“연초 대비 행 수가 15.8% 증가했습니다.”*와 같은 내용을 강조할 수 있습니다.  
SQL 쿼리나 수동 점검 없이 — 단지 **한눈에 파악 가능한 실행 가능한 인사이트**를 제공합니다.  

이는 digna가 반응형 모니터링에서 선제적 모니터링으로 전환하는 여정의 기초가 되며, 데이터 팀이 보다 능동적으로 대응할 수 있도록 합니다.  

---

### 대시보드 개선 – 더 매끄러운 사용자 경험
주요 기능 외에도 릴리스 2025.04에는 digna를 더 직관적이고 쾌적하게 만들기 위한 여러 **대시보드 개선**이 포함되어 있습니다:  
- 프로젝트와 검사 간 더 빠른 네비게이션  
- 검사 로그와 작업 제출을 위한 더 깔끔한 레이아웃  
- 인사이트를 더 빠르게 찾을 수 있도록 돕는 미세한 디자인 조정  

이러한 개선은 고객 피드백을 직접 반영한 것이며, digna를 **일상 사용을 위해 설계된 플랫폼**으로 만들려는 지속적인 노력을 보여줍니다.  

---

## 전반적인 개선 사항
- 대규모 데이터 세트에서의 검사 작업 성능 최적화.  
- 더 명확한 피드백을 제공하기 위한 dignacli의 오류 처리 개선.  
- 다수의 동시 작업이 있는 프로젝트의 안정성 향상.  
- 작업 로그 필터링 및 프로젝트 관리를 위한 UI 개선.  

---

## 요약
릴리스 2025.04는 **제어, 접근성, 인사이트**를 중심으로 합니다.  

- 새로운 **Inspection Hub**는 검사 작업에 대한 완전한 가시성을 제공합니다.  
- **다국어 지원**은 digna가 글로벌 팀 전반에서 사용될 수 있도록 합니다.  
- **가져오기/내보내기 기능**은 환경 간 구성 관리를 단순화합니다.  
- **Module Analytics (v1)**은 추세 및 변동성 추적을 통해 감지에서 이해로 초점을 전환합니다.  
- **대시보드 개선**은 전반적인 사용자 경험을 다듬습니다.  

이 업데이트들은 digna를 그 어느 때보다 강력하고, 사용하기 쉬우며, 국제적으로 준비된 플랫폼으로 만듭니다.

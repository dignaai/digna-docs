### 단계

1. **Open Your Project**  
   왼쪽 네비게이션에서 **Projects**를 클릭하고 대상 프로젝트를 선택합니다.

2. **Add a Datasoource**  
   **Datasources**로 이동한 다음 **Add Datasource**를 클릭합니다.

3. **Choose Datasource Type**  
   데이터소스 유형을 선택하세요: Table 또는 View.

4. **Find your Datasource on the list**  
   목록에서 원하는 Datasource를 찾습니다.

5. **Define Snapshot Query**  
   Snapshot Query를 정의합니다. Snapshot query는 *digna*가 하루치 데이터를 접근하는 방식을 정의합니다.

6. **Preview**  
   미리보기를 클릭하여 Snapshot query가 올바르게 정의되었는지 확인합니다.

7. **Create datasource**  
   모든 설정이 올바르게 구성되었다면 구성을 저장합니다.

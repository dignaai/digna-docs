### 단계

1. **프로젝트 섹션 열기**
   - 왼쪽 탐색 메뉴에서 **프로젝트**를 클릭합니다.

2. **새 프로젝트 생성**
   - **새 프로젝트** 버튼을 클릭합니다.

3. **프로젝트 세부 정보 입력**
   - **프로젝트 이름**을 입력합니다.  
   - (선택 사항) 컨텍스트를 위해 **설명**을 추가합니다.

4. **프로젝트 저장**
   - 완료하려면 **생성**을 클릭합니다.  
   - 프로젝트가 이제 **프로젝트 목록**에 표시됩니다.

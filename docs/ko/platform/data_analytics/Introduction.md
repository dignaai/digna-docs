# Data Analytics – 추세 및 안정성

## 목적
장기 추세와 데이터 안정성을 드러냅니다.

## 기술적 기능
### 파생 통계
- **추세, 변동성, 계절성**을 계산합니다.

### 지원 지표
- 레코드 수  
- 결측값  
- 최소/최대, 합계, 평균  

### 시계열 분석
- 주/월별 안정성

## 예시 사용 사례
- 3개월 롤링 기간 동안 상위 판매 제품을 식별합니다.  
- 결측값의 변동성을 감지하여 간헐적인 파이프라인 문제를 포착합니다.  
- KPI의 안정성이 높은 기간과 낮은 기간을 비교합니다.  

## 가치
기본 통계를 **비즈니스 모니터링** 및 **데이터 운영**을 위한 실행 가능한 인사이트로 전환합니다.

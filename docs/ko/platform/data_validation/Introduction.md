# Data Validation – 규칙 기반 검사

## 목적
결정론적 규칙 기반 검사를 시행합니다.

## 기술적 특징
- 지원:
  - 동등성 검사
  - 임계값 및 범위
  - 참조 목록 / 룩업 검증
- 준수를 위한 **추적성 및 감사 가능성** 제공  
- 규제 보고를 위해 규칙 실행이 기록됩니다  

## 예시 사용 사례
- 송장 금액이 회계 정책을 준수하는지 검증  
- VAT 코드와 통화 코드가 미리 정의된 참조 집합과 일치하는지 확인  
- 규제 프레임워크 하에서 위험가중자산의 임계값을 검증  

## 가치
엄격한 검증이 요구되는 **금융, 의료 및 규제 산업**에서 필수적입니다.

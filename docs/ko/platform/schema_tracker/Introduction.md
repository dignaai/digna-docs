# Data Schema Tracker – 스키마 진화 모니터링

## 목적
스키마 진화를 추적하고 알림을 제공합니다.

## 기술적 기능
- 모니터링 대상:
  - 추가되거나 제거된 컬럼
  - 데이터 타입 변경
- 의도적·비의도적 스키마 변경에 대한 알림  
- ETL 파이프라인이나 대시보드를 깨뜨릴 수 있는 **silent schema drift**를 방지  

## 사용 사례
- 다운스트림 오류를 유발할 수 있는 데이터 타입 변경(예: `INT` → `VARCHAR`) 식별  
- 스키마 불일치로 파이프라인이 실패하기 전에 데이터 엔지니어에게 알림  

## 가치
팀이 **빠르게 변화하는 데이터셋**을 통제할 수 있도록 합니다.

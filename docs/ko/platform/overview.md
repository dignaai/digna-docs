# *digna* 모듈 — 기술 개요



*digna*는 AI 기반의 **Data Quality & Observability Platform**입니다.  

데이터 환경에 직접 배포되어 맞춤형 규칙 코딩 없이도 데이터에 대한 신뢰를 보장합니다.



---



## 모듈 요약

| Module                  | Focus Area               | Key Capabilities |
|--------------------------|--------------------------|------------------|
| **Data Anomalies**      | 자동화된 이상 탐지        | ‘정상’ 동작을 학습하고, 볼륨, 분포, 값의 편차를 탐지 |
| **Data Analytics**      | 추세 및 변동성           | 장기 지표, 안정성 및 변화 패턴을 분석 |
| **Data Validation**     | 규칙 기반 검사           | 정확한 값, 임계값, 범위, 목록을 적용 — 감사 추적 포함 |
| **Data Timeliness**     | 전송 모니터링            | AI가 학습한 도착 시간 + 사용자 일정 결합, 지연된 데이터 탐지 |
| **Data Schema Tracker** | 구조 모니터링            | 스키마 드리프트 감지: 컬럼 추가/제거, 데이터 타입 변경 |

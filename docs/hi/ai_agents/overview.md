# AI एजेंटों को digna से कनेक्ट करें

**digna MCP Server** AI एजेंटों को [Model Context Protocol](https://modelcontextprotocol.io) (MCP) के
माध्यम से *digna* के साथ काम करने देता है। MCP एक खुला मानक है जिसे Claude, Gemini और कई अन्य AI टूल
समर्थन देते हैं। *digna* से कनेक्ट किया गया एजेंट आपके डेटा के बारे में प्रश्नों के उत्तर दे सकता है, अलर्ट
की जाँच कर सकता है और *digna* को कॉन्फ़िगर करने में मदद कर सकता है। एजेंट क्या-क्या कर सकते हैं, यह जानने के
लिए [digna Agentic](../platform/agentic/Introduction.md) देखें।

यह पृष्ठ *digna* पक्ष को कवर करता है, जो हर AI क्लाइंट के लिए एक जैसा है। क्लाइंट गाइड फिर दिखाती हैं कि
इसे कहाँ दर्ज करना है:

- [Claude](claude_mcp_guide.md): Claude Code, Claude Desktop और कस्टम कनेक्टर
- [Gemini](gemini_mcp_guide.md): Antigravity और Gemini CLI

!!! info "बीटा"

    digna Agentic, और उसके साथ digna MCP Server, [Release 2026.11](../changelog/Release_202611.md) में
    बीटा संस्करण के रूप में उपलब्ध कराया गया है।

## आरंभ करने से पहले {: #before-you-start }

आपको चाहिए:

- *digna* Release 2026.11 या उसके बाद का संस्करण
- ऐसा लाइसेंस जिसमें **digna Agentic** शामिल हो। इसके बिना MCP सर्वर हर अनुरोध अस्वीकार कर देता है
- एक *digna* उपयोगकर्ता खाता। एजेंट हर प्रोजेक्ट में उसी उपयोगकर्ता की अनुमतियों के साथ काम करता है, देखें
  [Permissions](../platform/agentic/how_it_works.md#permissions)
- एक AI क्लाइंट जो **streamable HTTP** पर रिमोट MCP सर्वरों से कनेक्ट होता हो और `Authorization` हेडर भेज
  सकता हो

## 1. MCP एंडपॉइंट खोजें {: #1-find-the-mcp-endpoint }

MCP सर्वर *digna* बैकएंड का हिस्सा है, इसलिए अलग से कुछ इंस्टॉल या शुरू करने की आवश्यकता नहीं है। इसका
एंडपॉइंट बैकएंड का पता है, जिसके बाद `/mcp` आता है:

```text
https://digna.example.com/mcp
```

यदि बैकएंड सीधे किसी होस्ट और पोर्ट पर चलता है, उदाहरण के लिए
`digna serve --address 0.0.0.0 --port 8082` के बाद, तो एंडपॉइंट वही पता है जिसके साथ `/mcp` जुड़ा हो:

```text
http://digna-host:8082/mcp
```

यदि बैकएंड के आगे कोई रिवर्स प्रॉक्सी है, तो उसे `/mcp` को `Authorization` हेडर के साथ बैकएंड तक फ़ॉरवर्ड
करना होगा।

!!! warning "नेटवर्क पर HTTPS का उपयोग करें"

    हर अनुरोध में एक API कुंजी होती है। जब भी AI क्लाइंट और *digna* एक ही मशीन पर न हों, HTTPS का उपयोग
    करें।

### कनेक्शन कहाँ से आता है {: #where-the-connection-comes-from }

अधिकांश AI क्लाइंट उसी मशीन से कनेक्ट होते हैं जिस पर वे चलते हैं: Claude Code, लोकल ब्रिज के साथ Claude
Desktop, Antigravity और Gemini CLI। इनके लिए *digna* का केवल उस मशीन से पहुँच योग्य होना पर्याप्त है,
उदाहरण के लिए आपकी कंपनी के नेटवर्क के भीतर।

Claude के **कस्टम कनेक्टर** अलग हैं: Anthropic का क्लाउड एंडपॉइंट से कनेक्ट होता है। वे केवल तभी काम करते
हैं जब एंडपॉइंट इंटरनेट से HTTPS पर पहुँच योग्य हो। ऐसे *digna* इंस्टॉलेशन के लिए जो केवल आपके नेटवर्क के
भीतर पहुँच योग्य है, उस क्लाइंट का उपयोग करें जो आपकी मशीन पर चलता है।

## 2. API कुंजी बनाएँ {: #2-create-an-api-key }

AI क्लाइंट किसी *digna* उपयोगकर्ता की API कुंजी से प्रमाणीकरण करता है।

1. *digna* में लॉग इन करें।
2. निचले-बाएँ कोने में अपनी उपयोगकर्ता प्रोफ़ाइल खोलें।
3. **API Keys** पर क्लिक करें, फिर **Add API Key** पर।
4. ऐसा नाम दर्ज करें जिससे पता चले कि कुंजी किस लिए है, जैसे *Claude Code – Marcin*, और चुनें कि वह कब
   समाप्त होगी।
5. कुंजी कॉपी करें। यह केवल एक बार दिखाई जाती है।

MCP सर्वर को भेजा गया हर अनुरोध कुंजी को इस हेडर में भेजता है:

```text
Authorization: Bearer <api key>
```

शब्द `Bearer` और उसके बाद का स्पेस हेडर मान का हिस्सा हैं।

## 3. अपना AI क्लाइंट कनेक्ट करें {: #3-connect-your-ai-client }

| AI क्लाइंट | कहाँ से कनेक्ट होता है | गाइड |
|---|---|---|
| Claude Code | आपकी मशीन | [Claude](claude_mcp_guide.md#claude-code) |
| लोकल ब्रिज के साथ Claude Desktop | आपकी मशीन | [Claude](claude_mcp_guide.md#claude-desktop-with-a-local-bridge) |
| Claude कस्टम कनेक्टर (claude.ai, Claude Desktop, Claude मोबाइल) | Anthropic का क्लाउड | [Claude](claude_mcp_guide.md#custom-connector) |
| Antigravity CLI, IDE और ऐप | आपकी मशीन | [Gemini](gemini_mcp_guide.md#antigravity) |
| Gemini CLI | आपकी मशीन | [Gemini](gemini_mcp_guide.md#gemini-cli) |

अन्य MCP क्लाइंट भी काम करते हैं, यदि वे कस्टम हेडर के साथ streamable HTTP पर रिमोट सर्वरों का समर्थन
करते हैं। उनमें से अधिकांश इस तरह का कॉन्फ़िगरेशन पढ़ते हैं। सटीक फ़ाइल और कुंजी नामों के लिए अपने क्लाइंट
का दस्तावेज़ देखें:

```json
{
  "mcpServers": {
    "digna": {
      "type": "http",
      "url": "https://digna.example.com/mcp",
      "headers": {
        "Authorization": "Bearer <api key>"
      }
    }
  }
}
```

## 4. इसे आज़माएँ {: #4-try-it }

एजेंट से कुछ ऐसा पूछें जिसका उत्तर केवल *digna* दे सकता है:

- *"मेरे digna प्रोजेक्ट सूचीबद्ध करो।"*
- *"प्रोजेक्ट X में आज कौन-से डेटा स्रोत हरे नहीं हैं?"*
- *"डेटा स्रोत Y की सबसे हाल की विफल जाँच समझाओ।"*

यदि एजेंट आपके प्रोजेक्ट सूचीबद्ध करता है, तो कनेक्शन काम कर रहा है।

## सुरक्षा {: #security }

- **हर व्यक्ति और क्लाइंट के लिए एक कुंजी।** तब आप किसी और को प्रभावित किए बिना **Delete API Key** से एक
  अकेली कुंजी रद्द कर सकते हैं।
- **उपयोगकर्ता सोच-समझकर चुनें।** एजेंट वह सब कुछ कर सकता है जो कुंजी का उपयोगकर्ता कर सकता है। केवल डेटा
  की जाँच के लिए, ऐसे उपयोगकर्ता का उपयोग करें जिसके पास प्रोजेक्ट्स में reader भूमिका हो।
- **कुंजियों को साझा फ़ाइलों से दूर रखें।** ऐसी कॉन्फ़िगरेशन फ़ाइल कमिट न करें जिसमें कुंजी हो। जहाँ क्लाइंट
  समर्थन करता हो, कुंजी को किसी परिवेश चर से पढ़ें।
- **समाप्ति तिथि निर्धारित करें।** पुरानी कुंजी समाप्त होने से पहले नई कुंजी बनाएँ और क्लाइंट को अपडेट करें।
- **टूल कॉल की समीक्षा करें।** टूल कॉल के लिए क्लाइंट की पुष्टि चालू रखें, कम से कम उन कॉल के लिए जो
  कॉन्फ़िगरेशन बदलती हैं।

## समस्या निवारण {: #troubleshooting }

### 401 Unauthorized

प्रतिक्रिया में कारण बताया जाता है:

| संदेश | कारण |
|---|---|
| `Missing or malformed Authorization header` | कोई हेडर नहीं भेजा गया, या मान `Bearer ` से शुरू नहीं होता |
| `Invalid API key` | कुंजी गलत है, या उसे हटा दिया गया है |
| `API key expired` | कुंजी समाप्त हो चुकी है। नई कुंजी बनाएँ |

### 403 Forbidden: `The license does not include the agentic (MCP) feature`

*digna* लाइसेंस में digna Agentic प्रविष्टि नहीं है, या वह प्रविष्टि समाप्त हो चुकी है। digna टीम से ऐसा
लाइसेंस माँगें जिसमें digna Agentic शामिल हो, और उसे अपने ऑपरेटिंग सिस्टम की इंस्टॉलेशन गाइड में बताए
अनुसार इंस्टॉल करें।

### हर अनुरोध अमान्य लाइसेंस त्रुटि के साथ विफल होता है

*digna* लाइसेंस स्वयं समाप्त हो चुका है। नया लाइसेंस इंस्टॉल होने तक MCP सर्वर डैशबोर्ड के साथ ही उत्तर
देना बंद कर देता है।

### एजेंट पढ़ सकता है लेकिन कॉन्फ़िगरेशन नहीं बदल सकता

API कुंजी के पीछे के उपयोगकर्ता के पास उस प्रोजेक्ट में editor भूमिका नहीं है। editor भूमिका वाले उपयोगकर्ता
की कुंजी का उपयोग करें, या किसी प्रोजेक्ट व्यवस्थापक से भूमिका बदलने के लिए कहें।

### क्लाइंट बिल्कुल कनेक्ट नहीं हो पाता

कनेक्ट होने वाली मशीन एंडपॉइंट तक नहीं पहुँच पाती। उस मशीन से एंडपॉइंट का पता खोलें, और फ़ायरवॉल, प्रॉक्सी
और प्रमाणपत्र जाँचें। Claude कस्टम कनेक्टर के लिए वह मशीन Anthropic के क्लाउड में है, देखें
[कनेक्शन कहाँ से आता है](#where-the-connection-comes-from)।

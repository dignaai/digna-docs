## Назначение интерфейса командной строки (CLI)

Интерфейс командной строки (CLI) ***digna*** — мощный инструмент, разработанный для упрощения взаимодействия с платформой ***digna***. Он предоставляет текстовый интерфейс, который позволяет пользователям эффективно выполнять широкий спектр задач без необходимости графического интерфейса.

### Основные возможности:

- **Эффективность и гибкость:** CLI обеспечивает быстрое выполнение команд, повышая производительность.
- **Автоматизация:** Поддерживает скрипты для автоматизации повторяющихся задач.
- **Удалённый доступ:** Управляйте ресурсами ***digna*** из любой точки.
- **Последовательность и надёжность:** Обеспечивает стабильную работу с документированными командами, находящимися под контролем версий.
- **Масштабируемость:** Справляется с операциями в крупном масштабе для корпоративных задач.
- **Обучение и освоение:** Позволяет глубже понять функциональность ***digna***.
- **Интеграция с другими инструментами:** Бесшовно интегрируется с инструментами автоматизации, такими как Control-M, UC4, AutomateNOW!

## Инструкция по установке для Windows

Чтобы начать, выполните следующие шаги по распаковке необходимых файлов, развертыванию папки *dignacli* и настройке подключения к репозиторию ***digna***. Убедитесь, что у вас есть учётные данные репозитория и все необходимые параметры конфигурации перед началом.

1. **Распаковка CLI ***digna***:**
   - Получите `.zip`-файл, содержащий CLI ***digna***.
   - Распакуйте файл в выбранную директорию.

2. **Развертывание папки `dignacli`:**
   - Скопируйте папку `dignacli` в предпочитаемое место установки (например, `C:\Program Files\***digna***`).

3. **Настройка `config.toml`:**
   - Проверьте наличие `config.toml` внутри `dignacli`.
   - При необходимости переименуйте `config_template.toml` в `config.toml` и настройте его в соответствии с предоставленной документацией.

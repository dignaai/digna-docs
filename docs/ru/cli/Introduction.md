## Назначение интерфейса командной строки (CLI)

The ***digna*** Command Line Interface (CLI) — мощный инструмент, предназначенный для упрощения взаимодействия с платформой ***digna***. Он предоставляет текстовый интерфейс, позволяющий пользователям эффективно выполнять широкий круг задач без необходимости использования графического интерфейса.

### Ключевые возможности:

- **Эффективность и гибкость:** CLI обеспечивает быстрое выполнение команд, что повышает производительность.
- **Автоматизация:** Поддерживает написание скриптов для автоматизации повторяющихся задач.
- **Удалённый доступ:** Управляйте ресурсами ***digna*** из любой точки.
- **Согласованность и надёжность:** Обеспечивает стабильную работу посредством задокументированных команд, находящихся под версионным контролем.
- **Масштабируемость:** Обрабатывает крупномасштабные операции для корпоративных задач.
- **Обучение и освоение:** Позволяет глубже понять функциональность ***digna***.
- **Интеграция с другими инструментами:** Бесшовно интегрируется с инструментами автоматизации, такими как Control-M, UC4, AutomateNOW!

## Инструкция по установке для Windows

Чтобы начать работу, выполните описанные ниже шаги для распаковки необходимых файлов, развертывания папки *dignacli* и настройки подключения к репозиторию ***digna***. Убедитесь, что у вас есть учётные данные репозитория и все требуемые данные конфигурации до начала работы.

1. **Распаковка ***digna*** CLI:**
   - Получите файл `.zip`, содержащий ***digna*** CLI.
   - Распакуйте файл в выбранный каталог.

2. **Развертывание папки `dignacli`:**
   - Скопируйте папку `dignacli` в предпочитаемое место установки (например, `C:\Program Files\***digna***`).

3. **Настройка `config.toml`:**
   - Проверьте наличие файла `config.toml` внутри `dignacli`.
   - При необходимости переименуйте `config_template.toml` в `config.toml` и настройте его в соответствии с прилагаемой документацией.

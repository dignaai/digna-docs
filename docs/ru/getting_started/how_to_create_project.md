### Шаги

1. **Откройте раздел проектов**
   - В левой навигации нажмите **Проекты**.

2. **Создайте новый проект**
   - Нажмите кнопку **Новый проект**.

3. **Введите данные проекта**
   - Укажите **Название проекта**.  
   - (Необязательно) Добавьте **Описание** для контекста.

4. **Сохраните проект**
   - Нажмите **Создать**, чтобы завершить.  
   - Проект теперь появится в вашем **Списке проектов**.

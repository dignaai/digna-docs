# Data Anomalies – Автоматическое обнаружение

## Purpose
Отслеживание аномалий без написания правил.

## Technical Features
### Metrics analyzed
- Объём записей  
- Пропущенные значения  
- Распределения и гистограммы  
- Диапазоны значений  
- Уникальность  

### Intelligent detection
- Использует **обучение на исторических данных** для динамического определения ожидаемых диапазонов  
- Помечает аномалии, когда фактические данные выходят за ожидаемые границы  

## Detection Scenarios
- **Падения/скачки объёма** → например, потеря половины дневных транзакций  
- **Перестановка столбцов** → столбцы имени и фамилии поменяны местами  
- **Неожиданные значения** → «Zurich» появляется среди австрийских городов  

## Value
Автоматизирует то, для чего обычно потребовались бы сотни ручных правил.

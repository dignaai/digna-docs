# Data Validation – Проверки на основе правил

## Цель
Обеспечить выполнение детерминированных проверок на основе правил.

## Технические возможности
- Поддерживает:
  - Проверки на равенство
  - Пороговые значения и диапазоны
  - Справочные списки / валидация по справочникам
- Обеспечивает **прослеживаемость и возможность аудита** для соблюдения требований  
- Исполнение правил логируется для регуляторной отчетности  

## Примеры использования
- Проверять, что суммы по счетам соответствуют учетной политике  
- Обеспечивать соответствие кодов НДС и кодов валют предопределённым справочным наборам  
- Валидировать пороговые значения для активов с взвешенным риском в рамках регуляторных требований  

## Ценность
Ключевое в **финансах, здравоохранении и регулируемых отраслях**, где требуется строгая проверка.

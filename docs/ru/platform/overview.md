# *digna* Модули — Технический обзор



*digna* — основанная на ИИ **платформа обеспечения качества данных и наблюдаемости**.  

Она работает непосредственно в вашей среде данных и обеспечивает доверие к вашим данным без необходимости кодирования пользовательских правил.



---



## Краткое описание модулей

| Модуль                  | Область применения      | Ключевые возможности |
|--------------------------|------------------------|----------------------|
| **Data Anomalies**      | Автоматическое обнаружение аномалий | Обучается «нормальному» поведению, выявляет отклонения в объеме, распределениях, значениях |
| **Data Analytics**      | Тренды и изменчивость  | Анализирует долгосрочные метрики, стабильность и закономерности изменений |
| **Data Validation**     | Проверки на основе правил | Применяет проверки точных значений, порогов, диапазонов, списков — с журналом аудита |
| **Data Timeliness**     | Мониторинг доставки    | Времена поступления, изученные ИИ, в сочетании с пользовательскими расписаниями; обнаруживает запоздавшие данные |
| **Data Schema Tracker** | Мониторинг структуры   | Обнаруживает дрейф схемы: новые/удаленные столбцы, изменения типов данных |

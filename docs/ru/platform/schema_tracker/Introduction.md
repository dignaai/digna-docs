# Data Schema Tracker – Мониторинг эволюции схемы

## Цель
Отслеживать и отправлять оповещения при изменении схемы.

## Технические возможности
- Отслеживает:
  - Добавленные или удалённые столбцы
  - Изменения типов данных
- Оповещает о намеренных и ненамеренных изменениях схемы  
- Предотвращает **тихий дрейф схемы**, который может привести к сбоям ETL-конвейеров или дашбордов  

## Примеры использования
- Выявление изменений типов данных (например, `INT` → `VARCHAR`), которые могут вызвать ошибки в последующих процессах  
- Оповещение дата-инженеров до того, как конвейеры упадут из-за несоответствий схемы  

## Ценность
Помогает командам контролировать **быстро меняющиеся, эволюционирующие наборы данных**.

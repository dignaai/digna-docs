# Data Analytics – Тренды и стабильность

## Цель
Выявление долгосрочных трендов и стабильности данных.

## Технические возможности
### Производные статистические показатели
- Вычисляет **тренд, волатильность, сезонность**.

### Поддерживаемые метрики
- Количество записей  
- Пропущенные значения  
- Минимумы/максимумы, суммы, средние  

### Анализ временных рядов
- Стабильность по неделям/месяцам

## Примеры использования
- Определять наиболее продаваемые товары за скользящий 3-месячный период.  
- Обнаруживать волатильность в пропущенных значениях для выявления прерывистых проблем в пайплайне.  
- Сравнивать периоды высокой и низкой стабильности KPI.  

## Ценность
Превращает базовую статистику в практические инсайты для **мониторинга бизнеса** и **операций с данными**.

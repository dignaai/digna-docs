# Changelog – Release 2026.04  

С релизом 2026.04 digna значительно расширяет свои возможности в аналитике и валидации данных.  
В этом релизе представлены расширенный анализ временных рядов, переиспользуемые компоненты валидации и централизованная стандартизация значений.

---

## Новые возможности  

### Analytics Chart – анализ временных рядов без Data Science  
- Новый **Analytics Chart** для интерактивного анализа временных рядов  
- Встроенные аналитические методы:
    - Линейная, квадратичная и кубическая регрессия  
    - Сегментная регрессия с настраиваемыми точками разрыва  
    - Методы сглаживания  
    - Квантильный анализ  
- Автоматическое определение трендов, сезонности и изменений в паттернах  
- Анализ остатков для углублённого понимания отклонений  
- Временные ряды автоматически рассчитываются для каждого набора данных  

**Влияние:** Позволяет пользователям понимать сложное поведение данных во времени без необходимости иметь экспертизу в Data Science или использовать внешние инструменты.

---

### Enumerations – центральное определение допустимых значений  
- Определяйте переиспользуемые наборы допустимых значений (например, страны, штаты, коды статусов)  
- Валидируйте значения столбцов относительно заранее заданных перечислений в **digna Data Validation**  
- Повторно используйте перечисления в разных проектах и источниках данных  
- Используйте перечисления везде через `#ENUM:MY_ENUM#`  
- Все проверки выполняются **непосредственно в исходной базе данных**  

**Влияние:** Обеспечивает согласованность и стандартизацию значений данных по всей организации.

---

### Validation Rule Templates – переиспользуемая логика качества данных  
- Определяйте переиспользуемые шаблоны правил валидации (например, проверки на пробелы, NOT NULL, проверки формата)  
- Применяйте шаблоны к нескольким наборам данных  
- Обеспечивайте единообразную логику правил в разных проектах  
- Снижайте дублирование и ручную настройку  
- Все проверки выполняются **непосредственно в исходной базе данных**  

**Влияние:** Обеспечивает масштабируемую и высокопроизводительную валидацию данных без перемещения данных.

---

### Условия релевантности на уровне статистики  
- Задавайте условия релевантности на **уровне столбца для каждой статистики**  
- Расширяет концепцию условий релевантности аномалий  
- Контролируйте, когда статистика должна считаться релевантной  
- Снижайте шум, исключая некритичные ситуации  

**Влияние:** Повышает качество сигналов, фокусируясь только на значимых отклонениях.

---

## Расширенные возможности Data Analytics & Validation  

В этом релизе digna расширяет как возможности по пониманию данных, так и стандартизацию валидации:

- Расширенная интерпретация **временных рядов** без знаний Data Science  
- Централизованное определение **допустимых значений через перечисления**  
- Переиспользуемая **логика валидации через шаблоны**  
- Тонкое управление **релевантностью статистик и оповещений**  

Вместе эти возможности позволяют организациям не только обнаруживать проблемы, но и **понимать, стандартизировать и контролировать качество данных**.

---

## Кому полезен этот релиз  

- **Инженеры данных:** переиспользуемая логика валидации и улучшённый контроль над поведением мониторинга  
- **Команды качества данных и управления (Data Governance):** стандартизированные правила и единообразная валидация данных в разных системах  
- **Команды аналитики и BI:** лучшее понимание трендов и отклонений  
- **Владельцы платформы:** повышенная вовлечённость за счёт упрощённой аналитики и масштабируемой валидации

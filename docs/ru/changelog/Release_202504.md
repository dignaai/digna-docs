# Changelog – Release 2025.04

С выпуском Release 2025.04 digna делает значительный шаг вперёд в упрощении управления качеством данных и наблюдаемостью, повышая прозрачность для команд и доступность для пользователей по всему миру.  
Этот релиз сочетает в себе **мощные новые возможности**, **улучшения автоматизации рабочих процессов** и **доработки удобства использования**.  

---

## Новые возможности

### Inspection Hub – новый центр управления
**Inspection Hub** теперь доступен как центральное место для управления всеми вашими задачами инспекции. Вместо того чтобы прыгать между разными модулями или полагаться исключительно на выполнение из командной строки, вы теперь можете контролировать и мониторить инспекции из одного упрощённого интерфейса.  

Основные возможности:  
- Инспекции по запросу: запуск новых задач мгновенно, когда нужны свежие результаты.  
- История инспекций: просматривайте временную шкалу инспекций — что запускалось, кто инициировал запуск и когда.  
- Отслеживание статуса: задания явно помечаются как завершённые, в процессе или ожидающие.  
- Информация об инициаторе: быстро определяйте, была ли инспекция вызвана пользователем, планировщиком или CLI.  
- Инструменты очистки: удаляйте устаревшие или ненужные задания, чтобы держать рабочую область в порядке.  
- Подробные логи: переходите в детали каждой задачи, чтобы увидеть время выполнения, какие источники были включены и как применялись пороги.  

Inspection Hub предоставляет командам **сквозную видимость и контроль**, упрощая управление инспекциями в крупных проектах.  

---

### Многоязычная поддержка – digna говорит на вашем языке
digna теперь готова для международных команд благодаря внедрению **многоязычной поддержки**.  

В этом релизе вы можете установить **предпочитаемый язык интерфейса** прямо в настройках пользователя. Поддерживаемые языки:  
- Английский (UK, US, CA, AU)  
- Немецкий (DE, AT, CH)  
- Польский (PL)  

Это делает digna проще в использовании для многоязычных организаций и обеспечивает более плавное внедрение в командах, работающих в разных регионах. В следующих релизах будут добавлены дополнительные языки.

### Импорт и экспорт источников данных – простая настройка конфигураций
Согласованность между окружениями критична для корпоративных развертываний. В версии 2025.04 digna вводит **импорт/экспорт источников данных** через **dignacli**, инструмент командной строки для продвинутых пользователей.  

Преимущества:  
- Экспортируйте конфигурацию источника данных один раз и повторно используйте её в Development, Test и Production.  
- Устраняйте ручную перенастройку и избегайте дорогостоящих ошибок.  
- Поддерживайте автоматизированные рабочие процессы и CI/CD с помощью простых CLI-команд (`export-ds` и `import-ds`).  
- Быстро копируйте источники данных между проектами для облегчения совместной работы.  

Эта функциональность гарантирует, что команды могут разворачивать решения с уверенностью, зная, что конфигурации согласованы в каждом окружении.  

---

### Module Analytics (v1) – от обнаружения к пониманию
digna начиналась как платформа для обнаружения аномалий и мониторинга качества данных. С релизом 2025.04 она развивается дальше с представлением **первой версии Module Analytics**.  

Module Analytics помогает пользователям **понимать свои данные**, а не только реагировать на проблемы. С этим новым модулем вы можете:  
- Отслеживать долгосрочные тренды в ваших наборах данных.  
- Обнаруживать и мониторить волатильность, чтобы понимать колебания.  
- Изучать поведение данных с течением времени для получения более глубокого контекста.  

Например, digna может автоматически подчеркнуть, что «число строк увеличилось на 15.8% с начала года».  
Никаких SQL-запросов, никаких ручных проверок — просто **полезные инсайты, видимые сразу**.  

Это основа пути digna к продвинутой аналитике данных, позволяющая командам переходить от реактивного к проактивному мониторингу.

### Улучшения панели управления – более плавный пользовательский опыт
Помимо основных функций, релиз 2025.04 включает несколько **доработок панели управления**, направленных на то, чтобы digna была более интуитивной и удобной в использовании:  
- Более быстрая навигация между проектами и инспекциями.  
- Чище отображение логов инспекций и отправки задач.  
- Ненавязчивые дизайнерские правки, помогающие быстрее находить инсайты.  

Эти улучшения основаны напрямую на отзывах клиентов и демонстрируют нашу постоянную приверженность созданию digna **платформы, рассчитанной на ежедневное использование**.

## Общие улучшения
- Оптимизация производительности для задач инспекции на больших наборах данных.  
- Улучшенная обработка ошибок в dignacli для более понятной обратной связи.  
- Повышение стабильности для проектов с большим количеством одновременных задач.  
- Доработки интерфейса для фильтрации логов задач и управления проектами.

## Резюме
Релиз 2025.04 про **контроль, доступность и понимание**.  

- Новый **Inspection Hub** даёт пользователям полную видимость задач инспекции.  
- **Многоязычная поддержка** обеспечивает использование digna командами по всему миру.  
- Функция **импорта/экспорта** упрощает управление конфигурациями между окружениями.  
- **Module Analytics (v1)** смещает фокус с обнаружения на понимание благодаря отслеживанию трендов и волатильности.  
- **Улучшения панели управления** совершенствуют общий пользовательский опыт.  

Вместе эти обновления делают digna более мощной, удобной и готовой к международному использованию, чем когда-либо прежде.

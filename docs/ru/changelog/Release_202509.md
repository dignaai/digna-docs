# Журнал изменений – Релиз 2025.09  

В релизе 2025.09 digna представляет новую **модульную архитектуру** и запускает **пять специализированных модулей** для качества данных и наблюдаемости.  
Этот релиз также усиливает аутентификацию и улучшает обработку уведомлений по всей платформе.  

---

## Новые функции  

### Модульная архитектура  
- digna теперь использует **модульную архитектуру**.  
- Клиенты могут включать только те модули, которые им нужны, и добавлять их по мере роста требований.  
- Ранее доступный функционал теперь входит в состав **digna Data Anomalies**.  

### Новые модули  
- **digna Data Anomalies** – обнаружение аномалий в объёмах данных, распределениях и пропущенных значениях на основе ИИ.  
- **digna Data Analytics** – оценка метрик наблюдаемости во временных рядах для выявления долгосрочных трендов и волатильности.  
- **digna Data Timeliness** – мониторинг ожидаемых времён поступления данных, как на основе ИИ, так и по правилам.  
- **digna Data Validation** – проверка на уровне записей по заданным правилам для обеспечения соответствия бизнес-правилам.  
- **digna Data Schema Tracker** – обнаружение изменений схемы (изменения DDL) в контролируемых базах данных.  

### MFA через OIDC  
- Поддержка **многофакторной аутентификации (MFA)** через OIDC Single Sign-On.  
- Обеспечивает корпоративный уровень безопасности для всех входов пользователей.  

### Уведомления по модулю  
- Уведомления теперь отправляются **по модулю**, что упрощает разделение оповещений от Data Anomalies, Data Analytics и других модулей.

## Обновления CLI  

- **Новая команда: `inspect-cancel`** – отмена инспекций по ID запроса или завершение всех активных запросов.  
- **Новая команда: `check-config`** – проверка конфигурационных файлов перед запуском.  
- **Новая команда: `remove-orphans`** – очистка «осиротевших» записей репозитория.  
- **Улучшенная команда `inspect`** — новая опция `--bypass-backend` (`-bb`) и стандартизированные коды возврата (`0 = OK, 1 = INFO, 2 = WARNING`).

### خطوات

1. **افتح مشروعك**  
   من التنقل الأيسر، انقر على **Projects** واختر المشروع المستهدف.

2. **Add a Datasource**  
   اذهب إلى **Datasources** وانقر **Add Datasource**.

3. **اختر نوع Datasource**  
   اختر نوع قاعدة البيانات: Table أو View.

4. **ابحث عن Datasource في القائمة**  
   اختر الـ Datasource من القائمة.

5. **حدد Snapshot Query**  
   عرّف Snapshot Query. يحدد Snapshot Query كيف سيصل *digna* إلى بيانات يوم واحد من بياناتك.

6. **معاينة**  
   انقر على preview للتحقق مما إذا تم تعريف الـ snapshot query بشكل صحيح.

7. **إنشاء datasource**  
   إذا تم تكوين كل شيء بشكل صحيح، يمكنك حفظ إعداداتك.

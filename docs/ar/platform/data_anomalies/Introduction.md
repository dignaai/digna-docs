# Data Anomalies – الكشف التلقائي

## الغرض
اكتشاف الشذوذ دون كتابة قواعد.

## الميزات التقنية
### المقاييس المحللة
- حجم السجلات  
- القيم المفقودة  
- التوزيعات والهيستوغرامات  
- نطاقات القيم  
- الفرادة  

### الكشف الذكي
- يستخدم **التعلّم التاريخي** لتحديد النطاقات المتوقعة بشكل ديناميكي  
- يحدد الشذوذ عندما تقع البيانات الفعلية خارج الحدود المتوقعة  

## سيناريوهات الكشف
- **انخفاضات/ارتفاعات الحجم** → مثال: اختفاء نصف المعاملات اليومية  
- **تبديل الأعمدة** → عكس أعمدة الاسم الأول والاسم الأخير  
- **قِيَم غير متوقعة** → ظهور “Zurich” ضمن مدن نمساوية  

## القيمة
يؤتمت ما كان سيتطلب عادة مئات القواعد اليدوية.

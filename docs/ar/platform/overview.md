# *digna* الوحدات — نظرة تقنية



*digna* هي **منصة مراقبة وجودة البيانات** مدعومة بالذكاء الاصطناعي.  

تعمل مباشرةً في بيئة بياناتك وتضمن الثقة في بياناتك دون الحاجة إلى كتابة قواعد مخصصة.



---



## ملخص الوحدات

| Module                  | Focus Area               | Key Capabilities |
|--------------------------|--------------------------|------------------|
| **Data Anomalies**      | اكتشاف الشذوذ المؤتمت     | يتعلّم السلوك «الطبيعي»، يكتشف الانحرافات في الحجم والتوزيعات والقيم |
| **Data Analytics**      | الاتجاهات والتقلبات      | يحلل المقاييس طويلة الأمد، الاستقرار، أنماط التغيير |
| **Data Validation**     | فحوصات قائمة على القواعد | يفرض القيم الدقيقة، العتبات، النطاقات والقوائم — مع سجل تدقيق |
| **Data Timeliness**     | مراقبة التسليم           | أوقات الوصول المتعلّمة بواسطة الذكاء الاصطناعي + جداول المستخدمين، يكتشف البيانات المتأخرة |
| **Data Schema Tracker** | المراقبة الهيكلية        | يكتشف انحراف المخطط: أعمدة جديدة/محذوفة، تغييرات نوع البيانات |

# Data Schema Tracker – رصد تطور المخطط

## Purpose
تتبّع وإصدار تنبيهات حول تطور المخطط.

## Technical Features
- يراقب:
  - الأعمدة المضافة أو المحذوفة
  - تغييرات نوع البيانات
- ينبه على التغييرات المقصودة وغير المقصودة في المخطط  
- يمنع **silent schema drift** الذي قد يكسر أنابيب ETL أو لوحات المعلومات  

## Example Use Cases
- تحديد تغييرات نوع البيانات (مثل `INT` → `VARCHAR`) التي قد تتسبب في أخطاء لاحقة  
- تنبيه مهندسي البيانات قبل فشل الأنابيب بسبب عدم تطابق المخطط  

## Value
يحافظ على سيطرة الفرق على **المجموعات البيانية المتغيرة بسرعة والمتطورة**.

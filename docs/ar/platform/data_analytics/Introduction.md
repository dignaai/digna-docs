# Data Analytics – الاتجاهات والاستقرار

## الهدف
كشف الاتجاهات طويلة الأمد واستقرار البيانات.

## الميزات التقنية
### إحصاءات مشتقة
- يحسب **الاتجاه، التقلب، الموسمية**.

### المقاييس المدعومة
- عدد السجلات  
- القيم المفقودة  
- الحد الأدنى/الحد الأقصى، المجاميع، المتوسطات  

### تحليل السلاسل الزمنية
- الاستقرار عبر أسابيع/أشهر

## أمثلة على حالات الاستخدام
- تحديد المنتجات الأكثر مبيعًا خلال نافذة متحركة مدتها 3 أشهر.  
- اكتشاف التقلب في القيم المفقودة لاكتشاف مشكلات خط أنابيب البيانات المتقطعة.  
- مقارنة فترات الاستقرار العالية مقابل المنخفضة في مؤشرات الأداء الرئيسية.  

## القيمة
حوّل الإحصاءات الأساسية إلى رؤى قابلة للتنفيذ لـ **مراقبة الأعمال** و**عمليات البيانات**.

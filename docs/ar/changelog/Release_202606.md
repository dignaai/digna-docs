# سجل التغييرات – الإصدار 2026.06  

مع الإصدار 2026.06، تتقدم digna خطوة كبيرة نحو الأتمتة، وقابلية التوسيع، وتحسين سهولة استخدام المنصة.  
يقدّم هذا الإصدار **digna Python SDK** الجديد، ودعم نشر رسمي عبر **Docker**، وتجربة لوحة تحكم مُجَدّدة، وقدرات محسّنة لقابلية نقل إدارة قواعد التحقق.

---

## الميزات الجديدة  

### digna Python SDK – أتمتة كل شيء باستخدام Python  
- التثبيت عبر:
  ```bash
  pip install digna-sdk
  ```
- إدارة digna وأتمتتها برمجياً باستخدام بايثون  
- إنشاء وتكوين المشاريع عبر الكود  
- تشغيل عمليات الفحص وتنفيذ المراقبة برمجياً  
- إدارة مجموعات البيانات، والقواعد، والإعدادات برمجياً  
- إجراء profiling للجداول واستخراج رؤى حول الـ metadata  
- تصدير نتائج الـ profiling وجودة البيانات إلى مستودعات وأنظمة خارجية  
- التكامل مع النوتبوكس، أدوات التنسيق (orchestration)، وأنابيب CI/CD  

**الأثر:** يتيح بنية تحتية كرمز (infrastructure-as-code) وأتمتة عميقة لتدفقات عمل جودة البيانات والمراقبة باستخدام بايثون.

### دعم Docker – تبسيط النشر والعمليات  
- صورة Docker رسمية لدigna  
- إعداد سريع ومتسق عبر البيئات  
- تسهيل عمليات البدء للمطورين، والاختبار، والإنتاج  
- تكامل سهل مع Kubernetes ومنصات الحاويات  
- تحسين قابلية النقل وقابلية إعادة الإنتاج للنشر  

**الأثر:** يجعل نشر وتشغيل digna أسهل في البُنى السحابية الحديثة المبنية على الحاويات.

---

### QueryMode – استراتيجية تنفيذ SQL مرنة

ممكن تكوين استراتيجية تنفيذ الاستعلام: وضع **Single** أو **Combined**

**Single Mode**: تُحتسب كل إحصائية بواسطة استعلام SQL مخصص واحد

  - مثالي لمصادر بيانات كبيرة حيث تكون قيود الذاكرة مهمة
  - يمنع استنزاف موارد الاستعلامات المجمعة (نفاد الذاكرة، حدود spool)
  - عدد استعلامات أعلى لكن بصمة ذاكرة أقل لكل استعلام

**Combined Mode**: تُحتسب جميع الإحصاءات داخل استعلام SQL واحد

  - يقلل عدد الاستعلامات الكلي وحمولة الشبكة
  - يُحسّن الأداء عندما تكون مصادر البيانات قابلة للإدارة في الذاكرة
  - أكثر كفاءة للتشغيل المتكرر والمتوازي

**الأثر:** يمنح المستخدمين تحكماً دقيقاً في تنفيذ الاستعلامات لموازنة الأداء، واستهلاك الموارد، وسلامة الذاكرة بناءً على خصائص مصدر البيانات.

### تجربة لوحة تحكم مُعاد تصميمها  
- واجهة مستخدم/تجربة مستخدم حديثة ومحسّنة  
- تنقل وهيكلة أوضح  
- رؤية أفضل لنتائج المراقبة ورؤى جودة البيانات  
- قابلية قراءة محسّنة للتنبيهات والإحصاءات ولوحات المعلومات  
- وصول أسرع للمعلومات التشغيلية الرئيسية  

**الأثر:** يحسّن سهولة الاستخدام والإنتاجية اليومية لجميع المستخدمين.

### توسيع الاستيراد والتصدير لقواعد التحقق  
- وظائف استيراد/تصدير محسّنة لقواعد التحقق  
- تسهيل الهجرة بين البيئات والمشاريع  
- إعادة استخدام مجموعات قواعد موحّدة بسهولة أكبر  
- حوكمة أفضل ودورة حياة محسّنة للقواعد  
- تبسيط التعاون بين الفرق  

**الأثر:** يمكّن حوكمة جودة بيانات قابلة للتوسع ومتسقة عبر المؤسسة.

# سجل التغييرات – إصدار 2025.09  

مع إصدار 2025.09، تُقدّم digna تصميمًا جديدًا **معياريًا** وتطلق **خمس وحدات متخصصة** لجودة البيانات والمراقبة.  
يعزز هذا الإصدار أيضًا المصادقة ويحسّن معالجة الإشعارات عبر المنصة.  

---

## الميزات الجديدة  

### التصميم المعياري  
- تتبع digna الآن بنية **معيارية**.  
- يمكن للعملاء تفعيل الوحدات التي يحتاجونها فقط وإضافة المزيد مع نمو المتطلبات.  
- أصبحت الوظائف السابقة الآن جزءًا من **digna Data Anomalies**.  

### الوحدات الجديدة  
- **digna Data Anomalies** – كشف قائم على الذكاء الاصطناعي للانحرافات في أحجام البيانات والتوزيعات والقيم المفقودة.  
- **digna Data Analytics** – تقييم متسلسل زمنيًا لمقاييس المراقبة لاكتشاف الاتجاهات طويلة الأمد والتقلبات.  
- **digna Data Timeliness** – مراقبة أوقات وصول البيانات المتوقعة، باستخدام طرق قائمة على الذكاء الاصطناعي وطرق قائمة على القواعد.  
- **digna Data Validation** – فحوصات على مستوى السجل تعتمد على القواعد لضمان الامتثال لقواعد العمل.  
- **digna Data Schema Tracker** – اكتشاف تغييرات المخططات (تعديلات DDL) في قواعد البيانات المراقبة.  

### المصادقة متعددة العوامل عبر OIDC  
- دعم **المصادقة متعددة العوامل (MFA)** مع تسجيل الدخول الموحد عبر OIDC.  
- يوفر أمانًا بمستوى المؤسسات لجميع تسجيلات دخول المستخدمين.  

### إشعارات عبر البريد الإلكتروني لكل وحدة  
- تُرسل الإشعارات الآن **لكل وحدة**، مما يسهل فصل التنبيهات الصادرة عن Data Anomalies وData Analytics والوحدات الأخرى.

## تحديثات سطر الأوامر (CLI)  

- **أمر جديد: `inspect-cancel`** – إلغاء عمليات الفحص حسب معرف الطلب أو إنهاء جميع الطلبات النشطة.  
- **أمر جديد: `check-config`** – التحقق من ملفات التكوين قبل بدء التشغيل.  
- **أمر جديد: `remove-orphans`** – تنظيف إدخالات المستودعات اليتيمة.  
- **تحسين أمر `inspect`** – خيار جديد `--bypass-backend` (`-bb`) ورموز إرجاع موحدة (`0 = OK, 1 = INFO, 2 = WARNING`).

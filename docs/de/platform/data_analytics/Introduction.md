# Data Analytics – Trends und Stabilität

## Zweck
Langfristige Trends und die Stabilität von Daten aufdecken.

## Technische Merkmale
### Abgeleitete Statistiken
- Berechnet **Trend, Volatilität, Saisonalität**.

### Unterstützte Metriken
- Anzahl der Datensätze  
- Fehlende Werte  
- Min/Max, Summen, Durchschnitte  

### Zeitreihenanalyse
- Stabilität über Wochen/Monate

## Beispielanwendungsfälle
- Meistverkaufte Produkte über einen rollierenden 3‑Monats-Zeitraum identifizieren.  
- Volatilität bei fehlenden Werten erkennen, um intermittierende Pipeline-Probleme zu erfassen.  
- Perioden hoher vs. niedriger Stabilität bei KPIs vergleichen.  

## Wert
Verwandelt grundlegende Statistiken in umsetzbare Erkenntnisse für **business monitoring** und **data operations**.

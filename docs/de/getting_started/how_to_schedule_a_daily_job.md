# So planen Sie einen täglichen Job

Mit der Planung können Sie Inspektionen automatisch ausführen lassen, ohne manuelles Eingreifen.  
In dieser Anleitung lernen Sie, wie Sie einen Job erstellen, der **einmal pro Tag** ausgeführt wird und so sicherstellt, dass Ihre Daten kontinuierlich überwacht werden.

---

## Warum tägliche Jobs nützlich sind

Die tägliche Planung ist die gängigste Konfiguration in Produktionsumgebungen. Sie stellt sicher:  

- **Aktualität** — die Daten des Tages werden täglich validiert.  
- **Konsistenz** — Anomalien werden früh erkannt, bevor sie sich nachgelagert auswirken.  
- **Automatisierung** — es ist nicht erforderlich, Inspektionen manuell zu starten.

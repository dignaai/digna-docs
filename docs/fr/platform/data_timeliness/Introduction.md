# Data Timeliness – Surveillance des livraisons dans les délais

## Purpose
S'assurer que les données arrivent au moment prévu.

## Technical Features
- Apprend automatiquement les **modèles d'arrivée** grâce à l'IA  
- Permet des **plannings définis par l'utilisateur** lorsque les horaires de livraison sont fixes  

## Example Use Cases
- Alerter les équipes opérationnelles lorsque les données de marché arrivent en retard, pour éviter des retards en aval  
- Surveiller le respect des SLA pour les livraisons de données entre les départements  

## Value
Protège les processus métier contre les retards silencieux et les données manquantes.

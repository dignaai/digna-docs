# Data Anomalies – Détection automatisée

## Objectif
Détecter les anomalies sans écrire de règles.

## Fonctionnalités techniques
### Métriques analysées
- Nombre d'enregistrements  
- Valeurs manquantes  
- Distributions & histogrammes  
- Plages de valeurs  
- Unicité  

### Détection intelligente
- Utilise **l'apprentissage à partir de l'historique** pour définir dynamiquement des plages attendues  
- Signale les anomalies lorsque les données réelles se situent en dehors des limites attendues  

## Scénarios de détection
- **Baisses/hausses de volume** → p. ex., manque la moitié des transactions quotidiennes  
- **Échanges de colonnes** → colonnes prénom et nom inversées  
- **Valeurs inattendues** → « Zurich » apparaissant parmi des villes autrichiennes  

## Valeur
Automatise ce qui nécessiterait normalement des centaines de règles manuelles.

### Étapes

1. **Ouvrir votre projet**  
   Dans la navigation de gauche, cliquez sur **Projets** et sélectionnez le projet cible.

2. **Ajouter une connexion**  
   Allez dans **Connexions** et cliquez sur **Ajouter une connexion**.

3. **Choisir le type de base de données**  
   Sélectionnez la base de données que vous souhaitez connecter (par ex., PostgreSQL, MySQL, SQL Server, Oracle, Snowflake, Teradata).

4. **Saisir les informations de connexion**  
   Fournissez **Nom**, **Hôte**, **Port**, **Base de données/Service**, et **Identifiants** (nom d'utilisateur/mot de passe ou SSO, selon le cas).

5. **Tester et enregistrer**  
   Cliquez sur **Tester**. Si la connexion est réussie, cliquez sur **Enregistrer**. La connexion apparaîtra sous **Connexions** pour le projet.

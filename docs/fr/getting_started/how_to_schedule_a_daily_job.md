# Comment planifier une tâche quotidienne

La planification vous permet d'exécuter des inspections automatiquement sans intervention manuelle.  
Dans ce guide, vous apprendrez à créer un job qui s'exécute **une fois par jour**, garantissant une surveillance continue de vos données.

---

## Pourquoi les tâches quotidiennes sont utiles

La planification quotidienne est la configuration la plus courante en production. Elle garantit :  

- **Fraîcheur** — les données de chaque jour sont validées.  
- **Cohérence** — les anomalies sont détectées tôt avant de se propager en aval.  
- **Automatisation** — plus besoin de déclencher manuellement les inspections.

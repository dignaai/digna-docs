### Étapes

1. **Ouvrez votre projet**  
   Dans la navigation de gauche, cliquez **Projects** et sélectionnez le projet cible.

2. **Ajouter une Datasource**  
   Allez dans **Datasources** et cliquez sur **Add Datasource**.

3. **Choisir le type de Datasource**  
   Sélectionnez le Type de base de données : Table ou View.

4. **Trouvez votre Datasource dans la liste**  
   Sélectionnez votre Datasource dans la liste.

5. **Définir la Snapshot Query**  
   Définissez la Snapshot Query. La Snapshot Query définit comment *digna* accédera à une journée de vos données.

6. **Aperçu**  
   Cliquez sur **Preview** pour vérifier si la Snapshot Query a été définie correctement.

7. **Créer la datasource**  
   Si tout a été configuré correctement, vous pouvez enregistrer votre configuration.

# *digna* モジュール — 技術概要



*digna* は AI 搭載の **Data Quality & Observability Platform** です。  

カスタムルールのコーディングを必要とせず、データ環境内で直接動作してデータの信頼性を確保します。



---



## モジュール概要

| Module                  | フォーカス領域           | 主な機能 |
|--------------------------|--------------------------|------------------|
| **Data Anomalies**      | 自動異常検知             | 「正常」挙動を学習し、ボリューム、分布、値の逸脱を検出 |
| **Data Analytics**      | トレンドと変動性         | 長期的な指標、安定性、変化パターンを分析 |
| **Data Validation**     | ルールベースのチェック   | 厳密な値、閾値、範囲、リストを適用 — 監査トレイル付き |
| **Data Timeliness**     | 配信監視                 | AI学習による到着時間とユーザースケジュールを組み合わせ、遅延データを検出 |
| **Data Schema Tracker** | 構造の監視               | スキーマドリフトを検出：新規/削除された列、データ型の変更 |

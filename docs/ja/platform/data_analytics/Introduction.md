# Data Analytics – 傾向と安定性

## Purpose
長期的な傾向とデータの安定性を明らかにします。

## Technical Features
### Derived statistics
- **傾向、変動性、季節性**を算出します。

### Supported metrics
- レコード数  
- 欠損値  
- 最小/最大、合計、平均  

### Time-series analysis
- 週／月単位での安定性

## Example Use Cases
- 3か月のローリング期間で売上上位の商品を特定する。  
- 欠損値の変動性を検出して断続的なパイプライン問題を捕捉する。  
- KPI の安定性が高い期間と低い期間を比較する。  

## Value
基本的な統計を **ビジネス監視** および **データ運用** のための実行可能なインサイトに変換します。

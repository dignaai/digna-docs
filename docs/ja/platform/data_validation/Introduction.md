# Data Validation – ルールベースのチェック

## Purpose
決定論的なルールベースのチェックを適用する。

## Technical Features
- 対応:
  - 等値チェック
  - しきい値と範囲
  - 参照リスト / ルックアップ検証
- コンプライアンス対応のための **トレーサビリティ & 監査可能性**  
- ルールの実行は規制報告用にログ記録されます  

## Example Use Cases
- 請求書の金額が会計ポリシーに準拠していることを検証する  
- VATコードや通貨コードが事前定義された参照セットと一致していることを確認する  
- 規制フレームワーク下でのリスク加重資産に対するしきい値を検証する  

## Value
厳格な検証が求められる **金融、ヘルスケア、規制産業** において不可欠です。

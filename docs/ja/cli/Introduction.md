## コマンドラインインターフェース（CLI）の目的

***digna*** コマンドラインインターフェース（CLI）は、***digna*** プラットフォームとのやり取りを効率化するために設計された強力なツールです。GUI を必要とせず、テキストベースのインターフェースを通じて幅広い作業を効率的に実行できます。

### 主な機能:

- **効率性と柔軟性:** CLI はコマンドの迅速な実行を可能にし、生産性を向上させます。
- **自動化:** スクリプトによる定型作業の自動化をサポートします。
- **リモートアクセス:** どこからでも ***digna*** リソースを管理できます。
- **一貫性と信頼性:** 文書化されバージョン管理されたコマンドにより、信頼性の高い操作を保証します。
- **スケーラビリティ:** エンタープライズの大規模な操作を処理します。
- **習得と理解:** ***digna*** の機能をより深く理解できます。
- **他ツールとの統合:** Control-M、UC4、AutomateNOW! のような自動化ツールとシームレスに統合できます。

## Windows 向けインストール手順

開始するには、以下の手順に従って必要なファイルを展開し、*dignacli* フォルダを配置し、***digna*** リポジトリへの接続を設定してください。作業を始める前に、リポジトリの認証情報や必要な設定情報を用意しておいてください。

1. **Extracting the ***digna*** CLI:**
   - ***digna*** CLI を含む `.zip` ファイルを入手します。
   - ファイルを任意のディレクトリに解凍します。

2. **Deploying the `dignacli` Folder:**
   - `dignacli` フォルダを希望するインストール先（例：`C:\Program Files\***digna***`）にコピーします。

3. **Configuring `config.toml`:**
   - `dignacli` 内に `config.toml` があるか確認します。
   - 必要に応じて `config_template.toml` を `config.toml` にリネームし、提供されたドキュメントに従って設定してください。

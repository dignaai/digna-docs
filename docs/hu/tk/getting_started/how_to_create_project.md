### Lépések

1. **Projekt szakasz megnyitása**
   - A bal oldali navigációs menüből kattintson a **Projects** elemre.

2. **Új projekt létrehozása**
   - Kattintson a **New Project** gombra.

3. **Projekt részleteinek megadása**
   - Adjon meg egy **Project Name**-et.  
   - (Opcionálisan) Kontextus megadásához adjon hozzá egy **Description**-t.

4. **Projekt mentése**
   - A befejezéshez kattintson a **Create** gombra.  
   - A projekt mostantól megjelenik a **Projects list**-ben.

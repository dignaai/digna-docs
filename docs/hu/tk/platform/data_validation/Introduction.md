# Data Validation – Szabályalapú ellenőrzések

## Cél
Determininsztikus, szabályalapú ellenőrzések végrehajtása.

## Technikai jellemzők
- Támogatott funkciók:
  - Egyenlőség-ellenőrzések
  - Küszöbök és tartományok
  - Referencia-listák / lookup-ellenőrzés
- Megfelelőséghez biztosítja a **nyomonkövethetőséget és auditálhatóságot**  
- A szabályok végrehajtása rögzítésre kerül szabályozói jelentéstételhez  

## Példák használati esetekre
- Ellenőrizze, hogy a számla összege megfelel-e a számviteli irányelveknek  
- Garantálja, hogy az ÁFA-kódok és a pénznemkódok előre definiált referenciahalmazokkal egyeznek  
- Ellenőrizze a kockázattal súlyozott eszközökre vonatkozó küszöbértékeket a szabályozói kereteknek megfelelően  

## Érték
A szigorú validáció alapvető a **pénzügyi, egészségügyi és szabályozott iparágakban**.

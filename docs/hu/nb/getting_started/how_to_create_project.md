### Lépések

1. **Nyisd meg a projekt szekciót**
   - A bal oldali navigációs sávon kattints a **Projektek** elemre.

2. **Hozz létre új projektet**
   - Kattints az **Új projekt** gombra.

3. **Töltsd ki a projekt adatait**
   - Add meg a **Projekt nevét**.  
   - (Opcionális) Adj hozzá egy **Leírást** a kontextushoz.

4. **Mentsd el a projektet**
   - Kattints a **Létrehozás** gombra a befejezéshez.  
   - A projekt most megjelenik a **Projektlistádban**.

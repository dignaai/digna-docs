# Data Validation – Szabályalapú ellenőrzések

## Purpose
A determinisztikus, szabályalapú ellenőrzések érvényesítése.

## Technical Features
- Támogatja:
  - Egyenlőség-ellenőrzéseket
  - Küszöbértékeket és tartományokat
  - Referencialistákat / lookup érvényesítést
- Biztosítja a **nyomonkövethetőséget és auditálhatóságot** a megfelelés érdekében  
- A szabályok végrehajtása naplózásra kerül a szabályozói jelentésekhez  

## Example Use Cases
- Számlák összegeinek ellenőrzése, hogy megfelelnek-e a számviteli előírásoknak  
- Annak biztosítása, hogy az áfa- és valutakódok megegyezzenek az előre meghatározott referenciakészletekkel  
- A szabályozói keretek szerinti kockázati súlyozott eszközök küszöbértékeinek érvényesítése  

## Value
Elengedhetetlen a **pénzügyi, egészségügyi és szabályozott iparágakban**, ahol szigorú érvényesítés szükséges.

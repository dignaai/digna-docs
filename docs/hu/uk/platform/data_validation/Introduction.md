# Data Validation – Szabályalapú ellenőrzések

## Cél
Determinált szabályalapú ellenőrzések végrehajtásának biztosítása.

## Műszaki jellemzők
- Támogatja:
  - Egyenlőség-ellenőrzéseket
  - Küszöbértékeket és tartományokat
  - Referencia-listákat / referenciaalapú ellenőrzést
- Biztosítja a **nyomon követhetőséget és az auditálhatóságot** a megfelelés érdekében  
- A szabályok végrehajtása naplózásra kerül a szabályozói jelentéstételhez  

## Példák használati esetekre
- Ellenőrizni, hogy a számlák összege megfelel-e a számviteli politikának  
- Ellenőrizni, hogy az áfa-kódok és a devizakódok megfelelnek-e előre definiált referencialistáknak  
- Ellenőrizni a küszöbértékeket a kockázati súlyozású eszközöknél a szabályozói követelményeknek megfelelően  

## Előnyök
Szükséges a **pénzügyekben, az egészségügyben és a szabályozott ágazatokban**, ahol szigorú validálásra van szükség.

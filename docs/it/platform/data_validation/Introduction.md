# Data Validation – Rule-Based Checks

## Purpose
Applicare controlli deterministici basati su regole.

## Technical Features
- Supporta:
  - Controlli di uguaglianza
  - Soglie e intervalli
  - Liste di riferimento / validazione tramite lookup
- Fornisce **tracciabilità & auditabilità** per la conformità  
- L'esecuzione delle regole viene registrata per il reporting normativo  

## Example Use Cases
- Verificare che gli importi delle fatture siano conformi alle politiche contabili  
- Assicurare che i codici IVA e i codici valuta corrispondano a insiemi di riferimento predefiniti  
- Validare le soglie per gli attivi ponderati per il rischio nell'ambito di quadri normativi  

## Value
Essenziale in **finanza, sanità e industrie regolamentate** dove è richiesta una validazione rigorosa.

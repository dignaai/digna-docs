# Data Analytics – Tendenze e Stabilità

## Scopo
Rivelare tendenze a lungo termine e la stabilità dei dati.

## Caratteristiche tecniche
### Statistiche derivate
- Calcola **trend, volatilità, stagionalità**.

### Metriche supportate
- Conteggio record  
- Valori mancanti  
- Min/max, somme, medie  

### Analisi delle serie temporali
- Stabilità su base settimanale/mensile

## Esempi di utilizzo
- Identificare i prodotti più venduti in un periodo mobile di 3 mesi.  
- Rilevare volatilità nei valori mancanti per individuare problemi intermittenti nella pipeline.  
- Confrontare periodi di alta vs. bassa stabilità nei KPI.  

## Valore
Trasforma statistiche di base in insight azionabili per il **monitoraggio aziendale** e le **operazioni sui dati**.

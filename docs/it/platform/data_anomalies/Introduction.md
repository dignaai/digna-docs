# Data Anomalies – Rilevamento automatico

## Purpose
Individuare anomalie senza scrivere regole.

## Technical Features
### Metrics analyzed
- Volume dei record  
- Valori mancanti  
- Distribuzioni & istogrammi  
- Intervalli di valori  
- Unicità  

### Intelligent detection
- Usa **apprendimento storico** per definire dinamicamente gli intervalli attesi  
- Segnala anomalie quando i dati effettivi escono dai limiti attesi  

## Detection Scenarios
- **Cali/aumenti di volume** → es. mancano la metà delle transazioni giornaliere  
- **Scambio di colonne** → colonne nome e cognome invertite  
- **Valori inaspettati** → “Zurigo” che compare tra le città austriache  

## Value
Automatizza ciò che normalmente richiederebbe centinaia di regole manuali.

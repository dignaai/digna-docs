### Passaggi

1. **Apri il tuo progetto**  
   Dalla navigazione a sinistra, clicca **Projects** e seleziona il progetto di destinazione.

2. **Aggiungi una Datasource**  
   Vai su **Datasources** e clicca **Add Datasource**.

3. **Scegli il tipo di Datasource**  
   Seleziona il tipo di database: Table o View.

4. **Trova la tua Datasource nella lista**  
   Seleziona la tua Datasource dall'elenco.

5. **Definisci la Snapshot Query**  
   Definisci la Snapshot Query. La Snapshot Query definisce come *digna* accederà ai dati di un singolo giorno.

6. **Preview**  
   Clicca su preview per verificare se la Snapshot Query è stata definita correttamente.

7. **Create datasource**  
   Se tutto è stato configurato correttamente, puoi salvare la configurazione.

### Passaggi

1. **Apri la sezione**
   - Dalla navigazione a sinistra, clicca **Projects**.

2. **Crea un nuovo progetto**
   - Clicca il pulsante **New Project**.

3. **Inserisci i dettagli del progetto**
   - Fornisci un **Project Name**.  
   - (Opzionale) Aggiungi una **Description** per il contesto.

4. **Salva il progetto**
   - Clicca **Create** per completare.  
   - Il progetto apparirà ora nella tua **Projects list**.

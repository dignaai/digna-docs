# Data Schema Tracker – Παρακολούθηση της Εξέλιξης του Σχήματος
<h1 style="display:none;">Μονάδα με AI για την Παρατηρησιμότητα Μεταδεδομένων και την Ποιότητα Δεδομένων – digna Data Schema Tracker</h1>

---

## Σκοπός

Το **Data Schema Tracker** σας ενημερώνει για το πώς εξελίσσονται οι δομές της βάσης δεδομένων σας.  
Παρακολουθεί συνεχώς τα **σχήματα πινάκων, τις στήλες και τους τύπους δεδομένων** για να εντοπίζει το **schema drift** — σκόπιμες ή ακούσιες δομικές αλλαγές που μπορούν να διαταράξουν pipelines, ETL jobs ή BI dashboards.

Εξασφαλίζοντας διαφάνεια στην εξέλιξη του σχήματος, το digna βοηθά τους οργανισμούς να διατηρούν **εμπιστοσύνη στην ποιότητα των δεδομένων**, να διαφυλάσσουν την **παρατηρησιμότητα των συστημάτων δεδομένων** και να αποφεύγουν δαπανηρά περιστατικά παραγωγής που προκαλούνται από μη ανιχνευμένες αλλαγές σχήματος.

---

## Τεχνική Επισκόπηση

### Τι Παρακολουθεί

- **Προσθήκη ή Αφαίρεση Στηλών** – Εντοπίζει νεοπαρουσιαζόμενες, μετονομαζόμενες ή διαγραμμένες στήλες.  
- **Τροποποιήσεις Τύπων Δεδομένων** – Αναγνωρίζει αλλαγές όπως `INT → VARCHAR` ή `DATE → TIMESTAMP`.  
- **Τροποποιήσεις Πινάκων και Views** – Παρακολουθεί δημιουργία, μετονομασία ή αφαίρεση πινάκων και views.  
- **Διαφορές Μεταξύ Περιβαλλόντων** – Συγκρίνει εκδόσεις σχήματος μεταξύ Dev, Test και Production περιβαλλόντων.  

### Ανίχνευση & Ειδοποίηση

- Σαρώνει τα **μεταδεδομένα της βάσης δεδομένων** ή τους **καταλόγους συστήματος** απευθείας μέσα στην πλατφόρμα δεδομένων σας.  
- Συγκρίνει κάθε στιγμιότυπο σχήματος με την προηγουμένως γνωστή έκδοση που είναι αποθηκευμένη στο observability schema του digna.  
- Δημιουργεί **ειδοποιήσεις σε πραγματικό χρόνο** στο dashboard, μέσω API ή εξωτερικών καναλιών ειδοποίησης (email, Slack, webhook).  
- Καταγράφει κάθε έκδοση σχήματος για **ιστορική παρακολούθηση και ετοιμότητα για έλεγχο**.

---

## Αρχιτεκτονική και Εκτέλεση

- **Εκτέλεση εντός Βάσης Δεδομένων:** το digna τρέχει εξ ολοκλήρου στο περιβάλλον σας, ερωτώντας views μεταδεδομένων χωρίς εξαγωγή οποιωνδήποτε δεδομένων.  
- **Ελαφρύ Σκανάρισμα:** προσπελαύνει μόνο δομικές πληροφορίες — ποτέ δεδομένα χρηστών.  
- **Κεντρική Αποθήκευση:** τα μεταδεδομένα σχήματος και τα αρχεία drift αποθηκεύονται στο observability schema του digna για οπτικοποίηση και ανάλυση.  
- **Αυτοματοποίηση:** υποστηρίζει προγραμματισμένες ή συμβάντικες σαρώσεις μέσω digna Core ή εξωτερικών εργαλείων ορχήστρωσης.

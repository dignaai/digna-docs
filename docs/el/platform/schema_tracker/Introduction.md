# Data Schema Tracker – Παρακολούθηση Εξέλιξης Σχήματος

## Purpose
Παρακολούθηση και ειδοποίηση για την εξέλιξη του σχήματος.

## Technical Features
- Παρακολουθεί:
  - Προσθήκη ή αφαίρεση στηλών
  - Αλλαγές τύπων δεδομένων
- Ειδοποιεί για εκούσιες και ακούσιες αλλαγές στο σχήμα  
- Αποτρέπει το **silent schema drift** που μπορεί να διακόψει ETL pipelines ή dashboards  

## Example Use Cases
- Ανίχνευση αλλαγών τύπων δεδομένων (π.χ., `INT` → `VARCHAR`) που μπορεί να προκαλέσουν σφάλματα στα επόμενα στάδια  
- Ειδοποίηση των data engineers πριν αποτύχουν τα pipelines λόγω ασυμφωνιών στο σχήμα  

## Value
Βοηθά τις ομάδες να έχουν έλεγχο πάνω σε **ταχέως μεταβαλλόμενα, εξελισσόμενα σύνολα δεδομένων**.

# Data Anomalies – Αυτόματη Ανίχνευση

## Purpose
Εντοπίστε ανωμαλίες χωρίς να γράφετε κανόνες.

## Technical Features
### Metrics analyzed
- Όγκος εγγραφών  
- Ελλείποντα δεδομένα  
- Κατανομές & ιστογράμματα  
- Εύρη τιμών  
- Μοναδικότητα  

### Intelligent detection
- Χρησιμοποιεί **ιστορική μάθηση** για να ορίσει δυναμικά τα αναμενόμενα εύρη  
- Σηματοδοτεί ανωμαλίες όταν τα πραγματικά δεδομένα βρίσκονται εκτός των αναμενόμενων ορίων  

## Detection Scenarios
- **Μειώσεις/αυξήσεις όγκου** → π.χ., λείπει το μισό των καθημερινών συναλλαγών  
- **Ανταλλαγή στηλών** → οι στήλες με το όνομα και το επώνυμο έχουν αντιστραφεί  
- **Απρόσμενες τιμές** → “Zurich” εμφανίζεται στη λίστα αυστριακών πόλεων  

## Value
Αυτοματοποιεί όσα κανονικά θα απαιτούσαν εκατοντάδες χειροκίνητους κανόνες.

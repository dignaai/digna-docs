# Data Analytics – Τάσεις και Σταθερότητα

## Purpose
Αποκάλυψη μακροχρόνιων τάσεων και σταθερότητας δεδομένων.

## Technical Features
### Derived statistics
- Υπολογίζει **τάση, μεταβλητότητα, εποχικότητα**.

### Supported metrics
- Πλήθος εγγραφών  
- Ελλείπουσες τιμές  
- Ελάχιστο/Μέγιστο, αθροίσματα, μέσοι όροι  

### Time-series analysis
- Σταθερότητα σε εβδομαδιαίο/μηνιαίο επίπεδο

## Example Use Cases
- Εντοπίστε τα πλέον πωλούμενα προϊόντα σε κυλιόμενη 3μηνη περίοδο.  
- Εντοπίστε μεταβλητότητα στις ελλείπουσες τιμές για να ανιχνεύσετε διαλείποντα προβλήματα στο pipeline.  
- Συγκρίνετε περιόδους υψηλής έναντι χαμηλής σταθερότητας στα KPIs.  

## Value
Μετατρέπει βασικά στατιστικά σε εφαρμόσιμα συμπεράσματα για **παρακολούθηση επιχειρήσεων** και **λειτουργίες δεδομένων**.

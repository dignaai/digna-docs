## Σκοπός της Διεπαφής Γραμμής Εντολών (CLI)

Η ***digna*** Command Line Interface (CLI) είναι ένα ισχυρό εργαλείο σχεδιασμένο να απλοποιεί τις αλληλεπιδράσεις με την πλατφόρμα ***digna***. Παρέχει μια κειμενοκεντρική διεπαφή που επιτρέπει στους χρήστες να εκτελούν ένα ευρύ φάσμα εργασιών αποδοτικά, χωρίς την ανάγκη γραφικού περιβάλλοντος.

### Κύρια Χαρακτηριστικά:

- **Απόδοση και Ευελιξία:** Η CLI επιτρέπει την γρήγορη εκτέλεση εντολών, βελτιώνοντας την παραγωγικότητα.
- **Αυτοματοποίηση:** Υποστηρίζει scripting για την αυτοματοποίηση επαναλαμβανόμενων εργασιών.
- **Απομακρυσμένη Πρόσβαση:** Διαχειριστείτε πόρους της ***digna*** από οπουδήποτε.
- **Συνέπεια και Αξιοπιστία:** Εξασφαλίζει αξιόπιστες λειτουργίες με τεκμηριωμένες, ελεγχόμενες εκδόσεις εντολών.
- **Κλιμάκωση:** Αντιμετωπίζει επιχειρησιακές εργασίες σε μεγάλο εύρος.
- **Μάθηση και Εμπέδωση:** Παρέχει βαθύτερη κατανόηση της λειτουργικότητας της ***digna***.
- **Ενσωμάτωση με Άλλα Εργαλεία:** Εντάσσεται απρόσκοπτα με εργαλεία αυτοματοποίησης όπως Control-M, UC4, AutomateNOW!

## Installation Instruction for Windows

Για να ξεκινήσετε, ακολουθήστε τα παρακάτω βήματα για να αποσυμπιέσετε τα απαραίτητα αρχεία, να αναπτύξετε τον φάκελο *dignacli* και να διαμορφώσετε τη σύνδεσή σας με το αποθετήριο της ***digna***. Βεβαιωθείτε ότι έχετε τα διαπιστευτήρια του αποθετηρίου σας και τυχόν απαιτούμενες λεπτομέρειες διαμόρφωσης πριν ξεκινήσετε.

1. **Εξαγωγή του CLI της ***digna***:**
   - Αποκτήστε το αρχείο `.zip` που περιέχει το CLI της ***digna***.
   - Αποσυμπιέστε το αρχείο στον κατάλογο που επιθυμείτε.

2. **Ανάπτυξη του φακέλου `dignacli`:**
   - Αντιγράψτε τον φάκελο `dignacli` στην προτιμώμενη θέση εγκατάστασης (π.χ. `C:\Program Files\***digna***`).

3. **Διαμόρφωση του `config.toml`:**
   - Ελέγξτε για το `config.toml` μέσα στο `dignacli`.
   - Μετονομάστε το `config_template.toml` σε `config.toml` αν χρειάζεται και διαμορφώστε το χρησιμοποιώντας την παρεχόμενη τεκμηρίωση.

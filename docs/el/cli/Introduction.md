## Σκοπός της Διεπαφής Γραμμής Εντολών (CLI)

Η ***digna*** Command Line Interface (CLI) είναι ένα ισχυρό εργαλείο σχεδιασμένο για να απλοποιεί τις αλληλεπιδράσεις με την πλατφόρμα ***digna***. Παρέχει μια διεπαφή βασισμένη σε κείμενο που επιτρέπει στους χρήστες να εκτελούν ένα ευρύ φάσμα εργασιών αποδοτικά, χωρίς την ανάγκη γραφικού περιβάλλοντος χρήστη.

### Κύρια Χαρακτηριστικά:

- **Αποδοτικότητα και Ευελιξία:** Η CLI επιτρέπει την γρήγορη εκτέλεση εντολών, βελτιώνοντας την παραγωγικότητα.
- **Αυτοματοποίηση:** Υποστηρίζει scripting για την αυτοματοποίηση επαναλαμβανόμενων εργασιών.
- **Απομακρυσμένη Πρόσβαση:** Διαχειριστείτε πόρους του ***digna*** από οπουδήποτε.
- **Συνέπεια και Αξιοπιστία:** Διασφαλίζει αξιόπιστες λειτουργίες με τεκμηριωμένες, ελεγχόμενες εκδόσεις εντολών.
- **Επεκτασιμότητα:** Αντιμετωπίζει λειτουργίες σε μεγάλη κλίμακα για επιχειρησιακές εργασίες.
- **Εκμάθηση και Εμβάθυνση:** Παρέχει βαθύτερη κατανόηση της λειτουργικότητας του ***digna***.
- **Ενσωμάτωση με Άλλα Εργαλεία:** Ενσωματώνεται απρόσκοπτα με εργαλεία αυτοματοποίησης όπως Control-M, UC4, AutomateNOW!

## Οδηγίες Εγκατάστασης για Windows

Για να ξεκινήσετε, ακολουθήστε τα παρακάτω βήματα για να αποσυμπιέσετε τα απαραίτητα αρχεία, να αναπτύξετε τον φάκελο *dignacli* και να διαμορφώσετε τη σύνδεσή σας με το αποθετήριο ***digna***. Βεβαιωθείτε ότι έχετε τα διαπιστευτήρια του αποθετηρίου και οποιαδήποτε απαιτούμενα στοιχεία διαμόρφωσης έτοιμα πριν ξεκινήσετε.

1. **Αποσυμπίεση του ***digna*** CLI:**
   - Αποκτήστε το αρχείο `.zip` που περιέχει το ***digna*** CLI.
   - Αποσυμπιέστε το αρχείο στον φάκελο που επιθυμείτε.

2. **Ανάπτυξη του φακέλου `dignacli`:**
   - Αντιγράψτε το φάκελο `dignacli` στην επιλεγμένη τοποθεσία εγκατάστασης (π.χ., `C:\Program Files\***digna***`).

3. **Ρύθμιση του `config.toml`:**
   - Ελέγξτε για το αρχείο `config.toml` μέσα στο `dignacli`.
   - Μετονομάστε το `config_template.toml` σε `config.toml` εάν χρειάζεται και ρυθμίστε το σύμφωνα με την παρεχόμενη τεκμηρίωση.

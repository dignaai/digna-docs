# Πώς να προγραμματίσετε ένα ημερήσιο job

Ο προγραμματισμός σάς επιτρέπει να εκτελείτε επιθεωρήσεις αυτόματα χωρίς χειροκίνητη παρέμβαση.  
Σε αυτόν τον οδηγό, θα μάθετε πώς να δημιουργήσετε ένα job που εκτελείται **μία φορά την ημέρα**, εξασφαλίζοντας ότι τα δεδομένα σας παρακολουθούνται συνεχώς.

## Τι θα μάθετε

- Πώς να αποκτήσετε πρόσβαση στην ενότητα **Scheduling** στο digna dashboard  
- Πώς να δημιουργήσετε ένα νέο προγραμματισμένο job  
- Πώς να το ρυθμίσετε ώστε να τρέχει **καθημερινά σε σταθερή ώρα**  
- Πώς να επιλέξετε το σωστό project και datasource  
- Πώς να ενεργοποιήσετε το job ώστε να εκτελείται αυτόματα  

---

## Γιατί οι ημερήσιες εργασίες είναι χρήσιμες

Ο ημερήσιος προγραμματισμός είναι η πιο συνηθισμένη ρύθμιση σε παραγωγικά περιβάλλοντα. Εξασφαλίζει:  

- **Φρεσκάδα** — τα δεδομένα κάθε ημέρας ελέγχονται.  
- **Συνέπεια** — οι ανωμαλίες ανιχνεύονται νωρίς πριν προχωρήσουν σε επόμενα στάδια.  
- **Αυτοματοποίηση** — δεν χρειάζεται χειροκίνητη ενεργοποίηση των επιθεωρήσεων.

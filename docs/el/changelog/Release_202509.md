# Κατάλογος αλλαγών – Έκδοση 2025.09  

Με την Έκδοση 2025.09, η digna εισάγει μια νέα **modular αρχιτεκτονική** και λανσάρει **πέντε εξειδικευμένα modules** για Data Quality και Observability.  
Αυτή η έκδοση ενισχύει επίσης τον μηχανισμό ταυτοποίησης και βελτιώνει τη διαχείριση ειδοποιήσεων σε όλη την πλατφόρμα.  

---

## Νέα Χαρακτηριστικά  

### Modular Design  
- Η digna πλέον ακολουθεί μια **modular αρχιτεκτονική**.  
- Οι πελάτες μπορούν να ενεργοποιούν μόνο τα modules που χρειάζονται και να προσθέτουν περισσότερα καθώς μεγαλώνουν οι ανάγκες τους.  
- Η προηγούμενη λειτουργικότητα αποτελεί τώρα μέρος του **digna Data Anomalies**.  

### Νέα Modules  
- **digna Data Anomalies** – Εντοπισμός ανωμαλιών με υποστήριξη AI σε όγκους δεδομένων, κατανομές και ελλείπουσες τιμές.  
- **digna Data Analytics** – Αξιολόγηση χρονοσειρών μετρήσεων observability για την ανίχνευση μακροπρόθεσμων τάσεων και μεταβλητότητας.  
- **digna Data Timeliness** – Παρακολούθηση αναμενόμενων χρόνων άφιξης δεδομένων, με προσεγγίσεις βάσει AI και κανόνων.  
- **digna Data Validation** – Έλεγχοι σε επίπεδο εγγραφής με κανόνες για διασφάλιση συμμόρφωσης με επιχειρησιακούς κανόνες.  
- **digna Data Schema Tracker** – Ανίχνευση αλλαγών στο σχήμα (τροποποιήσεις DDL) στις παρακολουθούμενες βάσεις δεδομένων.  

### MFA μέσω OIDC  
- Υποστήριξη για **Multi-Factor Authentication (MFA)** με OIDC Single Sign-On.  
- Παρέχει ασφάλεια επιπέδου enterprise για όλες τις συνδέσεις χρηστών.  

### Ειδοποιήσεις Email ανά Module  
- Οι ειδοποιήσεις πλέον αποστέλλονται **ανά module**, διευκολύνοντας τον διαχωρισμό των alerts από Data Anomalies, Data Analytics και άλλα modules.

## Ενημερώσεις CLI  

- **Νέα εντολή: `inspect-cancel`** – Ακύρωση επιθεωρήσεων με βάση το request ID ή τερματισμός όλων των ενεργών αιτήσεων.  
- **Νέα εντολή: `check-config`** – Επικύρωση αρχείων ρύθμισης πριν την εκκίνηση.  
- **Νέα εντολή: `remove-orphans`** – Καθαρισμός ορφανών εγγραφών αποθετηρίου.  
- **Ενισχυμένη εντολή `inspect`** – Νέα επιλογή `--bypass-backend` (`-bb`) και τυποποιημένοι κωδικοί επιστροφής (`0 = OK, 1 = INFO, 2 = WARNING`).

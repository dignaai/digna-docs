# digna Modules — Technical Overview



digna is an AI-powered **Data Quality & Observability Platform**.  

It runs directly in your data environment and ensures trust in your data without requiring custom rule coding.



---



## Module Summary

| Module                  | Focus Area               | Key Capabilities |
|--------------------------|--------------------------|------------------|
| **Data Anomalies**      | Automated anomaly detection | Learns “normal” behavior, detects deviations in volume, distributions, values |
| **Data Analytics**      | Trends & volatility      | Analyzes long-term metrics, stability, change patterns |
| **Data Validation**     | Rule-based checks        | Enforce exact values, thresholds, ranges, lists — with audit trail |
| **Data Timeliness**     | Delivery monitoring      | AI-learned arrival times + user schedules, detects late data |
| **Data Schema Tracker** | Structural monitoring    | Detects schema drift: new/removed columns, datatype changes |

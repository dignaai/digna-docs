# Data Validation – Regelbaserte sjekker

## Formål
Håndheve deterministiske, regelbaserte sjekker.

## Tekniske funksjoner
- Støtter:
  - Likhetssjekker
  - Terskler og intervaller
  - Referanselister / oppslagsvalidering
- Gir **sporbarhet og etterprøvbarhet** for etterlevelse  
- Utførelse av regler loggføres for regulatorisk rapportering  

## Eksempler på brukstilfeller
- Sjekke at fakturabeløp er i samsvar med regnskapsretningslinjer  
- Sikre at MVA-koder og valutakoder samsvarer med forhåndsdefinerte referansesett  
- Validere terskler for risikovektede eiendeler i henhold til regulatoriske rammeverk  

## Verdi
Avgjørende innen **finans, helsetjenester og regulerte bransjer** hvor streng validering kreves.

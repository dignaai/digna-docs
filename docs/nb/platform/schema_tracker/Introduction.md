# Data Schema Tracker – Overvåk skjemaendringer

## Formål
Spor og varsle ved skjemaendringer.

## Tekniske funksjoner
- Overvåker:
  - Tilføyde eller fjernede kolonner
  - Endringer i datatyper
- Varsler ved både tilsiktede og utilsiktede skjemaendringer  
- Forhindrer **silent schema drift** som kan bryte ETL-pipelines eller dashbord  

## Brukseksempler
- Identifisere endringer i datatyper (f.eks. `INT` → `VARCHAR`) som kan forårsake feil i nedstrømsprosesser  
- Varsle dataingeniører før pipelines feiler på grunn av skjemaavvik  

## Verdi
Holder teamene i kontroll over **raskt bevegelige, stadig utviklende datasett**.

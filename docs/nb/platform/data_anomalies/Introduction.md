# Data Anomalies – Automatisk deteksjon

## Purpose
Oppdage anomalier uten å skrive regler.

## Technical Features
### Metrics analyzed
- Antall poster  
- Manglende verdier  
- Fordelinger & histogrammer  
- Verdiområder  
- Unikhet  

### Intelligent detection
- Bruker **historisk læring** for å definere forventede intervaller dynamisk  
- Marker anomalier når faktisk data faller utenfor forventede grenser  

## Detection Scenarios
- **Volumfall/økninger** → f.eks. mangler halvparten av daglige transaksjoner  
- **Kolonner byttet om** → fornavn- og etternavn-kolonner byttet om  
- **Uventede verdier** → “Zurich” dukker opp i østerrikske byer  

## Value
Automatiserer det som normalt ville krevd hundrevis av manuelle regler.

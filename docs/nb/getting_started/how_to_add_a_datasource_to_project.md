### Steg

1. **Åpne prosjektet ditt**  
   Fra venstremenyen klikker du **Projects** og velger målprosjektet.

2. **Legg til en Datasource**  
   Gå til **Datasources** og klikk **Add Datasource**.

3. **Velg type Datasource**  
   Velg database Type: Table eller View.

4. **Finn din Datasource i listen**  
   Velg din Datasource fra listen.

5. **Definer Snapshot Query**  
   Definer Snapshot Query. Snapshot Query definerer hvordan *digna* vil få tilgang til én dags data.

6. **Forhåndsvisning**  
   Klikk på preview for å verifisere om Snapshot Query ble definert riktig.

7. **Opprett datasource**  
   Hvis alt er konfigurert riktig, kan du lagre konfigurasjonen din.

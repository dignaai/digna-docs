# Data Analytics – Trendit ja vakaus

## Tarkoitus
Paljastaa pitkäaikaiset trendit ja datan vakaus.

## Tekniset ominaisuudet
### Johdetut tilastot
- Laskee **trendi, volatiliteetti, kausivaihtelu**.

### Tuetut mittarit
- Tietueiden määrä  
- Puuttuvat arvot  
- Minimi/maximi, summat, keskiarvot  

### Aikasarja-analyysi
- Vakaus viikkojen/kuukausien tasolla

## Esimerkkikäyttötapaukset
- Tunnista eniten myyvät tuotteet liukuvalla 3 kuukauden ajanjaksolla.  
- Havaitse puuttuvien arvojen volatiliteetti ajoittaisten pipeline-ongelmien löytämiseksi.  
- Vertaile KPI:iden korkean ja matalan vakauden ajanjaksoja.  

## Arvo
Muuttaa perusstatistiikan toiminnallisiksi oivalluksiksi **liiketoiminnan seurannassa** ja **dataoperaatioissa**.

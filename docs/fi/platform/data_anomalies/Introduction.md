# Data Anomalies – Automaattinen havaitseminen

## Tarkoitus
Havaitse poikkeamat ilman sääntöjen kirjoittamista.

## Tekniset ominaisuudet
### Analysoitavat mittarit
- Tietueiden määrä  
- Puuttuvat arvot  
- Jakautumat & histogrammit  
- Arvoalueet  
- Yksilöllisyys  

### Älykäs tunnistus
- Käyttää **historiallista oppimista** määrittämään odotetut rajat dynaamisesti  
- Merkitsee poikkeamat, kun todelliset tiedot ovat odotettujen rajojen ulkopuolella  

## Havaitsemistilanteet
- **Määrän laskut/huiput** → esim. puolet päivittäisistä tapahtumista puuttuu  
- **Sarakkeiden sekoittuminen** → etunimi- ja sukunimisarakkeet vaihdettu  
- **Odottamattomat arvot** → “Zurich” esiintyy Itävallan kaupungeissa  

## Hyödyt
Automatisoi sen, mitä normaalisti vaatisi satoja manuaalisia sääntöjä.

# *digna* -moduulit — tekninen yleiskuva



*digna* on tekoälypohjainen **Data Quality & Observability Platform**.  

Se toimii suoraan dataympäristössäsi ja varmistaa datasi luotettavuuden ilman tarvetta kirjoittaa räätälöityjä sääntöjä.



---



## Moduuliyhteenveto

| Module                  | Focus Area               | Key Capabilities |
|--------------------------|--------------------------|------------------|
| **Data Anomalies**      | Automaattinen anomaliatunnistus | Oppii “normaalin” käyttäytymisen, havaitsee poikkeamat volyymissa, jakaumissa, arvoissa |
| **Data Analytics**      | Trendit & vaihtelu       | Analysoi pitkän aikavälin mittareita, vakautta, muutosten malleja |
| **Data Validation**     | Sääntöpohjaiset tarkistukset        | Pakottaa täsmälliset arvot, kynnysarvot, arvovälit ja listat — auditointiloki mukana |
| **Data Timeliness**     | Toimitusten seuranta      | Tekoälyn oppimat saapumisajat + käyttäjän aikataulut, havaitsee myöhässä saapuvan datan |
| **Data Schema Tracker** | Rakennevalvonta    | Havaitsee skeeman muutokset: uudet/poistetut sarakkeet, tietotyyppien muutokset |

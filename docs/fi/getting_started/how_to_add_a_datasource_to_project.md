### Vaiheet

1. **Avaa projektisi**  
   Vasemman navigaation valikosta klikkaa **Projects** ja valitse kohdeprojekti.

2. **Lisää Datasource**  
   Siirry kohtaan **Datasources** ja klikkaa **Add Datasource**.

3. **Valitse datasource-tyyppi**  
   Valitse tietokantatyyppi: **Table** tai **View**.

4. **Etsi datasource listalta**  
   Valitse datasource listalta.

5. **Määritä Snapshot Query**  
   Määritä Snapshot Query. Snapshot Query määrittelee, miten *digna* pääsee käsiksi yhden päivän tietoihin.

6. **Esikatselu**  
   Napsauta **Preview** varmistaaksesi, että Snapshot Query on määritelty oikein.

7. **Luo datasource**  
   Jos kaikki on konfiguroitu oikein, voit tallentaa asetuksesi.

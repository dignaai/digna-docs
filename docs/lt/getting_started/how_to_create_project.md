### Veiksmai

1. **Atidarykite projektų skiltį**
   - Kairėje naršymo juostoje spustelėkite **Projektai**.

2. **Sukurkite naują projektą**
   - Spustelėkite mygtuką **Naujas projektas**.

3. **Įveskite projekto duomenis**
   - Nurodykite **Projekto pavadinimą**.  
   - (Pasirinktinai) Pridėkite **Aprašymą** kontekstui.

4. **Išsaugokite projektą**
   - Spustelėkite **Sukurti**, kad užbaigtumėte.  
   - Projektas dabar bus matomas jūsų **projektų sąraše**.

### Žingsniai

1. **Atidarykite savo projektą**  
   Kairėje naršymo juostoje spustelėkite **Projects** ir pasirinkite tikslinį projektą.

2. **Pridėti duomenų šaltinį**  
   Eikite į **Datasources** ir spustelėkite **Add Datasource**.

3. **Pasirinkite duomenų šaltinio tipą**  
   Pasirinkite duomenų bazės tipą: Table arba View.

4. **Raskite savo duomenų šaltinį sąraše**  
   Pasirinkite savo duomenų šaltinį iš sąrašo.

5. **Apibrėžkite Snapshot Query**  
   Apibrėžkite Snapshot Query. Snapshot Query nurodo, kaip *digna* pasieks vienos dienos jūsų duomenis.

6. **Peržiūra**  
   Spustelėkite Preview, kad patikrintumėte, ar Snapshot Query buvo apibrėžta teisingai.

7. **Sukurti duomenų šaltinį**  
   Jei viskas sukonfigūruota teisingai, galite išsaugoti savo konfigūraciją.

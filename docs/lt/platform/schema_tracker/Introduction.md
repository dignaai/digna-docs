# Data Schema Tracker – Stebėti schemos evoliuciją

## Paskirtis
Stebėti schemos pokyčius ir siųsti įspėjimus.

## Techninės funkcijos
- Stebi:
  - Pridėtus arba pašalintus stulpelius
  - Duomenų tipų pakeitimus
- Siunčia įspėjimus apie tiek ketinamus, tiek neketinamus schemos pakeitimus  
- Apsaugo nuo **tylaus schemos dreifo**, kuris gali sutrikdyti ETL procesus arba sukelti klaidas dashboard'uose  

## Naudojimo pavyzdžiai
- Nustatyti duomenų tipų pakeitimus (pvz., `INT` → `VARCHAR`), kurie gali sukelti vėlesnes klaidas  
- Įspėti duomenų inžinierius prieš ETL procesų gedimus dėl schemos neatitikimų  

## Vertė
Padeda komandoms kontroliuoti **greitai kintančius, besivystančius duomenų rinkinius**.

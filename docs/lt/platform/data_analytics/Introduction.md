# Data Analytics – Tendencijos ir Stabilumas

## Tikslas
Atskleisti ilgalaikes tendencijas ir duomenų stabilumą.

## Techninės savybės
### Išvestinės statistikos
- Apskaičiuoja **tendenciją, svyravimus, sezoniškumą**.

### Palaikomi metrikai
- Įrašų skaičius  
- Trūkstamos reikšmės  
- Min/max, sumos, vidurkiai  

### Laiko eilučių analizė
- Stabilumas per savaites/mėnesius

## Naudojimo pavyzdžiai
- Nustatyti daugiausiai parduodamus produktus per slenkantį 3 mėnesių laikotarpį.  
- Aptikti trūkstamų reikšmių svyravimus, kad būtų galima nustatyti epizodines pipeline problemas.  
- Palyginti KPI aukšto ir žemo stabilumo laikotarpius.  

## Vertė
Paverčia pagrindines statistikas į veiksmingas įžvalgas **verslo stebėsenai** ir **duomenų operacijoms**.

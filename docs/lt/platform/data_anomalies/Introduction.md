# Data Anomalies – Automatizuotas aptikimas

## Paskirtis
Aptinkite anomalijas nerašydami taisyklių.

## Techninės savybės
### Analizuojamos metrikos
- Įrašų kiekis  
- Trūkstamos reikšmės  
- Pasiskirstymai ir histogramos  
- Reikšmių intervalai  
- Unikalumas  

### Išmanus aptikimas
- Naudoja **istorinį mokymąsi** tam, kad dinamiškai apibrėžtų numatytus intervalus  
- Pažymi anomalijas, kai faktiniai duomenys patenka už numatytų ribų  

## Aptikimo scenarijai
- **Apimties kritimai/šuoliai** → pvz., prarasta pusė dienos transakcijų  
- **Stulpelių apsikeitimas** → vardų ir pavardžių stulpeliai sukeisti vietomis  
- **Nenumatytos reikšmės** → „Zurich“ atsiranda tarp Austrijos miestų  

## Vertė
Automatizuoja tai, kam įprastai prireiktų šimtų rankinių taisyklių.

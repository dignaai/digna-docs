# Data Validation – Taisymais pagrįstos patikros

## Tikslas
Užtikrinti deterministines, taisymais pagrįstas patikras.

## Techninės savybės
- Palaiko:
  - Lygybės patikras
  - Slenksčius ir intervalus
  - Referencinių sąrašų / lookup patikrą
- Teikia **sekamumą ir audito galimybes** atitikties užtikrinimui  
- Taisyklių vykdymas registruojamas reguliavimo ataskaitoms  

## Panaudojimo pavyzdžiai
- Patikrinti, ar sąskaitų faktūrų sumos atitinka apskaitos politiką  
- Užtikrinti, kad PVM kodai ir valiutų kodai atitiktų iš anksto apibrėžtus referencinius sąrašus  
- Patikrinti slenksčius rizikos svertiniams aktyvams pagal reguliavimo reikalavimus  

## Vertė
Esminė **finansų, sveikatos priežiūros ir reguliuojamose pramonės šakose**, kur reikalinga griežta patikra.

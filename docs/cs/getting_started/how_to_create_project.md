### Kroky

1. **Otevřete sekci projektů**
   - V levém navigačním panelu klikněte na **Projekty**.

2. **Vytvořte nový projekt**
   - Klikněte na tlačítko **Nový projekt**.

3. **Zadejte údaje o projektu**
   - Zadejte **název projektu**.  
   - (Volitelné) Přidejte **popis** pro kontext.

4. **Uložte projekt**
   - Klikněte na **Vytvořit** pro dokončení.  
   - Projekt se nyní zobrazí ve vašem **seznamu projektů**.

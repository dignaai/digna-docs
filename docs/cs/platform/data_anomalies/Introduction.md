# Data Anomalies – Automatická detekce

## Purpose
Zachycujte anomálie bez nutnosti psát pravidla.

## Technical Features
### Metrics analyzed
- Objem záznamů  
- Chybějící hodnoty  
- Distribuce & histogramy  
- Rozsahy hodnot  
- Unikátnost  

### Intelligent detection
- Využívá **učení z historických dat** k dynamickému definování očekávaných rozsahů  
- Označuje anomálie, když se skutečná data dostanou mimo očekávané hranice  

## Detection Scenarios
- **Poklesy/výkyvy objemu** → např. chybí polovina denních transakcí  
- **Prohození sloupců** → např. sloupce s křestním jménem a příjmením prohozeny  
- **Neočekávané hodnoty** → “Zurich” se objevuje mezi rakouskými městy  

## Value
Automatizuje to, co by jinak vyžadovalo stovky ručních pravidel.

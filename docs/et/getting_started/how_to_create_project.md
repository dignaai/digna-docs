### Sammud

1. **Ava projektide sektsioon**
   - Vasakust navigeerimismenüüst klõpsake **Projects**.

2. **Loo uus projekt**
   - Klõpsake nuppu **New Project**.

3. **Sisestage projekti andmed**
   - Sisestage **Project Name**.  
   - (Valikuline) Lisage konteksti jaoks **Description**.

4. **Salvesta projekt**
   - Klõpsake lõpetamiseks **Create**.  
   - Projekt ilmub nüüd teie **Projects list**-is.

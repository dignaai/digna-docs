### Sammud

1. **Ava oma projekt**  
   Vasakust navigeerimisribal klõpsake **Projects** ja valige sihtprojekt.

2. **Lisa andmeallikas**  
   Minge vahekaardile **Datasources** ja klõpsake **Add Datasource**.

3. **Vali Datasource'i tüüp**  
   Valige andmebaasi tüüp: Table või View.

4. **Leia oma Datasource loendist**  
   Valige oma Datasource loendist.

5. **Määra Snapshot Query**  
   Määrake Snapshot Query. Snapshot query määrab, kuidas *digna* pääseb ligi ühe päeva andmetele.

6. **Preview**  
   Klõpsake Preview, et kontrollida, kas Snapshot Query on õigesti määratud.

7. **Create datasource**  
   Kui kõik on õigesti konfigureeritud, saate oma konfiguratsiooni salvestada.

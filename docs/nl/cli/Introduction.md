## Doel van de Command Line Interface (CLI)

De ***digna*** Command Line Interface (CLI) is een krachtig hulpmiddel ontworpen om interacties met het ***digna*** platform te vereenvoudigen. Het biedt een tekstgebaseerde interface waarmee gebruikers efficiënt een breed scala aan taken kunnen uitvoeren, zonder dat een grafische gebruikersinterface nodig is.

### Belangrijkste kenmerken:

- **Efficiëntie en flexibiliteit:** De CLI maakt snelle uitvoering van commando's mogelijk, wat de productiviteit verbetert.
- **Automatisering:** Ondersteunt scripting om repetitieve taken te automatiseren.
- **Extern beheer:** Beheer ***digna***-resources vanaf elke locatie.
- **Consistentie en betrouwbaarheid:** Zorgt voor betrouwbare operaties met gedocumenteerde, versiebeheerde commando's.
- **Schaalbaarheid:** Ondersteunt grootschalige operaties voor enterprise-taken.
- **Leren en beheersing:** Biedt een dieper begrip van de functionaliteit van ***digna***.
- **Integratie met andere tools:** Integreert naadloos met automatiseringstools zoals Control-M, UC4, AutomateNOW!

## Installatie-instructies voor Windows

Om te beginnen, volg de onderstaande stappen om de benodigde bestanden uit te pakken, de 
*dignacli* map te plaatsen en je verbinding met de ***digna*** repository te configureren. Zorg dat je 
je repository-gegevens en eventuele benodigde configuratiegegevens bij de hand hebt voordat je begint.

1. **Extracting the ***digna*** CLI:**
   - Verkrijg het `.zip`-bestand met de ***digna*** CLI.
   - Pak het bestand uit naar de gewenste map.

2. **Deploying the `dignacli` Folder:**
   - Kopieer de `dignacli` map naar je voorkeursinstallatielocatie (bijv. `C:\Program Files\***digna***`).

3. **Configuring `config.toml`:**
   - Controleer of `config.toml` aanwezig is in `dignacli`.
   - Hernoem `config_template.toml` naar `config.toml` indien nodig en configureer het volgens de meegeleverde documentatie.

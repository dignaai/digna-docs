# Data Schema Tracker – Schema-evolutie bewaken

## Doel
Volg schema-evolutie en genereer waarschuwingen.

## Technische kenmerken
- Controleert:
  - Toegevoegde of verwijderde kolommen
  - Wijzigingen in datatypes
- Waarschuwt bij zowel opzettelijke als onopzettelijke schemawijzigingen  
- Voorkomt **silent schema drift** die ETL-pijplijnen of dashboards kan breken  

## Voorbeelden van gebruik
- Het identificeren van datatype-wijzigingen (bijv. `INT` → `VARCHAR`) die downstream-fouten kunnen veroorzaken  
- Data-engineers waarschuwen voordat pijplijnen falen door schema-mismatches  

## Waarde
Houdt teams in controle over **snel evoluerende datasets**.

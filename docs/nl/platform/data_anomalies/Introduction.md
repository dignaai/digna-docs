# Data Anomalies – Automatische Detectie

## Doel
Vang anomalieën zonder regels te schrijven.

## Technische kenmerken
### Geanalyseerde metrics
- Recordvolume  
- Ontbrekende waarden  
- Verdelingen & histogrammen  
- Waardebereiken  
- Uniciteit  

### Intelligente detectie
- Gebruikt **historisch leren** om verwachte waardenbereiken dynamisch te bepalen  
- Markeert anomalieën wanneer actuele data buiten de verwachte grenzen valt  

## Detectiescenario's
- **Daling/piek in volume** → bijv. ontbreekt de helft van de dagelijkse transacties  
- **Kolomverwisselingen** → voornaam- en achternaamkolommen omgewisseld  
- **Onverwachte waarden** → “Zurich” verschijnt bij Oostenrijkse steden  

## Waarde
Automatiseert wat normaal honderden handmatige regels zou vereisen.

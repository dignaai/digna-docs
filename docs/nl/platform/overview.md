# *digna* Modules — Technisch Overzicht



*digna* is een AI-aangedreven **Data Quality & Observability Platform**.  

Het draait rechtstreeks in uw dataomgeving en zorgt voor vertrouwen in uw data zonder dat het schrijven van aangepaste regels vereist is.



---



## Moduleoverzicht

| Module                  | Focusgebied               | Belangrijkste mogelijkheden |
|--------------------------|--------------------------|------------------|
| **Data Anomalies**      | Geautomatiseerde anomaliedetectie | Leert “normaal” gedrag, detecteert afwijkingen in volume, verdelingen, waarden |
| **Data Analytics**      | Trends & volatiliteit      | Analyseert langetermijnstatistieken, stabiliteit, veranderpatronen |
| **Data Validation**     | Regelgebaseerde controles        | Handhaaft exacte waarden, drempels, bereiken, lijsten — met audittrail |
| **Data Timeliness**     | Leveringsmonitoring      | AI-geleerde aankomsttijden + gebruikersschema's, detecteert te late data |
| **Data Schema Tracker** | Structurele monitoring    | Detecteert schema drift: nieuwe/verwijderde kolommen, datatype-wijzigingen |

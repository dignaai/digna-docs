# Data Anomalies – Detecção Automatizada

## Purpose
Detectar anomalias sem escrever regras.

## Technical Features
### Metrics analyzed
- Volume de registros  
- Valores ausentes  
- Distribuições & histogramas  
- Intervalos de valores  
- Unicidade  

### Intelligent detection
- Usa **aprendizado histórico** para definir dinamicamente intervalos esperados  
- Sinaliza anomalias quando os dados reais ficam fora dos limites esperados  

## Detection Scenarios
- **Quedas/picos de volume** → por exemplo, falta metade das transações diárias  
- **Troca de colunas** → colunas de primeiro nome e último nome invertidas  
- **Valores inesperados** → “Zurich” aparecendo em cidades austríacas  

## Value
Automatiza o que normalmente exigiria centenas de regras manuais.

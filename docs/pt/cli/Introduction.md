## Objetivo da Interface de Linha de Comando (CLI)

A Interface de Linha de Comando (CLI) do ***digna*** é uma ferramenta poderosa projetada para simplificar as interações com a plataforma ***digna***. Ela fornece uma interface baseada em texto que permite aos usuários executar uma ampla gama de tarefas de forma eficiente, sem a necessidade de uma interface gráfica.

### Principais recursos:

- **Eficiência e Flexibilidade:** A CLI possibilita a execução rápida de comandos, aumentando a produtividade.
- **Automação:** Suporta scripting para automatizar tarefas repetitivas.
- **Acesso Remoto:** Gerencie recursos do ***digna*** de qualquer lugar.
- **Consistência e Confiabilidade:** Garante operações confiáveis com comandos documentados e controlados por versão.
- **Escalabilidade:** Lida com operações em grande escala para tarefas corporativas.
- **Aprendizado e Domínio:** Proporciona entendimento mais profundo da funcionalidade do ***digna***.
- **Integração com Outras Ferramentas:** Integra-se perfeitamente com ferramentas de automação como Control-M, UC4, AutomateNOW!

## Instruções de instalação para Windows

Para começar, siga os passos descritos abaixo para extrair os arquivos necessários, implantar a pasta *dignacli* e configurar sua conexão com o repositório do ***digna***. Certifique-se de ter suas credenciais do repositório e quaisquer detalhes de configuração necessários prontos antes de iniciar.

1. **Extraindo a CLI do ***digna***:**
   - Obtenha o arquivo `.zip` contendo a CLI do ***digna***.
   - Extraia o arquivo para o diretório desejado.

2. **Implantando a pasta `dignacli`:**
   - Copie a pasta `dignacli` para o local de instalação preferido (por exemplo, `C:\Program Files\***digna***`).

3. **Configurando `config.toml`:**
   - Verifique se existe `config.toml` dentro de `dignacli`.
   - Renomeie `config_template.toml` para `config.toml`, se necessário, e configure-o usando a documentação fornecida.

### Etapas

1. **Abra seu Projeto**  
   Na navegação à esquerda, clique em **Projects** e selecione o projeto desejado.

2. **Adicione uma Datasource**  
   Vá para **Datasources** e clique em **Add Datasource**.

3. **Escolha o Tipo de Datasource**  
   Selecione o Type do banco de dados: Table ou View.

4. **Encontre sua Datasource na lista**  
   Selecione sua Datasource na lista.

5. **Defina a Snapshot Query**  
   Defina a Snapshot Query. A snapshot query define como *digna* acessará um dia dos seus dados.

6. **Preview**  
   Clique em **Preview** para verificar se a snapshot query foi definida corretamente.

7. **Create datasource**  
   Se tudo estiver configurado corretamente, você pode salvar sua configuração.

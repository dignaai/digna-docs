### Etapas

1. **Abra a seção de Projetos**
   - Na navegação à esquerda, clique em **Projetos**.

2. **Crie um Novo Projeto**
   - Clique no botão **Novo Projeto**.

3. **Insira os Detalhes do Projeto**
   - Forneça um **Nome do Projeto**.  
   - (Opcional) Adicione uma **Descrição** para contexto.

4. **Salve o Projeto**
   - Clique em **Criar** para concluir.  
   - O projeto aparecerá agora na sua **lista de projetos**.

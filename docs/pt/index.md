# *digna* Platform
<h1 style="display:none;">Plataforma orientada por IA para Qualidade e Observabilidade de Dados – digna</h1>

## Plataforma europeia para Qualidade de Dados e Observabilidade de Dados

**digna** é uma **plataforma orientada por IA para Qualidade e Observabilidade de Dados**, projetada para operar inteiramente dentro do seu ambiente — on-premises ou na sua private cloud.  
Ela garante controle contínuo sobre a *qualidade dos dados*, consistência dos dados e entrega oportuna.  

A plataforma **nunca é entregue como SaaS**. A equipe digna **não tem acesso aos dados dos clientes**, garantindo máxima privacidade, segurança e conformidade regulatória.  

---

## Opções de implantação: On-Premises & Private Cloud

- **On-Premises**  
  Instale a digna diretamente na sua infraestrutura — sob controle total do cliente e isolada de serviços externos.  

- **Private Cloud**  
  Execute a digna dentro dos seus ambientes de private ou hybrid cloud (VMs, containers ou Kubernetes). Ela se adapta à sua arquitetura mantendo total soberania dos dados.  

---

## Execução dentro do banco de dados para monitoramento de dados de alto desempenho

*digna* executa todas as lógicas de **verificações de qualidade de dados e detecção de anomalias** **dentro do seu motor de banco de dados**.  
Essa abordagem única minimiza o movimento de dados, aproveita o desempenho nativo e assegura observabilidade dos dados o mais próximo possível da fonte.  

---

## Capacidades principais para monitoramento contínuo e observabilidade

- Rastreamento contínuo de **volumes de dados, distribuições e consistência**  
- Validação automatizada de **regras técnicas e de negócio**  
- Detecção de **entregas de dados ausentes ou atrasadas**  
- Alertas sobre **alterações de esquema ou estrutura**  
- Análise de tendências históricas para **confiabilidade e qualidade de dados** a longo prazo  

---

## Benefícios da abordagem da digna para Qualidade e Observabilidade de Dados

- **Controle Total dos Dados** – os dados nunca saem do seu ambiente  
- **Conformidade por design** – ideal para setores regulados (finanças, saúde, telecom)  
- **Desempenho** – a execução dentro do banco de dados reduz latência e escala com eficiência  
- **Flexibilidade** – mesma plataforma em ambientes on-prem e private cloud  
- **Implantação Rápida** – instalação em poucas horas, atualizações em menos de uma hora

## Integrações com as principais plataformas de dados

*digna* conecta-se perfeitamente com:  

- **Databases & Warehouses:** Teradata, Snowflake, BigQuery, Redshift, Oracle, PostgreSQL, SQL Server, MySQL  
- **Data Lakes / Lakehouses:** Hadoop, Databricks  
- **ETL & Processing Tools:** Spark, Airflow, dbt, Informatica, Talend

## Perguntas Frequentes

**O que é a plataforma digna?**  
Uma solução baseada em IA para melhorar a qualidade dos dados e a observabilidade dos dados, operando completamente dentro do seu próprio ambiente.

**A digna é uma solução SaaS?**  
Não. A digna é instalada on-premises ou na sua private cloud, não sendo entregue como Software as a Service.

**Quais bancos de dados a digna suporta?**  
A digna integra-se com Teradata, Snowflake, Databricks, Oracle, PostgreSQL e muitos outros.

**Por que escolher a digna em vez de ferramentas baseadas em nuvem?**  
Porque combina IA, soberania total dos dados e monitoramento in-database — garantindo pipelines de dados confiáveis e conformidade regulatória.

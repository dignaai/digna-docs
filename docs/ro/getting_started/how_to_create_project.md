### Pași

1. **Deschide secțiunea Proiecte**
   - Din meniul din stânga, dă click pe **Proiecte**.

2. **Creează un proiect nou**
   - Apasă butonul **Proiect nou**.

3. **Completează detaliile proiectului**
   - Introdu un **Nume proiect**.  
   - (Opțional) Adaugă o **Descriere** pentru context.

4. **Salvează proiectul**
   - Apasă **Creează** pentru a finaliza.  
   - Proiectul va apărea acum în **lista ta de proiecte**.

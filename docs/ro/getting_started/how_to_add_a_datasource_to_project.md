### Pași

1. **Open Your Project**  
   Din meniul din stânga, faceți clic pe **Projects** și selectați proiectul țintă.

2. **Add a Datasource**  
   Accesați **Datasources** și faceți clic pe **Add Datasource**.

3. **Choose Datasource Type**  
   Selectați tipul bazei de date: Table sau View.

4. **Find your Datasource on the list**  
   Selectați Datasource-ul din listă.

5. **Define Snapshot Query**  
   Definiți Snapshot Query. Snapshot query define modul în care *digna* va accesa datele pentru o singură zi.

6. **Preview**  
   Faceți clic pe **Preview** pentru a verifica dacă Snapshot Query a fost definită corect.

7. **Create datasource**  
   Dacă totul a fost configurat corect, puteți salva configurația.

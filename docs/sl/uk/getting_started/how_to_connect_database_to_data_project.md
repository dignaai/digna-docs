### Koraki

1. **Odprite svoj projekt**  
   V levi navigaciji kliknite **Projects** in izberite svoj projekt.

2. **Dodajte povezavo**  
   Pojdite v **Connections** in kliknite **Add Connection**.

3. **Izberite tip baze podatkov**  
   Izberite bazo podatkov, na katero se želite povezati (npr. PostgreSQL, MySQL, SQL Server, Oracle, Snowflake, Teradata).

4. **Vnesite parametre povezave**  
   Podajte **Name**, **Host**, **Port**, **Database/Service** in **Credentials** (uporabniško ime/geslo ali SSO, odvisno od primera).

5. **Preveri in shrani**  
   Kliknite **Test**. Če je preverjanje uspešno, kliknite **Save**. Povezava se bo pojavila v razdelku **Connections** za projekt.

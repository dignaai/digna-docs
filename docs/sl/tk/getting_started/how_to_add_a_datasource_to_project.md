### Koraki

1. **Odprite projekt**  
   V levem navigacijskem meniju kliknite **Projekti** in izberite ciljnega projekta.

2. **Dodaj vir podatkov**  
   Pojdite na stran **Podatkovni viri** in kliknite **Dodaj vir podatkov**.

3. **Izberite vrsto vira podatkov**  
   Izberite vrsto baze: tabela ali pogled.

4. **Poiščite svoj vir podatkov na seznamu**  
   Na seznamu izberite svoj vir podatkov.

5. **Opredelite Snapshot Query**  
   Opredelite Snapshot Query. Snapshot Query opiše, kako *digna* dostopa do dnevnega dela vaših podatkov.

6. **Predogled**  
   Kliknite Predogled, da potrdite, ali je Snapshot Query pravilno opredeljen.

7. **Ustvari vir podatkov**  
   Če je vse pravilno konfigurirano, lahko shranite nastavitve.

# Data Anomalies – Samodejno zaznavanje

## Namen
Zaznajte anomalije brez pisanja pravil.

## Tehnične značilnosti
### Analizirane metrike
- Obseg zapisov  
- Manjkajoče vrednosti  
- Porazdelitve in histogrami  
- Razponi vrednosti  
- Edinstvenost  

### Pametno zaznavanje
- Uporablja **učenje iz zgodovinskih podatkov** za dinamično določanje pričakovanih razponov  
- Označi anomalije, ko dejanski podatki zapustijo pričakovane meje  

## Scenariji zaznavanja
- **Padci/piki obsega** → npr. polovica dnevnih transakcij manjka  
- **Zamenjava stolpcev** → npr. stolpca Ime in Priimek sta zamenjana  
- **Nepričakovane vrednosti** → npr. v avstrijskih mestih se pojavi “Zurich”  

## Vrednost
Avtomatizira naloge, ki bi sicer zahtevale na stotine ročnih pravil.

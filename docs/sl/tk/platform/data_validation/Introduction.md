# Data Validation – Preverjanja na podlagi pravil

## Namen
Izvesti deterministična preverjanja na osnovi pravil.

## Tehnične značilnosti
- Podpira:
  - Preverjanje enakosti
  - Pragi in intervali
  - Referenčni seznami / lookup preverjanje
- Zagotavlja **sledljivost in možnost revizije** za skladnost  
- Izvedba pravil se beleži za regulativno poročanje  

## Primeri uporabe
- Preverite, ali so zneski računov v skladu z računovodskimi politikami  
- Zagotovite, da se kode DDV in kode valut ujemajo s predhodno določenimi referenčnimi nabori  
- Preverite pragovne vrednosti za sredstva, utežena glede na tveganje, v okviru regulativnih okvirov  

## Vrednost
Stroga validacija je bistvena v **finančnih, zdravstvenih in reguliranih sektorjih**.

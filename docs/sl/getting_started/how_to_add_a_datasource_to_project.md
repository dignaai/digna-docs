### Koraki

1. **Odprite svoj projekt**  
   V levi navigaciji kliknite **Projects** in izberite ciljni projekt.

2. **Add a Datasource**  
   Pojdite na **Datasources** in kliknite **Add Datasource**.

3. **Izberite tip Datasource**  
   Izberite tip baze: Table ali View.

4. **Poiščite svoj Datasource na seznamu**  
   Izberite svoj Datasource s seznama.

5. **Določite Snapshot Query**  
   Določite Snapshot Query. Snapshot query določa, kako bo *digna* dostopala do enega dne vaših podatkov.

6. **Preview**  
   Kliknite Preview, da preverite, ali je Snapshot Query pravilno definiran.

7. **Create datasource**  
   Če je bila konfiguracija pravilna, lahko shranite nastavitve.

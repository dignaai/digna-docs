### Koraki

1. **Odprite svoj projekt**  
   Iz levega menija kliknite **Projekti** in izberite ciljni projekt.

2. **Dodajte povezavo**  
   Pojdite na **Povezave** in kliknite **Dodaj povezavo**.

3. **Izberite tip baze**  
   Izberite bazo, ki jo želite povezati (npr. PostgreSQL, MySQL, SQL Server, Oracle, Snowflake, Teradata).

4. **Vnesite podatke za povezavo**  
   Izpolnite **Ime**, **Host**, **Port**, **Database/Service**, in **Credentials** (uporabniško ime/geslo ali SSO, odvisno od konfiguracije).

5. **Preizkusite in shranite**  
   Kliknite **Test**. Če je uspešno, kliknite **Shrani**. Povezava se bo prikazala pod **Povezave** za projekt.

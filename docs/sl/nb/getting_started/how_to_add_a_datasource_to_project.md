### Koraki

1. **Odprite svoj projekt**  
   Iz levega menija kliknite **Projects** in izberite ciljni projekt.

2. **Dodajte Datasource**  
   Pojdite na **Datasources** in kliknite **Add Datasource**.

3. **Izberite vrsto Datasource**  
   Izberite tip baze: Table ali View.

4. **Poiščite svoj Datasource na seznamu**  
   Izberite svoj Datasource s seznama.

5. **Določite Snapshot Query**  
   Določite Snapshot Query. Snapshot Query določa, kako bo *digna* dostopala do podatkov za en dan.

6. **Predogled**  
   Kliknite na preview, da preverite, ali je bil Snapshot Query pravilno določen.

7. **Ustvarite datasource**  
   Če je vse pravilno konfigurirano, lahko shranite svojo konfiguracijo.

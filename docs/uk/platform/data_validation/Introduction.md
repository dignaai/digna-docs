# Data Validation – Перевірки на основі правил

## Purpose
Забезпечення виконання детермінованих перевірок на основі правил.

## Technical Features
- Підтримує:
  - Перевірки на рівність
  - Порогові значення та діапазони
  - Довідні списки / перевірка за довідником
- Надає **відстежуваність і можливість аудиту** для забезпечення відповідності  
- Виконання правил реєструється для регуляторної звітності  

## Example Use Cases
- Перевіряти, чи суми рахунків-фактур відповідають бухгалтерській політиці  
- Переконатися, що коди ПДВ і коди валют відповідають заздалегідь визначеним наборам довідників  
- Перевіряти порогові значення для активів з ризиковою вагою відповідно до регуляторних вимог  

## Value
Необхідне у **фінансах, охороні здоров'я та регульованих галузях**, де потрібна сувора валідація.

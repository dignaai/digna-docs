# Data Anomalies – Автоматичне виявлення

## Мета
Виявляйте аномалії без написання правил.

## Технічні можливості
### Аналізовані метрики
- Обсяг записів  
- Пропущені значення  
- Розподіли та гістограми  
- Діапазони значень  
- Унікальність  

### Інтелектуальне виявлення
- Використовує **навчання на історичних даних** для динамічного визначення очікуваних меж  
- Позначає аномалії, коли фактичні дані виходять за межі очікуваних  

## Сценарії виявлення
- **Спади/стрибки обсягу** → наприклад, відсутня половина щоденних транзакцій  
- **Плутанина колонок** → колонки «ім'я» та «прізвище» помінялися місцями  
- **Неочікувані значення** → «Zurich» з’являється в списку австрійських міст  

## Цінність
Автоматизує те, що зазвичай вимагало б сотень ручних правил.

# Data Schema Tracker – Моніторинг еволюції схем

## Мета
Відстежувати та повідомляти про еволюцію схеми.

## Технічні можливості
- Відстежує:
  - Додані або видалені стовпці
  - Зміни типів даних
- Надсилає сповіщення про як умисні, так і ненавмисні зміни схеми  
- Запобігає **тихому дрейфу схеми**, який може зламати ETL-пайплайни або дашборди  

## Приклади використання
- Виявлення змін типів даних (наприклад, `INT` → `VARCHAR`), які можуть спричинити помилки на наступних етапах обробки  
- Повідомлення інженерів даних до того, як пайплайни зупиняться через невідповідність схем  

## Цінність
Дозволяє командам контролювати **швидко еволюціонуючі набори даних**.

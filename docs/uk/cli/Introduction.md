## Призначення інтерфейсу командного рядка (CLI)

Інтерфейс командного рядка (CLI) ***digna*** — потужний інструмент, створений для оптимізації взаємодії з платформою ***digna***. Він надає текстовий інтерфейс, який дозволяє користувачам виконувати широкий спектр завдань ефективно, без потреби в графічному інтерфейсі користувача.

### Ключові можливості:

- **Ефективність і гнучкість:** CLI дозволяє швидко виконувати команди, підвищуючи продуктивність.
- **Автоматизація:** Підтримує скриптування для автоматизації повторюваних завдань.
- **Віддалений доступ:** Керуйте ресурсами ***digna*** з будь-якого місця.
- **Послідовність і надійність:** Забезпечує надійну роботу за допомогою документованих команд з контролем версій.
- **Масштабованість:** Підтримує операції в корпоративних масштабах.
- **Навчання та опанування:** Дає глибше розуміння функціональності ***digna***.
- **Інтеграція з іншими інструментами:** Безшовно інтегрується з інструментами автоматизації, такими як Control-M, UC4, AutomateNOW!

## Інструкція з встановлення для Windows

Щоб почати роботу, виконайте наведені нижче кроки для розпакування необхідних файлів, розгортання папки *dignacli* та налаштування підключення до репозиторію ***digna***. Переконайтесь, що у вас готові облікові дані репозиторію та будь-які необхідні деталі конфігурації перед початком.

1. **Розпакування CLI ***digna***:**
   - Отримайте `.zip` файл, що містить CLI ***digna***.
   - Розпакуйте файл у бажану директорію.

2. **Розгортання папки `dignacli`:**
   - Скопіюйте папку `dignacli` до бажаного місця встановлення (наприклад, `C:\Program Files\***digna***`).

3. **Налаштування `config.toml`:**
   - Перевірте наявність `config.toml` всередині `dignacli`.
   - За потреби перейменуйте `config_template.toml` на `config.toml` та налаштуйте його згідно з наданою документацією.

# Як запланувати щоденне завдання

Планування дозволяє запускати інспекції автоматично без ручного втручання.  
У цьому посібнику ви дізнаєтеся, як створити завдання, яке виконується **раз на день**, що забезпечить безперервний моніторинг ваших даних.

## Чого ви навчитеся

- Як отримати доступ до розділу **Scheduling** у dashboard digna  
- Як створити нове заплановане завдання  
- Як налаштувати його на виконання **щодня в фіксований час**  
- Як вибрати правильний проект та datasource  
- Як увімкнути завдання, щоб воно виконувалося автоматично  

---

## Чому щоденні завдання корисні

Щоденне планування — найпоширеніша конфігурація в продуктивних середовищах. Воно забезпечує:  

- **Freshness** — дані перевіряються щодня.  
- **Consistency** — аномалії виявляються на ранніх етапах, до їхнього поширення далі по ланцюгу обробки.  
- **Automation** — немає потреби вручну запускати інспекції.

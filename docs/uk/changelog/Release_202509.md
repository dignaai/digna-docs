# Журнал змін – Реліз 2025.09  

У релізі 2025.09 digna представляє нову **модульну архітектуру** та запускає **п'ять спеціалізованих модулів** для якості даних та спостережуваності.  
Цей реліз також посилює автентифікацію та покращує обробку сповіщень по всій платформі.  

---

## 🚀 Нові можливості  

### Модульний дизайн  
- digna тепер використовує **модульну архітектуру**.  
- Клієнти можуть вмикати лише ті модулі, які їм потрібні, і додавати інші в міру зростання вимог.  
- Попередня функціональність тепер є частиною **digna Data Anomalies**.  

### Нові модулі  
- **digna Data Anomalies** – AI‑підтримуване виявлення аномалій у обсягах даних, розподілах та відсутніх значеннях.  
- **digna Data Analytics** – оцінка часових рядів показників спостережуваності для виявлення довгострокових трендів та волатильності.  
- **digna Data Timeliness** – моніторинг очікуваних часів надходження даних, як на основі AI, так і за правилами.  
- **digna Data Validation** – перевірки на рівні запису на основі правил для забезпечення відповідності бізнес-правилам.  
- **digna Data Schema Tracker** – виявлення змін схем (зміни DDL) у моніторених базах даних.  

### MFA через OIDC  
- Підтримка **багатофакторної автентифікації (MFA)** через OIDC Single Sign-On.  
- Надає корпоративний рівень безпеки для всіх входів користувачів.  

### Сповіщення електронною поштою по модулю  
- Сповіщення тепер надсилаються **по модулю**, що полегшує розділення тривог від Data Anomalies, Data Analytics та інших модулів.

## 🛠 Оновлення CLI  

- **Нова команда: `inspect-cancel`** – Скасувати інспекції за ідентифікатором запиту або завершити всі активні запити.  
- **Нова команда: `check-config`** – Перевірити файли конфігурації перед стартом.  
- **Нова команда: `remove-orphans`** – Очистити сирітські записи репозиторіїв.  
- **Покращена команда `inspect`** – Нова опція `--bypass-backend` (`-bb`) і стандартизовані коди повернення (`0 = OK, 1 = INFO, 2 = WARNING`).

### Steg

1. **Öppna ditt projekt**  
   I den vänstra navigeringen klickar du på **Projects** och väljer målsprojektet.

2. **Lägg till en Datasource**  
   Gå till **Datasources** och klicka på **Add Datasource**.

3. **Välj typ av Datasource**  
   Välj databasens typ: Table eller View.

4. **Hitta din Datasource i listan**  
   Välj din Datasource från listan.

5. **Definiera Snapshot Query**  
   Definiera Snapshot Query. Snapshot query definierar hur *digna* kommer att läsa en dags data.

6. **Preview**  
   Klicka på **Preview** för att kontrollera att Snapshot Query var definierad korrekt.

7. **Create datasource**  
   Om allt är konfigurerat korrekt kan du spara din konfiguration.

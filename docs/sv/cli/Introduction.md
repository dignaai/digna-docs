## Syfte med kommandoradsgränssnittet (CLI)

***digna*** kommandoradsgränssnitt (CLI) är ett kraftfullt verktyg som är utformat för att förenkla interaktioner med ***digna***-plattformen. Det tillhandahåller ett textbaserat gränssnitt som låter användare utföra ett brett spektrum av uppgifter effektivt, utan behov av ett grafiskt användargränssnitt.

### Viktiga funktioner:

- **Effektivitet och flexibilitet:** CLI:t möjliggör snabb exekvering av kommandon och förbättrar produktiviteten.
- **Automatisering:** Stöder skriptning för att automatisera repetitiva uppgifter.
- **Fjärråtkomst:** Hantera ***digna***-resurser från var som helst.
- **Konsekvens och tillförlitlighet:** Säkerställer tillförlitlig drift med dokumenterade och versionsstyrda kommandon.
- **Skalbarhet:** Hanterar storskaliga operationer för företagsuppgifter.
- **Inlärning och fördjupning:** Ger en djupare förståelse för ***digna***s funktionalitet.
- **Integration med andra verktyg:** Integreras sömlöst med automatiseringsverktyg som Control-M, UC4 och AutomateNOW!

## Installationsanvisningar för Windows

För att komma igång, följ stegen nedan för att extrahera nödvändiga filer, distribuera mappen `dignacli` och konfigurera din anslutning till ***digna*** repository. Se till att du har dina repository-uppgifter och eventuella nödvändiga konfigurationsdetaljer redo innan du börjar.

1. **Extrahera ***digna*** CLI:**
   - Hämta `.zip`-filen som innehåller ***digna*** CLI.
   - Packa upp filen till önskad mapp.

2. **Distribuera mappen `dignacli`:**
   - Kopiera mappen `dignacli` till din föredragna installationsplats (t.ex. `C:\Program Files\***digna***`).

3. **Konfigurera `config.toml`:**
   - Kontrollera om `config.toml` finns i `dignacli`.
   - Byt namn på `config_template.toml` till `config.toml` vid behov och konfigurera den enligt den medföljande dokumentationen.

## Syftet med kommandoradsgränssnittet (CLI)

***digna*** kommandoradsgränssnitt (CLI) är ett kraftfullt verktyg utformat för att förenkla interaktionen med ***digna***-plattformen. Det tillhandahåller ett textbaserat gränssnitt som låter användare utföra en rad uppgifter effektivt, utan behov av ett grafiskt användargränssnitt.

### Viktiga funktioner:

- **Effektivitet och flexibilitet:** CLI möjliggör snabb körning av kommandon, vilket förbättrar produktiviteten.
- **Automatisering:** Stöder skript för att automatisera repetitiva uppgifter.
- **Fjärråtkomst:** Hantera ***digna***-resurser var som helst.
- **Konsistens och tillförlitlighet:** Säkerställer pålitliga operationer med dokumenterade, versionskontrollerade kommandon.
- **Skalbarhet:** Hanterar storskaliga operationer för företagsuppgifter.
- **Lärande och behärskning:** Ger djupare förståelse för funktionaliteten i ***digna***.
- **Integration med andra verktyg:** Integreras sömlöst med automatiseringsverktyg som Control-M, UC4, AutomateNOW!

## Installationsinstruktioner för Windows

För att komma igång, följ stegen nedan för att extrahera nödvändiga filer, distribuera
*dignacli*-mappen och konfigurera din anslutning till ***digna***-repositoryt. Se till att du har
dina inloggningsuppgifter för repositoryt och eventuella nödvändiga konfigurationsdetaljer redo innan du börjar.

1. **Extrahera ***digna*** CLI:**
   - Hämta `.zip`-filen som innehåller ***digna*** CLI.
   - Packa upp filen till önskad mapp.

2. **Distribuera mappen `dignacli`:**
   - Kopiera mappen `dignacli` till din föredragna installationsplats (t.ex. `C:\Program Files\***digna***`).

3. **Konfigurera `config.toml`:**
   - Kontrollera att `config.toml` finns i `dignacli`.
   - Byt namn på `config_template.toml` till `config.toml` vid behov och konfigurera filen enligt den medföljande dokumentationen.

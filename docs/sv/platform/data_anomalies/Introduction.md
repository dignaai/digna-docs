# Data Anomalies – Automatiserad upptäckt

## Syfte
Fånga anomalier utan att skriva regler.

## Tekniska funktioner
### Analyserade mått
- Postvolym  
- Saknade värden  
- Fördelningar & histogram  
- Värdeintervall  
- Unikhet  

### Intelligent detektion
- Använder **historisk inlärning** för att dynamiskt definiera förväntade intervall  
- Flaggar anomalier när verkliga data ligger utanför de förväntade gränserna  

## Detektionsscenarier
- **Volume drops/spikes** → t.ex. hälften av de dagliga transaktionerna saknas  
- **Column swaps** → förnamns- och efternamnskolumnerna omkastade  
- **Unexpected values** → “Zurich” dyker upp bland österrikiska städer  

## Värde
Automatiserar det som normalt skulle kräva hundratals manuella regler.

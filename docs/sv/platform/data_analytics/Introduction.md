# Data Analytics – Trender och stabilitet

## Syfte
Avslöja långsiktiga trender och datastabilitet.

## Tekniska funktioner
### Härledda statistikmått
- Beräknar **trend, volatilitet, säsongsmönster**.

### Stödda mått
- Antal poster  
- Saknade värden  
- Min/max, summor, medelvärden  

### Tidsserieanalys
- Stabilitet över veckor/månader

## Exempel på användningsfall
- Identifiera bästsäljande produkter över en rullande 3-månadersperiod.  
- Upptäck volatilitet i saknade värden för att fånga intermittenta pipelineproblem.  
- Jämför perioder med hög respektive låg stabilitet i KPI:er.  

## Värde
Omvandlar grundläggande statistik till handlingsbara insikter för **affärsövervakning** och **dataoperationer**.

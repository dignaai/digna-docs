### Steps

1. **Open Your Project**  
   From the left navigation, click **Projects** and select the target project.

2. **Add a Datasoource**  
   Go to **Datasources** and click **Add Datasource**.

3. **Choose Datasource Type**  
   Select the database Type: Table or View.

4. **Find your Datasource on the list**  
   Select your Datasource from the list.

5. **Define Snapshot Query**  
   Define Snapshot Query. Snapshot query defines how *digna* will access one day of your data.

6. **Preview**
   CLick preview to verify if the snapshot query was defined correctly.

7. **Create datasource**
   If everything was configured properly, you can save your configuration.

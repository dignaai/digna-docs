### Trin

1. **Åbn dit projekt**  
   Fra venstremenuen skal du klikke på **Projects** og vælge det ønskede projekt.

2. **Tilføj en datasource**  
   Gå til **Datasources** og klik på **Add Datasource**.

3. **Vælg Datasource-type**  
   Vælg database-typen: Table eller View.

4. **Find din datasource på listen**  
   Vælg den relevante datasource fra listen.

5. **Definér Snapshot Query**  
   Definér Snapshot Query. Snapshot query definerer, hvordan *digna* vil få adgang til én dags data.

6. **Forhåndsvisning**  
   Klik på preview for at kontrollere, om snapshot query er defineret korrekt.

7. **Opret datasource**  
   Hvis alt er konfigureret korrekt, kan du gemme din konfiguration.

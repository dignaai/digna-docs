# *digna* Moduler — Teknisk oversigt



*digna* er en AI-drevet platform for datakvalitet og observabilitet.  

Den kører direkte i dit data-miljø og sikrer tillid til dine data uden at kræve kodning af brugerdefinerede regler.



---



## Moduloversigt

| Modul                  | Fokusområde               | Nøglefunktioner |
|--------------------------|--------------------------|------------------|
| **Data Anomalies**      | Automatiseret anomalidetektion | Lærer "normal" adfærd, opdager afvigelser i volumen, fordelinger, værdier |
| **Data Analytics**      | Trends & volatilitet      | Analyserer langsigtede metrikker, stabilitet, ændringsmønstre |
| **Data Validation**     | Regelbaserede kontroller        | Håndhæver præcise værdier, tærskler, intervaller, lister — med revisionsspor |
| **Data Timeliness**     | Leveringsovervågning      | AI-lærte ankomsttider + brugerplaner, opdager forsinkede data |
| **Data Schema Tracker** | Strukturel overvågning    | Registrerer schema drift: nye/fjernede kolonner, ændringer i datatyper |

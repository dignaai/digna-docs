# Data Analytics – Trends og Stabilitet

## Purpose
Afsløre langsigtede trends og datastabilitet.

## Technical Features
### Derived statistics
- Beregner **trend, volatilitet, sæsonalitet**.

### Supported metrics
- Antal poster  
- Manglende værdier  
- Min/max, summer, gennemsnit  

### Time-series analysis
- Stabilitet på tværs af uger/måneder

## Example Use Cases
- Identificer bedst sælgende produkter over en rullende 3-måneders periode.  
- Opdag volatilitet i manglende værdier for at fange intermitterende pipeline-problemer.  
- Sammenlign perioder med høj vs. lav stabilitet i KPI'er.  

## Value
Omsætter grundlæggende statistik til handlingsrettede indsigter for **forretningsovervågning** og **dataoperationer**.

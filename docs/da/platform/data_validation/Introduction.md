# Data Validation – Regelbaserede kontroller

## Formål
Håndhæv deterministiske, regelbaserede kontroller.

## Tekniske funktioner
- Understøtter:
  - Lighedstjek
  - Tærskler og intervaller
  - Referencelister / opslagsvalidering
- Sikrer **sporbarhed og revisionssporbarhed** for overholdelse  
- Regeludførelse logges til regulatorisk rapportering  

## Eksempler på anvendelsestilfælde
- Bekræft, at fakturabeløb overholder regnskabsprincipper  
- Sørg for, at momskoder og valutakoder matcher foruddefinerede referencesæt  
- Valider tærskler for risikovægtede aktiver under regulatoriske rammer  

## Værdi
Væsentlig i **finans, sundhedssektoren og regulerede industrier**, hvor streng validering er påkrævet.

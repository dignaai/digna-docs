# Data Anomalies – Automatisk detektion

## Purpose
Catch anomalies without writing rules.

## Technical Features
### Analyserede metrikker
- Antal poster  
- Manglende værdier  
- Fordelinger & histogrammer  
- Værdiintervaller  
- Unikhed  

### Intelligent detektion
- Bruger **historisk læring** til dynamisk at definere forventede intervaller  
- Marker anomalier, når de faktiske data ligger uden for de forventede grænser  

## Detektionsscenarier
- **Fald/stigninger i volumen** → f.eks. mangler halvdelen af de daglige transaktioner  
- **Kolonneombytninger** → kolonnerne for fornavn og efternavn byttet om  
- **Uventede værdier** → “Zurich” optræder i østrigske byer  

## Værdi
Automatiserer det, som normalt ville kræve hundredevis af manuelle regler.

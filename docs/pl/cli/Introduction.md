## Przeznaczenie interfejsu wiersza poleceń (CLI)

Interfejs wiersza poleceń (CLI) ***digna*** to potężne narzędzie stworzone, aby usprawnić interakcje z platformą ***digna***. Zapewnia interfejs tekstowy, który pozwala użytkownikom wykonywać szeroki zakres zadań efektywnie, bez potrzeby korzystania z graficznego interfejsu użytkownika.

### Kluczowe cechy:

- **Wydajność i elastyczność:** CLI umożliwia szybkie wykonywanie poleceń, zwiększając produktywność.
- **Automatyzacja:** Obsługuje skrypty do automatyzacji powtarzalnych zadań.
- **Dostęp zdalny:** Zarządzaj zasobami ***digna*** z dowolnego miejsca.
- **Spójność i niezawodność:** Zapewnia niezawodne działanie dzięki udokumentowanym, wersjonowanym poleceniom.
- **Skalowalność:** Obsługuje operacje na dużą skalę dla zadań korporacyjnych.
- **Nauka i opanowanie:** Umożliwia głębsze zrozumienie funkcjonalności ***digna***.
- **Integracja z innymi narzędziami:** Bezproblemowo integruje się z narzędziami automatyzacji takimi jak Control-M, UC4, AutomateNOW!

## Instrukcja instalacji dla systemu Windows

Aby rozpocząć, wykonaj poniższe kroki, aby rozpakować niezbędne pliki, wdrożyć folder *dignacli* i skonfigurować połączenie z repozytorium ***digna***. Upewnij się, że masz przygotowane poświadczenia do repozytorium oraz wszelkie wymagane szczegóły konfiguracyjne przed rozpoczęciem.

1. **Rozpakowywanie CLI ***digna***:**
   - Pobierz plik `.zip` zawierający CLI ***digna***.
   - Rozpakuj plik do wybranego katalogu.

2. **Wdrożenie folderu `dignacli`:**
   - Skopiuj folder `dignacli` do wybranej lokalizacji instalacyjnej (np. `C:\Program Files\***digna***`).

3. **Konfiguracja `config.toml`:**
   - Sprawdź, czy w `dignacli` znajduje się plik `config.toml`.
   - W razie potrzeby zmień nazwę `config_template.toml` na `config.toml` i skonfiguruj go, korzystając z udostępnionej dokumentacji.

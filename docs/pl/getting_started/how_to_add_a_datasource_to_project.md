### Kroki

1. **Open Your Project**  
   W lewej nawigacji kliknij **Projects** i wybierz docelowy projekt.

2. **Add a Datasoource**  
   Przejdź do **Datasources** i kliknij **Add Datasource**.

3. **Choose Datasource Type**  
   Wybierz typ bazy danych: Table lub View.

4. **Find your Datasource on the list**  
   Wybierz swoje Datasource z listy.

5. **Define Snapshot Query**  
   Zdefiniuj Snapshot Query. Snapshot Query określa, w jaki sposób *digna* uzyska dostęp do jednego dnia Twoich danych.

6. **Preview**  
   Kliknij **Preview**, aby sprawdzić, czy Snapshot Query zostało poprawnie zdefiniowane.

7. **Create datasource**  
   Jeśli wszystko zostało poprawnie skonfigurowane, możesz zapisać swoją konfigurację.

### Kroki

1. **Otwórz swój projekt**  
   W lewym menu kliknij **Projects** i wybierz docelowy projekt.

2. **Add a Datasource**  
   Przejdź do **Datasources** i kliknij **Add Datasource**.

3. **Wybierz typ Datasource**  
   Wybierz typ bazy danych: Table lub View.

4. **Znajdź swój Datasource na liście**  
   Wybierz swój Datasource z listy.

5. **Zdefiniuj Snapshot Query**  
   Zdefiniuj Snapshot Query. Snapshot query określa, jak *digna* uzyska dostęp do jednego dnia twoich danych.

6. **Preview**  
   Kliknij Preview, aby sprawdzić, czy zapytanie Snapshot Query zostało zdefiniowane poprawnie.

7. **Create datasource**  
   Jeśli wszystko zostało poprawnie skonfigurowane, możesz zapisać konfigurację.

### Soļi

1. **Open Your Project**  
   No kreisās navigācijas noklikšķiniet uz **Projects** un izvēlieties attiecīgo projektu.

2. **Add a Connection**  
   Dodieties uz **Connections** un noklikšķiniet uz **Add Connection**.

3. **Choose Database Type**  
   Izvēlieties datubāzi, kuru vēlaties savienot (piem., PostgreSQL, MySQL, SQL Server, Oracle, Snowflake, Teradata).

4. **Enter Connection Details**  
   Norādiet **Name**, **Host**, **Port**, **Database/Service**, un **Credentials** (lietotājvārds/parole vai SSO, ja piemērojams).

5. **Test & Save**  
   Noklikšķiniet uz **Test**. Ja tests ir veiksmīgs, noklikšķiniet uz **Save**. Savienojums parādīsies sadaļā **Connections** attiecīgajam projektam.

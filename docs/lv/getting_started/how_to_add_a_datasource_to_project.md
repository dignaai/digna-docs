### Soļi

1. **Atveriet savu projektu**  
   Kreisajā navigācijā noklikšķiniet uz **Projects** un izvēlieties mērķa projektu.

2. **Pievienot datu avotu**  
   Dodieties uz **Datasources** un noklikšķiniet uz **Add Datasource**.

3. **Izvēlieties datu avota tipu**  
   Izvēlieties datu avota tipu: **Table** vai **View**.

4. **Atrodiet savu datu avotu sarakstā**  
   Atlasiet savu datu avotu no saraksta.

5. **Definējiet Snapshot Query**  
   Definējiet **Snapshot Query**. Snapshot Query nosaka, kā *digna* piekļūs vienas dienas datiem.

6. **Preview**  
   Noklikšķiniet uz **Preview**, lai pārbaudītu, vai Snapshot Query ir definēts pareizi.

7. **Create datasource**  
   Ja viss ir konfigurēts pareizi, varat saglabāt konfigurāciju.

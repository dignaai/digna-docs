# *digna* moduļi — Tehniskais pārskats



*digna* ir ar mākslīgo intelektu darbināta **datu kvalitātes un novērošanas platforma**.  

Tas darbojas tieši jūsu datu vidē un nodrošina uzticību jūsu datiem, neprasot pielāgotu noteikumu kodēšanu.



---



## Moduļu kopsavilkums

| Module                  | Fokuss                   | Galvenās iespējas |
|--------------------------|--------------------------|------------------|
| **Data Anomalies**      | Automātiska anomāliju noteikšana | Mācās “parastu” uzvedību, atklāj novirzes apjomā, sadalījumos, vērtībās |
| **Data Analytics**      | Tendences un svārstīgums | Analizē ilgtermiņa metriku, stabilitāti, izmaiņu modeļus |
| **Data Validation**     | Uz noteikumiem balstītas pārbaudes | Nodrošina precīzas vērtības, sliekšņus, diapazonus, sarakstus — ar audita žurnālu |
| **Data Timeliness**     | Piegādes uzraudzība      | Mākslīgā intelekta mācīti ierašanās laiki + lietotāju grafiki, atklāj novēlotus datus |
| **Data Schema Tracker** | Strukturālā uzraudzība    | Atklāj shēmas nobīdi: jaunas/noņemtas kolonnas, datu tipu izmaiņas |

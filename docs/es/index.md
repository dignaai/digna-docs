# Plataforma *digna*

**digna** es una plataforma para **Calidad de Datos** y **Observabilidad de Datos**, diseñada para ejecutarse completamente dentro del entorno del cliente.  

Nunca se entrega como Software como Servicio — el equipo de *digna* no tiene acceso a los datos del cliente.  
Esto garantiza la máxima privacidad, seguridad y cumplimiento.  

---

## Opciones de implementación

- **On-Premises**  
  *digna* puede instalarse directamente en la propia infraestructura del cliente, totalmente bajo su control.  

- **Private Cloud**  
  Se ejecuta en los entornos de nube privada o híbrida del cliente (VMs, contenedores o Kubernetes).  
  La plataforma se adapta a la estrategia de nube existente sin requerir servicios externos.  


---

## Ejecución en la base de datos

*digna* ejecuta comprobaciones y lógica de detección de anomalías **directamente dentro del motor de base de datos**.  
Este enfoque reduce el movimiento de datos, aprovecha el rendimiento nativo de la base de datos y garantiza que la supervisión ocurra lo más cerca posible de los datos.  

---

## Capacidades clave

- Monitoreo continuo de volúmenes de datos, distribuciones y consistencia  
- Validación automatizada de reglas de negocio y técnicas  
- Detección de entregas de datos tardías o faltantes  
- Alertas sobre cambios estructurales en tablas o vistas  
- Análisis de tendencias históricas en la calidad y fiabilidad de los datos  

---

## Beneficios

- **Control total de datos** – solo en el entorno del cliente, sin acceso externo  
- **Cumplimiento por diseño** – apropiado para industrias reguladas con políticas de datos estrictas  
- **Rendimiento** – la ejecución en la base de datos reduce la sobrecarga y escala de forma eficiente  
- **Flexibilidad** – misma plataforma para entornos on-prem y private cloud  
- **Despliegue rápido** – instalación en horas, actualizaciones en menos de una hora  

---

## Integraciones

*digna* se conecta a:  

- **Bases de datos y Data Warehouses**: Teradata, Snowflake, BigQuery, Redshift, Oracle, PostgreSQL, SQL Server, MySQL  
- **Data Lakes / Lakehouses**: Hadoop, Databricks 
- **ETL y procesamiento**: Spark, Airflow, dbt, Informatica, Talend

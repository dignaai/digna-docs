# Plataforma *digna*

**digna** es una plataforma para **Data Quality** y **Data Observability**, diseñada para ejecutarse completamente dentro del entorno del cliente.  

Nunca se entrega como Software as a Service — el equipo de *digna* no tiene acceso a los datos de los clientes.  
Esto garantiza máxima privacidad, seguridad y cumplimiento normativo.  

---

## Opciones de implementación

- **On-Premises**  
  *digna* puede instalarse directamente en la infraestructura del cliente, completamente bajo su control.  

- **Private Cloud**  
  Se ejecuta en los entornos de nube privada o híbrida del cliente (VMs, contenedores o Kubernetes).  
  La plataforma se adapta a la estrategia de nube existente sin requerir servicios externos.  


---

## Ejecución en la base de datos

*digna* ejecuta comprobaciones y lógica de detección de anomalías **directamente dentro del motor de la base de datos**.  
Este enfoque reduce el movimiento de datos, aprovecha el rendimiento nativo del motor y garantiza que el monitoreo se realice lo más cerca posible de los datos.  

---

## Capacidades clave

- Monitoreo continuo de volúmenes de datos, distribuciones y consistencia  
- Validación automatizada de reglas de negocio y técnicas  
- Detección de entregas de datos retrasadas o faltantes  
- Alertas sobre cambios estructurales en tablas o vistas  
- Análisis de tendencias históricas en calidad y confiabilidad de los datos  

---

## Beneficios

- **Full Data Control** – solo entorno del cliente, sin acceso externo  
- **Compliance by Design** – diseñado para industrias reguladas con políticas de datos estrictas  
- **Performance** – la ejecución en la base de datos reduce la sobrecarga y escala de forma eficiente  
- **Flexibility** – la misma plataforma en entornos on-prem y private cloud  
- **Fast Deployment** – instalación en pocas horas, actualizaciones en menos de una hora  

---

## Integraciones

*digna* se conecta a:  

- **Databases & Warehouses**: Teradata, Snowflake, BigQuery, Redshift, Oracle, PostgreSQL, SQL Server, MySQL  
- **Data Lakes / Lakehouses**: Hadoop, Databricks 
- **ETL & Processing**: Spark, Airflow, dbt, Informatica, Talend

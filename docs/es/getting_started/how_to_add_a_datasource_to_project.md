### Pasos

1. **Abra su proyecto**  
   En la navegación izquierda, haga clic en **Projects** y seleccione el proyecto objetivo.

2. **Agregar un Datasoource**  
   Vaya a **Datasources** y haga clic en **Add Datasource**.

3. **Elija el tipo de Datasource**  
   Seleccione el Type de base de datos: Table o View.

4. **Encuentre su Datasource en la lista**  
   Seleccione su Datasource de la lista.

5. **Defina Snapshot Query**  
   Defina Snapshot Query. La Snapshot Query define cómo *digna* accederá a un día de sus datos.

6. **Preview**  
   Haga clic en **Preview** para verificar si la Snapshot Query se definió correctamente.

7. **Crear datasource**  
   Si todo se configuró correctamente, puede guardar su configuración.

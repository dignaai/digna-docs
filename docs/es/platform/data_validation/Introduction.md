# Data Validation – Comprobaciones basadas en reglas

## Propósito
Aplicar comprobaciones deterministas basadas en reglas.

## Características técnicas
- Admite:
  - Comprobaciones de igualdad
  - Umbrales y rangos
  - Listas de referencia / validación por búsqueda
- Proporciona **trazabilidad & auditabilidad** para cumplimiento  
- La ejecución de las reglas se registra para informes regulatorios  

## Casos de uso ejemplares
- Verificar que los importes de las facturas cumplan las políticas contables  
- Asegurar que los códigos de IVA y los códigos de moneda coincidan con conjuntos de referencia predefinidos  
- Validar umbrales para activos ponderados por riesgo según marcos regulatorios  

## Valor
Esencial en **finanzas, salud y sectores regulados** donde se requiere una validación estricta.

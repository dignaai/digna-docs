### Vaiheet

1. **Avaa projektiosio**
   - Vasemmasta navigaatiosta valitse **Projektit**.

2. **Luo uusi projekti**
   - Klikkaa **Uusi projekti** -painiketta.

3. **Anna projektin tiedot**
   - Anna **Projektin nimi**.  
   - (Valinnainen) Lisää **Kuvaus** kontekstin antamiseksi.

4. **Tallenna projekti**
   - Klikkaa **Luo** viimeistelläksesi.  
   - Projekti näkyy nyt **projektien luettelossasi**.

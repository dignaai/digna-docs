### Steg

1. **Öppna projektavsnittet**
   - Från vänstermenyn, klicka på **Projekt**.

2. **Skapa ett nytt projekt**
   - Klicka på knappen **Nytt projekt**.

3. **Ange projektdetaljer**
   - Ange ett **Projektnamn**.  
   - (Valfritt) Lägg till en **Beskrivning** för kontext.

4. **Spara projektet**
   - Klicka på **Skapa** för att slutföra.  
   - Projektet kommer nu att visas i din **projektlista**.

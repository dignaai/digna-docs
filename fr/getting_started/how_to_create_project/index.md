### Étapes

1. **Ouvrir la section Projets**
   - Dans la navigation de gauche, cliquez sur **Projects**.

2. **Créer un nouveau projet**
   - Cliquez sur le bouton **New Project**.

3. **Saisir les détails du projet**
   - Fournissez un **Project Name**.  
   - (Facultatif) Ajoutez une **Description** pour le contexte.

4. **Enregistrer le projet**
   - Cliquez sur **Create** pour terminer.  
   - Le projet apparaîtra désormais dans votre **Projects list**.

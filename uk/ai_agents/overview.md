# Підключення ШІ-агентів до digna

**digna MCP Server** дає змогу ШІ-агентам працювати з *digna* через
[Model Context Protocol](https://modelcontextprotocol.io) (MCP) — відкритий стандарт, який
підтримують Claude, Gemini та багато інших ШІ-інструментів. Агент, підключений до *digna*, може
відповідати на запитання про ваші дані, розслідувати сповіщення та допомагати налаштовувати *digna*.
Що саме вміють агенти, описано в [digna Agentic](../platform/agentic/Introduction.md).

Ця сторінка описує бік *digna*, однаковий для всіх ШІ-клієнтів. Посібники для клієнтів далі
показують, куди ці дані ввести:

- [Claude](claude_mcp_guide.md): Claude Code, Claude Desktop і власні конектори
- [Gemini](gemini_mcp_guide.md): Antigravity і Gemini CLI

!!! info "Бета-версія"

    digna Agentic, а разом з ним і digna MCP Server, постачається як бета-версія у
    [Release 2026.11](../changelog/Release_202611.md).

---

## Перш ніж почати {: #before-you-start }

Вам потрібні:

- *digna* Release 2026.11 або новіший
- Ліцензія, що включає **digna Agentic**. Без неї сервер MCP відхиляє кожен запит
- Обліковий запис користувача *digna*. Агент діє з правами цього користувача в кожному проєкті,
  див. [Дозволи](../platform/agentic/how_it_works.md#permissions)
- ШІ-клієнт, який підключається до віддалених серверів MCP через **streamable HTTP** і може
  надсилати заголовок `Authorization`

---

## 1. Знайдіть кінцеву точку MCP {: #1-find-the-mcp-endpoint }

Сервер MCP є частиною бекенду *digna*, тож нічого додатково встановлювати чи запускати не
потрібно. Його кінцева точка — це адреса бекенду, до якої додано `/mcp`:

```text
https://digna.example.com/mcp
```

Якщо бекенд працює безпосередньо на хості й порту, наприклад після
`digna serve --address 0.0.0.0 --port 8082`, кінцева точка — це ця адреса з `/mcp`:

```text
http://digna-host:8082/mcp
```

Якщо перед бекендом стоїть зворотний проксі, він має пересилати `/mcp` до бекенду разом із
заголовком `Authorization`.

!!! warning "Використовуйте HTTPS у мережі"

    Кожен запит містить ключ API. Використовуйте HTTPS завжди, коли ШІ-клієнт і *digna* працюють
    не на одній машині.

### Звідки надходить підключення {: #where-the-connection-comes-from }

Більшість ШІ-клієнтів підключаються з машини, на якій вони працюють: Claude Code, Claude Desktop
з локальним мостом, Antigravity і Gemini CLI. Для них *digna* має бути доступна лише з цієї
машини, наприклад у межах корпоративної мережі.

**Власні конектори** Claude працюють інакше: до кінцевої точки підключається хмара Anthropic.
Вони працюють лише тоді, коли кінцева точка доступна з інтернету через HTTPS. Для інсталяції
*digna*, доступної лише у вашій мережі, використовуйте клієнт, що працює на вашій машині.

## 2. Створіть ключ API {: #2-create-an-api-key }

ШІ-клієнт автентифікується за допомогою ключа API користувача *digna*.

1. Увійдіть до *digna*.
2. Відкрийте свій профіль користувача в лівому нижньому куті.
3. Натисніть **API Keys**, потім **Add API Key**.
4. Введіть назву, яка пояснює призначення ключа, наприклад *Claude Code – Marcin*, і виберіть,
   коли закінчується термін його дії.
5. Скопіюйте ключ. Він відображається лише один раз.

Кожен запит до сервера MCP передає ключ у такому заголовку:

```text
Authorization: Bearer <api key>
```

Слово `Bearer` і пробіл після нього є частиною значення заголовка.

## 3. Підключіть свій ШІ-клієнт {: #3-connect-your-ai-client }

| ШІ-клієнт | Звідки підключається | Посібник |
|---|---|---|
| Claude Code | Ваша машина | [Claude](claude_mcp_guide.md#claude-code) |
| Claude Desktop з локальним мостом | Ваша машина | [Claude](claude_mcp_guide.md#claude-desktop-with-a-local-bridge) |
| Власний конектор Claude (claude.ai, Claude Desktop, Claude mobile) | Хмара Anthropic | [Claude](claude_mcp_guide.md#custom-connector) |
| Antigravity CLI, IDE і застосунок | Ваша машина | [Gemini](gemini_mcp_guide.md#antigravity) |
| Gemini CLI | Ваша машина | [Gemini](gemini_mcp_guide.md#gemini-cli) |

Інші клієнти MCP також працюють, якщо підтримують віддалені сервери через streamable HTTP із
власним заголовком. Більшість із них читає конфігурацію на зразок цієї. Точні назви файлу та
ключів дивіться в документації свого клієнта:

```json
{
  "mcpServers": {
    "digna": {
      "type": "http",
      "url": "https://digna.example.com/mcp",
      "headers": {
        "Authorization": "Bearer <api key>"
      }
    }
  }
}
```

## 4. Перевірте {: #4-try-it }

Запитайте агента про те, на що може відповісти лише *digna*:

- *"Покажи список моїх проєктів у digna."*
- *"Які джерела даних у проєкті X сьогодні не зелені?"*
- *"Поясни останню невдалу перевірку джерела даних Y."*

Якщо агент показує ваші проєкти, підключення працює.

## Безпека {: #security }

- **Один ключ на кожну людину й кожен клієнт.** Тоді можна відкликати окремий ключ за допомогою
  **Delete API Key**, не зачіпаючи нікого іншого.
- **Обирайте користувача свідомо.** Агент може робити все, що може робити користувач ключа. Лише
  для дослідження даних використовуйте користувача з роллю читача в проєктах.
- **Не зберігайте ключі в спільних файлах.** Не комітьте файл конфігурації, що містить ключ. Якщо
  клієнт це підтримує, читайте ключ зі змінної середовища.
- **Встановлюйте термін дії.** Створіть новий ключ до того, як мине термін дії старого, і оновіть
  клієнт.
- **Перевіряйте виклики інструментів.** Не вимикайте в клієнті підтвердження викликів
  інструментів, принаймні для викликів, які змінюють конфігурацію.

## Усунення несправностей {: #troubleshooting }

### 401 Unauthorized

Відповідь пояснює причину:

| Повідомлення | Причина |
|---|---|
| `Missing or malformed Authorization header` | Заголовок не надіслано, або значення не починається з `Bearer ` |
| `Invalid API key` | Ключ неправильний або його видалено |
| `API key expired` | Термін дії ключа минув. Створіть новий |

### 403 Forbidden: `The license does not include the agentic (MCP) feature`

Ліцензія *digna* не містить запису digna Agentic, або термін дії цього запису минув. Попросіть
команду digna надати ліцензію, що включає digna Agentic, і встановіть її, як описано в посібнику
зі встановлення для вашої операційної системи.

### Кожен запит завершується помилкою недійсної ліцензії

Минув термін дії самої ліцензії *digna*. Сервер MCP перестає відповідати разом із дашбордом, доки
не буде встановлено нову ліцензію.

### Агент може читати, але не змінювати конфігурацію

Користувач, якому належить ключ API, не має ролі редактора в цьому проєкті. Використовуйте ключ
користувача з роллю редактора або попросіть адміністратора проєкту змінити роль.

### Клієнт узагалі не може підключитися

Машина, що підключається, не може досягти кінцевої точки. Відкрийте адресу кінцевої точки з цієї
машини та перевірте брандмауери, проксі та сертифікат. Для власного конектора Claude ця машина
розташована в хмарі Anthropic, див. [Звідки надходить підключення](#where-the-connection-comes-from).

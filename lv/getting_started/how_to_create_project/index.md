### Soļi

1. **Atveriet projekta sadaļu**
   - Kreisajā navigācijas joslā noklikšķiniet uz **Projekti**.

2. **Izveidojiet jaunu projektu**
   - Noklikšķiniet uz pogas **Jauns projekts**.

3. **Ievadiet projekta detaļas**
   - Norādiet **projekta nosaukumu**.  
   - (Neobligāti) Pievienojiet **Aprakstu**, lai sniegtu kontekstu.

4. **Saglabājiet projektu**
   - Noklikšķiniet uz **Izveidot**, lai pabeigtu.  
   - Projekts tagad parādīsies jūsu **Projektu sarakstā**.

    digna CLI Reference 2026.01¶

    2026-01-15

    Αυτή η σελίδα τεκμηριώνει το πλήρες σύνολο εντολών που είναι διαθέσιμες στην έκδοση digna CLI 2026.01, συμπεριλαμβανομένων παραδειγμάτων χρήσης και επιλογών.

    CLI Basics¶

    help¶

    Η επιλογή --help παρέχει πληροφορίες σχετικά με τις διαθέσιμες εντολές και τη χρήση τους. Υπάρχουν δύο βασικοί τρόποι χρήσης αυτής της επιλογής:

    1. Εμφάνιση Γενικής Βοήθειας:

      Χρησιμοποιήστε –help αμέσως μετά την λέξη-κλειδί dignacl

      dignacli --help

    2. Λήψη Βοήθειας για Συγκεκριμένες Εντολές:

      Για λεπτομερείς πληροφορίες σχετικά με μια συγκεκριμένη εντολή, προσθέστε --help σε αυτήν την εντολή.
      Για παράδειγμα, για να λάβετε βοήθεια για την εντολή add-user, εκτελέστε: 

      dignacli add-user --help

      ### output:

      • Περιγραφή Εντολής: Παρέχει λεπτομερή περιγραφή του τι κάνει η εντολή.
      • Σύνταξη: Εμφανίζει την ακριβή σύνταξη, συμπεριλαμβανομένων των υποχρεωτικών και προαιρετικών ορισμάτων.
      • Επιλογές: Λίστα με τις επιλογές που σχετίζονται με την εντολή, μαζί με τις εξηγήσεις τους.
      • Παραδείγματα: Παρέχει παραδείγματα για το πώς να εκτελέσετε την εντολή αποτελεσματικά.

    check-config¶

    Η εντολή check-config είναι ένα βοηθητικό εργαλείο μέσα στο digna CLI σχεδιασμένο για να ελέγχει τη διαμόρφωση του digna. Αυτή η εντολή διασφαλίζει ότι τα συστατικά του digna μπορούν να βρουν τα απαιτούμενα στοιχεία διαμόρφωσης στο config.toml.

    Options¶

    • --configpath, -cp: Αρχείο ή φάκελος που περιέχει τη ρύθμιση. Εάν παραλειφθεί, θα χρησιμοποιηθεί το ../config.toml.

    Command Usage¶

    dignacli check-config

    Μετά από επιτυχή εκτέλεση, η εντολή εμφανίζει μια επιβεβαίωση της πληρότητας της διαμόρφωσης.

    Εάν η διαμόρφωση φαίνεται ελλιπής, θα παρατεθούν τα ελλείποντα στοιχεία διαμόρφωσης.

    check-repo-connection¶

    Η εντολή check-repo-connection είναι ένα βοηθητικό εργαλείο μέσα στο digna CLI σχεδιασμένο για να ελέγχει τη συνδεσιμότητα και την πρόσβαση σε ένα συγκεκριμένο αποθετήριο του digna. Αυτή η εντολή διασφαλίζει ότι το CLI μπορεί να αλληλεπιδράσει με το αποθετήριο.

    Command Usage¶

    dignacli check-repo-connection

    Μετά από επιτυχή εκτέλεση, η εντολή εμφανίζει επιβεβαίωση της σύνδεσης, μαζί με λεπτομέρειες για το αποθετήριο: Έκδοση αποθετηρίου, Host, Database και Schema.

    Εάν η σύνδεση με το αποθετήριο δεν είναι επιτυχής, ελέγξτε το αρχείο config.toml για σωστές ρυθμίσεις.

    version¶

    Για να ελέγξετε την εγκατεστημένη έκδοση του dignacli, χρησιμοποιήστε την επιλογή --version.

    Command Usage¶

    dignacli --version

    Example Output¶

    dignacli version 2026.01

    logging options¶

    Εξ ορισμού, η έξοδος στην κονσόλα των εντολών του digna έχει σχεδιαστεί να είναι λιτή. Οι περισσότερες εντολές προσφέρουν τη δυνατότητα παροχής επιπλέον πληροφοριών, χρησιμοποιώντας τις ακόλουθες επιλογές:

    -- verbose (-v)
    -- debug (-d)
    -- logfile (lf)

    Οι επιλογές “verbose” και “debug” καθορίζουν το επίπεδο λεπτομέρειας, ενώ η εναλλαγή “logfile” επιτρέπει την ανακατεύθυνση της εξόδου ώστε να εγγράφεται σε αρχείο αντί για το παράθυρο της κονσόλας.

    User Management¶

    add-user¶

    Η εντολή add-user στο digna CLI χρησιμοποιείται για την προσθήκη νέου χρήστη στο σύστημα του digna.

    Command Usage¶

    dignacli add-user [OPTIONS] USER_NAME USER_FULL_NAME USER_PASSWORD

    Arguments¶

    • USER_NAME: Το όνομα χρήστη για τον νέο χρήστη (υποχρεωτικό).
    • USER_FULL_NAME: Το πλήρες όνομα του νέου χρήστη (υποχρεωτικό).
    • USER_PASSWORD: Ο κωδικός πρόσβασης για τον νέο χρήστη (υποχρεωτικό).

    Options¶

    • --is_superuser, -su: Σημάδι για να οριστεί ο νέος χρήστης ως διαχειριστής.
    • --valid_until, -vu: Ορίζει ημερομηνία λήξης για το λογαριασμό χρήστη με μορφή YYYY-MM-DD HH:MI:SS. Εάν δεν οριστεί, ο λογαριασμός δεν έχει ημερομηνία λήξης.

    Example¶

    Για να προσθέσετε νέο χρήστη με όνομα jdoe, πλήρες όνομα John Doe και κωδικό password123:

    dignacli add-user [OPTIONS] USER_NAME USER_FULL_NAME USER_PASSWORD

    Για να προσθέσετε νέο χρήστη και να ορίσετε ημερομηνία λήξης λογαριασμού: 

    dignacli add-user jdoe "John Doe" password123 --valid_until "2024-12-31 23:59:59"

    delete-user¶

    Η εντολή delete-user στο digna CLI χρησιμοποιείται για την αφαίρεση ενός υπάρχοντος χρήστη από το σύστημα του digna.

    Command Usage¶

    dignacli delete-user USER_NAME

    Arguments¶

    • USER_NAME: Το όνομα χρήστη του χρήστη που θα διαγραφεί (υποχρεωτικό). Αυτό είναι το μόνο απαιτούμενο όρισμα της εντολής.

    Example¶

    dignacli delete-user jdoe

    Η εκτέλεση αυτής της εντολής θα αφαιρέσει τον χρήστη jdoe από το σύστημα του digna, ανακαλώντας την πρόσβασή του και διαγράφοντας τα συσχετιζόμενα δεδομένα και δικαιώματά του από το αποθετήριο.

    modify-user¶

    Η εντολή modify-user στο digna CLI χρησιμοποιείται για την ενημέρωση των στοιχείων ενός υπάρχοντος χρήστη στο σύστημα του digna.

    Command Usage¶

    dignacli modify-user <USER_NAME> <USER_FULL_NAME> [options]

    Arguments¶

    • USER_NAME: Το όνομα χρήστη του χρήστη που θα τροποποιηθεί (υποχρεωτικό).
    • USER_FULL_NAME: Το νέο πλήρες όνομα για τον χρήστη (υποχρεωτικό).

    Options¶

    • --is_superuser, -su: Ορίζει τον χρήστη ως superuser, χορηγώντας αυξημένα προνόμια. Αυτή η σημαία δεν απαιτεί τιμή.
    • --valid_until, -vu: Ορίζει ημερομηνία λήξης για το λογαριασμό χρήστη στη μορφή YYYY-MM-DD HH:MI:SS. Εάν δεν παρέχεται, ο λογαριασμός παραμένει έγκυρος επ’ αόριστον.

    Example¶

    Για να τροποποιήσετε το πλήρες όνομα του χρήστη jdoe σε “Johnathan Doe” και να ορίσετε τον χρήστη ως superuser: 

    dignacli modify-user jdoe "Johnathan Doe" --is_superuser

    modify-user-pwd¶

    Η εντολή modify-user-pwd στο digna CLI χρησιμοποιείται για την αλλαγή του κωδικού πρόσβασης ενός υπάρχοντος χρήστη στο σύστημα του digna.

    Command Usage¶

    dignacli modify-user-pwd <USER_NAME> <USER_PWD>

    Arguments¶

    • USER_NAME: Το όνομα χρήστη του χρήστη του οποίου ο κωδικός πρόκειται να αλλάξει (υποχρεωτικό).
    • USER_PWD: Ο νέος κωδικός πρόσβασης για τον χρήστη (υποχρεωτικό).

    Example¶

    Για να αλλάξετε τον κωδικό του χρήστη jdoe σε newpassword123: 

    dignacli modify-user-pwd jdoe newpassword123

    list-users¶

    Η εντολή list-users στο digna CLI εμφανίζει λίστα με όλους τους χρήστες που είναι καταχωρημένοι στο σύστημα του digna.

    Command Usage¶

    dignacli list-users

    Η εκτέλεση αυτής της εντολής στο digna CLI θα συνδεθεί με το αποθετήριο του digna και θα εμφανίσει όλους τους χρήστες, δείχνοντας το ID τους, το όνομα χρήστη, το πλήρες όνομα, την κατάσταση superuser και τους χρονικούς δείκτες λήξης.

    Repository Management¶

    upgrade-repo¶

    Η εντολή upgrade-repo στο digna CLI χρησιμοποιείται για την αναβάθμιση ή αρχικοποίηση του αποθετηρίου του digna. Αυτή η εντολή είναι απαραίτητη για την εφαρμογή ενημερώσεων ή τη ρύθμιση της υποδομής του αποθετηρίου για πρώτη φορά.

    Command Usage¶

    dignacli upgrade-repo [options]

    Options¶

    • --simulation-mode, -s: Όταν είναι ενεργοποιημένο, αυτή η επιλογή εκτελεί την εντολή σε λειτουργία προσομοίωσης, εκτυπώνοντας τις δηλώσεις SQL που θα εκτελούνταν αλλά χωρίς να τις εφαρμόζει πραγματικά. Είναι χρήσιμη για προεπισκόπηση αλλαγών χωρίς να γίνονται τροποποιήσεις στο αποθετήριο.

    Example¶

    Για να αναβαθμίσετε το αποθετήριο του digna, μπορείτε να εκτελέσετε την εντολή χωρίς επιλογές:

    dignacli upgrade-repo
    Για να εκτελέσετε την αναβάθμιση σε λειτουργία προσομοίωσης (για να δείτε τις δηλώσεις SQL χωρίς να τις εφαρμόσετε):

    dignacli upgrade-repo --simulation-mode

    Αυτή η εντολή είναι κρίσιμη για τη συντήρηση του συστήματος digna, διασφαλίζοντας ότι το σχήμα της βάσης δεδομένων και τα άλλα συστατικά του αποθετηρίου είναι ενημερωμένα με την τελευταία έκδοση του λογισμικού.

    encrypt¶

    Η εντολή encrypt στο digna CLI χρησιμοποιείται για την κρυπτογράφηση ενός κωδικού πρόσβασης.

    Command Usage¶

    dignacli encrypt <PASSWORD>

    Arguments¶

    • PASSWORD: Ο κωδικός που χρειάζεται να κρυπτογραφηθεί (υποχρεωτικό).

    Example¶

    Για να κρυπτογραφήσετε έναν κωδικό, πρέπει να παρέχετε τον κωδικό ως όρισμα.
    Για παράδειγμα, για να κρυπτογραφήσετε τον κωδικό mypassword123, θα χρησιμοποιούσατε: 

    dignacli encrypt mypassword123
    Αυτή η εντολή εξάγει την κρυπτογραφημένη μορφή του παρεχόμενου κωδικού, η οποία μπορεί στη συνέχεια να χρησιμοποιηθεί σε ασφαλείς περιβάλλοντες. Εάν το όρισμα του κωδικού δεν παρέχεται, το CLI θα εμφανίσει σφάλμα που υποδεικνύει το ελλείπον όρισμα.

    generate-key¶

    Η εντολή generate-key χρησιμοποιείται για τη δημιουργία ενός Fernet key, το οποίο είναι απαραίτητο για την ασφάλεια των κωδικών που αποθηκεύονται στο αποθετήριο του digna.

    Command Usage¶

    dignacli generate-key

    Data Management¶

    clean-up¶

    Η εντολή clean-up στο digna CLI χρησιμοποιείται για την αφαίρεση προφίλ, προβλέψεων και δεδομένων του συστήματος φωτεινού σηματοδότη (traffic light system) για μία ή περισσότερες πηγές δεδομένων εντός ενός συγκεκριμένου project. Αυτή η εντολή είναι απαραίτητη για τη διαχείριση του κύκλου ζωής των δεδομένων, βοηθώντας στη διατήρηση ενός οργανωμένου και αποδοτικού περιβάλλοντος δεδομένων με την εκκαθάριση παρωχημένων ή περιττών δεδομένων.

    Command Usage¶

    dignacli clean-up <PROJECT_NAME> <FROM_DATE> <TO_DATE> [options]

    Arguments¶

    • PROJECT_NAME: Το όνομα του project από το οποίο θα αφαιρεθούν δεδομένα (υποχρεωτικό). Η χρήση της λέξης-κλειδί all-projects σε αυτό το όρισμα υποδεικνύει στο digna να επαναλάβει την εντολή σε όλα τα υπάρχοντα projects.
    • FROM_DATE: Η ημερομηνία και ώρα έναρξης για την αφαίρεση δεδομένων. Επιτρεπτές μορφές περιλαμβάνουν %Y-%m-%d, %Y-%m-%dT%H:%M:%S, ή %Y-%m-%d %H:%M:%S (υποχρεωτικό).
    • TO_DATE: Η ημερομηνία και ώρα λήξης για την αφαίρεση δεδομένων, ακολουθώντας τις ίδιες μορφές με το FROM_DATE (υποχρεωτικό).

    Options¶

    • --table-name, -tn: Περιορίζει την εργασία καθαρισμού σε έναν συγκεκριμένο πίνακα εντός του project.
    • --table-filter, -tf: Φίλτρο για να περιορίσει τον καθαρισμό σε πίνακες που περιέχουν την καθορισμένη υποσυμβολοσειρά στο όνομά τους.
    • --timing, -tm: Εμφανίζει τη διάρκεια χρόνου της διαδικασίας καθαρισμού μετά την ολοκλήρωση.
    • --help: Εμφανίζει πληροφορίες βοήθειας για την εντολή clean-up και τερματίζει.

    Example¶

    Για να αφαιρέσετε δεδομένα από το project ProjectA μεταξύ 1 Ιανουαρίου 2023 και 30 Ιουνίου 2023:

    dignacli clean-up ProjectA 2023-01-01 2023-06-30

    Για να αφαιρέσετε δεδομένα μόνο από έναν συγκεκριμένο πίνακα με όνομα Table1:

    dignacli clean-up ProjectA 2023-01-01 2023-06-30 --table-name Table1

    Αυτή η εντολή βοηθά στη διαχείριση του αποθηκευτικού χώρου και εξασφαλίζει ότι το αποθετήριο περιέχει μόνο σχετικές πληροφορίες.

    remove-orphans¶

    Η εντολή remove-orphans στο digna CLI χρησιμοποιείται για εργασίες συντήρησης στο αποθετήριο του digna.
    Όταν ένας χρήστης διαγράψει projects ή πηγές δεδομένων, τα προφίλ και οι προβλέψεις παραμένουν στο αποθετήριο. Με αυτή την εντολή, τέτοιες "ορφανές" εγγραφές θα αφαιρεθούν από το αποθετήριο.

    Command Usage¶

    dignacli list-projects

    list-projects¶

    Η εντολή list-projects στο digna CLI χρησιμοποιείται για να εμφανίσει μια λίστα με όλα τα διαθέσιμα projects στο σύστημα του digna.

    Command Usage¶

    dignacli list-projects

    Αυτή η εντολή είναι ιδιαίτερα χρήσιμη για διαχειριστές και χρήστες που διαχειρίζονται πολλαπλά projects, παρέχοντας μια γρήγορη επισκόπηση των διαθέσιμων projects στο αποθετήριο του digna.

    list-ds¶

    Η εντολή list-ds στο digna CLI χρησιμοποιείται για να εμφανίσει μια λίστα με όλες τις διαθέσιμες πηγές δεδομένων εντός ενός συγκεκριμένου project. Αυτή η εντολή είναι χρήσιμη για την κατανόηση των δεδομένων που είναι διαθέσιμα για ανάλυση και διαχείριση στο σύστημα του digna.

    Command Usage¶

    dignacli list-ds <PROJECT_NAME>

    Arguments¶

    • PROJECT_NAME: Το όνομα του project για το οποίο καταγράφονται οι πηγές δεδομένων (υποχρεωτικό).

    Example¶

    Για να εμφανίσετε όλες τις πηγές δεδομένων στο project με όνομα ProjectA:

    dignacli list-ds ProjectA

    Αυτή η εντολή παρέχει στους χρήστες μια επισκόπηση των πηγών δεδομένων διαθέσιμων σε ένα project, βοηθώντας τους να περιηγηθούν και να διαχειριστούν το τοπίο των δεδομένων πιο αποτελεσματικά.

    inspect¶

    Η εντολή inspect στο digna CLI χρησιμοποιείται για τη δημιουργία προφίλ, προβλέψεων και δεδομένων του συστήματος φωτεινού σηματοδότη (traffic light system) για μία ή περισσότερες πηγές δεδομένων εντός ενός συγκεκριμένου project. Αυτή η εντολή βοηθά στην ανάλυση και παρακολούθηση δεδομένων για ένα ορισμένο χρονικό διάστημα. Μετά την ολοκλήρωση της επιθεώρησης, επιστρέφεται η τιμή του υπολογισμένου συστήματος φωτεινού σηματοδότη:
    - 0: OK
    - 1: INFO
    - 2: WARNING

    Command Usage¶

    dignacli inspect <PROJECT_NAME> <FROM_DATE> <TO_DATE> [options]

    Arguments¶

    • PROJECT_NAME: Το όνομα του project για το οποίο θα επιθεωρηθούν τα δεδομένα (υποχρεωτικό). Η χρήση της λέξης-κλειδί all-projects σε αυτό το όρισμα υποδεικνύει στο digna να επαναλάβει την εντολή σε όλα τα υπάρχοντα projects.
    • FROM_DATE: Η ημερομηνία και ώρα έναρξης για την επιθεώρηση δεδομένων. Επιτρεπτές μορφές περιλαμβάνουν %Y-%m-%d, %Y-%m-%dT%H:%M:%S, ή %Y-%m-%d %H:%M:%S (υποχρεωτικό).
    • TO_DATE: Η ημερομηνία και ώρα λήξης για την επιθεώρηση δεδομένων, ακολουθώντας τις ίδιες μορφές με το FROM_DATE (υποχρεωτικό).

    Options¶

    • --table-name, -tn: Περιορίζει την επιθεώρηση σε έναν συγκεκριμένο πίνακα εντός του project.
    • --table-filter, -tf: Φίλτρο για επιθεώρηση μόνο των πινάκων που περιέχουν την καθορισμένη υποσυμβολοσειρά στα ονόματά τους.
    • --enable_notification, -en: Ενεργοποιεί την αποστολή ειδοποιήσεων σε περίπτωση συναγερμών.
    • --bypass-backend, -bb: Παράκαμψη του backend και εκτέλεση της επιθεώρησης απευθείας από το CLI (μόνο για σκοπούς δοκιμών!).

    Example¶

    Για να επιθεωρήσετε δεδομένα για το project ProjectA από 1 Ιανουαρίου 2024 έως 31 Ιανουαρίου 2024:

    dignacli inspect ProjectA 2024-01-01 2024-01-31

    Για να επιθεωρήσετε μόνο έναν συγκεκριμένο πίνακα και να αναγκάσετε επανυπολογισμό προβλέψεων:

    dignacli inspect ProjectA 2024-01-01 2024-01-31 --table-name Table1 --force-prediction
    Αυτή η εντολή είναι χρήσιμη για τη δημιουργία ενημερωμένων προφίλ και προβλέψεων, την παρακολούθηση της ακεραιότητας των δεδομένων και τη διαχείριση συστημάτων ειδοποιήσεων εντός ενός συγκεκριμένου χρονικού πλαισίου project.

    inspect-async¶

    Η εντολή inspect-async στο digna CLI χρησιμοποιείται για τη δημιουργία προφίλ, προβλέψεων και δεδομένων του συστήματος φωτεινού σηματοδότη για μία ή περισσότερες πηγές δεδομένων εντός ενός συγκεκριμένου project. Αυτή η εντολή βοηθά στην ανάλυση και παρακολούθηση δεδομένων για ένα ορισμένο χρονικό διάστημα. Σε αντίθεση με την εντολή inspect, αυτή δεν περιμένει την ολοκλήρωση της επιθεώρησης. Αντίθετα, επιστρέφει το request id για το υποβληθέν αίτημα επιθεώρησης. Για να ελέγξετε την πρόοδο της διαδικασίας επιθεώρησης, χρησιμοποιήστε την εντολή inspect-status.

    Command Usage¶

    dignacli inspect-async <PROJECT_NAME> <FROM_DATE> <TO_DATE> [options]

    Arguments¶

    • PROJECT_NAME: Το όνομα του project για το οποίο θα επιθεωρηθούν τα δεδομένα (υποχρεωτικό). Η χρήση της λέξης-κλειδί all-projects σε αυτό το όρισμα υποδεικνύει στο digna να επαναλάβει την εντολή σε όλα τα υπάρχοντα projects.
    • FROM_DATE: Η ημερομηνία και ώρα έναρξης για την επιθεώρηση δεδομένων. Επιτρεπτές μορφές περιλαμβάνουν %Y-%m-%d, %Y-%m-%dT%H:%M:%S, ή %Y-%m-%d %H:%M:%S (υποχρεωτικό).
    • TO_DATE: Η ημερομηνία και ώρα λήξης για την επιθεώρηση δεδομένων, ακολουθώντας τις ίδιες μορφές με το FROM_DATE (υποχρεωτικό).

    Options¶

    • --table-name, -tn: Περιορίζει την επιθεώρηση σε έναν συγκεκριμένο πίνακα εντός του project.
    • --table-filter, -tf: Φίλτρο για επιθεώρηση μόνο των πινάκων που περιέχουν την καθορισμένη υποσυμβολοσειρά στα ονόματά τους.
    • --enable_notification, -en: Ενεργοποιεί την αποστολή ειδοποιήσεων σε περίπτωση συναγερμών.

    Example¶

    Για να επιθεωρήσετε δεδομένα για το project ProjectA από 1 Ιανουαρίου 2024 έως 31 Ιανουαρίου 2024:

    dignacli inspect-async ProjectA 2024-01-01 2024-01-31

    inspect-status¶

    Η εντολή inspect-status στο digna CLI χρησιμοποιείται για να ελέγξετε την πρόοδο μιας ασύγχρονης επιθεώρησης βάσει του request ID.

    Command Usage¶

    dignacli inspect-status <REQUEST ID>

    Arguments¶

    • REQUEST_ID: Το request id που επέστρεψε η εντολή inspect-async

    Example¶

    Για να ελέγξετε την πρόοδο μιας επιθεώρησης με request ID 12345:

    dignacli inspect-status 12345

    inspect-cancel¶

    Η εντολή inspect-cancel στο digna CLI χρησιμοποιείται για την ακύρωση επιθεωρήσεων βάσει του request ID ή μπορεί να χρησιμοποιηθεί για την ακύρωση όλων των τρεχόντων αιτημάτων.

    Command Usage¶

    dignacli inspect-cancel <REQUEST ID>
dignacli inspect-cancel --killall

    Arguments¶

    • REQUEST_ID: Το request id που επέστρεψε η εντολή inspect-async

    Example¶

    Για να ακυρώσετε την επιθεώρηση με request ID 12345:

    dignacli inspect-cancel 12345

    Για να ακυρώσετε όλα τα αιτήματα που είναι αυτήν τη στιγμή σε εκτέλεση ή σε εκκρεμότητα:

    dignacli inspect-cancel --killall

    export-ds¶

    Η εντολή export-ds στο digna CLI χρησιμοποιείται για τη δημιουργία εξαγωγής πηγών δεδομένων από το αποθετήριο του digna. Εξ ορισμού, όλες οι πηγές δεδομένων από ένα συγκεκριμένο project θα εξαχθούν.

    Command Usage¶

    dignacli export-ds <PROJECT_NAME> [options]

    Arguments¶

    • PROJECT_NAME: Το όνομα του project από το οποίο θα εξαχθούν οι πηγές δεδομένων.

    Options¶

    • --table_name, -tn: Εξάγει μια συγκεκριμένη πηγή δεδομένων από ένα project.
    • --exportfile, -ef: Προσδιορίζει το όνομα αρχείου για την εξαγωγή.

    Example¶

    Για να εξάγετε όλες τις πηγές δεδομένων από το project με όνομα ProjectA:

    dignacli export-ds ProjectA

    Αυτή η εντολή εξάγει όλες τις πηγές δεδομένων από το ProjectA ως έγγραφο JSON που μπορεί να εισαχθεί σε άλλο project ή αποθετήριο digna.

    import-ds¶

    Η εντολή import-ds στο digna CLI χρησιμοποιείται για την εισαγωγή πηγών δεδομένων σε ένα στοχευόμενο project και τη δημιουργία αναφοράς εισαγωγής.

    Command Usage¶

    dignacli import-ds <PROJECT_NAME> <EXPORT_FILE> [options]

    Arguments¶

    • PROJECT_NAME: Το όνομα του project στο οποίο θα εισαχθούν οι πηγές δεδομένων.
    • EXPORT_FILE: Το όνομα του αρχείου της εξαγωγής πηγών δεδομένων που θα εισαχθεί.

    Options¶

    • --output-file, -o: Αρχείο για αποθήκευση της αναφοράς εισαγωγής (αν δεν οριστεί, εκτυπώνει στον τερματικό σε μορφή πίνακα).
    • --output-format, -f: Μορφή για αποθήκευση της αναφοράς εισαγωγής (json, csv).

    Example¶

    Για να εισάγετε όλες τις πηγές δεδομένων από το αρχείο εξαγωγής my_export.json στο ProjectB:

    dignacli import-ds ProjectB my_export.json

    Μετά την εισαγωγή, αυτή η εντολή θα εμφανίσει επίσης μια αναφορά των εισαχθέντων και των παραλειφθέντων αντικειμένων. Μόνο νέες πηγές δεδομένων θα εισαχθούν στο ProjectB. Για να μάθετε ποια αντικείμενα θα εισαχθούν και ποια θα παραλειφθούν, μπορείτε να χρησιμοποιήσετε την εντολή plan-import-ds.

    plan-import-ds¶

    Η εντολή plan-import-ds στο digna CLI χρησιμοποιείται για να προγραμματίσει/αναλύσει την εισαγωγή πηγών δεδομένων σε ένα στοχευόμενο project και να δημιουργήσει αναφορά σχεδίου εισαγωγής.

    Command Usage¶

    dignacli plan-import-ds <PROJECT_NAME> <EXPORT_FILE> [options]

    Arguments¶

    • PROJECT_NAME: Το όνομα του project στο οποίο θα εισάγονταν οι πηγές δεδομένων.
    • EXPORT_FILE: Το όνομα του αρχείου εξαγωγής πηγών δεδομένων που θα αναλυθεί πριν από την εισαγωγή.

    Options¶

    • --output-file, -o: Αρχείο για αποθήκευση της αναφοράς εισαγωγής (αν δεν οριστεί, εκτυπώνει στον τερματικό σε μορφή πίνακα).
    • --output-format, -f: Μορφή για αποθήκευση της αναφοράς εισαγωγής (json, csv).

    Example¶

    Για να ελέγξετε ποιες πηγές δεδομένων θα εισαχθούν και ποιες θα παραλειφθούν από το αρχείο εξαγωγής my_export.json όταν εισαχθεί στο ProjectB:

    dignacli plan-import-ds ProjectB my_export.json

    Αυτή η εντολή θα εμφανίσει μόνο ένα σχέδιο εισαγωγής των αντικειμένων που θα εισαχθούν και αυτών που θα παραλειφθούν.

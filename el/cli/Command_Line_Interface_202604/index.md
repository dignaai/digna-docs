## CLI Basics

---

### help
Η επιλογή `--help` παρέχει πληροφορίες σχετικά με τις διαθέσιμες εντολές και τον τρόπο χρήσης τους. Υπάρχουν δύο βασικοί τρόποι χρήσης αυτής της επιλογής:

1. **Εμφάνιση Γενικής Βοήθειας:**
   
    Χρησιμοποιήστε `--help` αμέσως μετά την εντολή ***dignacli***  
   ```bash
   dignacli --help
   ```

2. **Λήψη Βοήθειας για Συγκεκριμένες Εντολές:**  
  
    Για λεπτομερείς πληροφορίες σχετικά με μια συγκεκριμένη εντολή, προσθέστε `--help` μετά από εκείνη την εντολή.
    Για παράδειγμα, για βοήθεια με την εντολή `add-user`, εκτελέστε:
     ```bash
     dignacli add-user --help
     ```

     ### output:
      
     - **Περιγραφή Εντολής:** Προσφέρει μια λεπτομερή περιγραφή του τι κάνει η εντολή.  
     - **Σύνταξη:** Εμφανίζει την ακριβή σύνταξη, συμπεριλαμβανομένων των υποχρεωτικών και προαιρετικών ορισμάτων.  
     - **Επιλογές:** Λίστα με τις επιλογές που αφορούν την εντολή, μαζί με τις εξηγήσεις τους.  
     - **Παραδείγματα:** Παρέχει παραδείγματα για το πώς να εκτελέσετε αποτελεσματικά την εντολή.

### check-config

Η εντολή `check-config` είναι ένα βοηθητικό εργαλείο μέσα στο CLI του ***digna*** σχεδιασμένο για να ελέγχει τη διαμόρφωση του ***digna***. Αυτή η εντολή εξασφαλίζει ότι τα συστατικά του ***digna*** μπορούν να εντοπίσουν τα απαιτούμενα στοιχεία διαμόρφωσης στο config.toml.

#### Options

- `--configpath`, `-cp`: Αρχείο ή φάκελος που περιέχει τη διαμόρφωση. Εάν παραλειφθεί, θα χρησιμοποιηθεί το ../config.toml.
      
#### Command Usage
```bash
dignacli check-config
```

Μετά την επιτυχή εκτέλεση, η εντολή εμφανίζει μια επιβεβαίωση της πληρότητας της διαμόρφωσης.  
  
Εάν η διαμόρφωση φαίνεται ελλιπής, θα αναφερθούν τα ελλείποντα στοιχεία διαμόρφωσης.

  
### check-repo-connection

Η εντολή `check-repo-connection` είναι ένα βοηθητικό εργαλείο μέσα στο CLI του ***digna*** σχεδιασμένο για να ελέγχει τη συνδεσιμότητα και την πρόσβαση σε ένα συγκεκριμένο αποθετήριο ***digna***. Αυτή η εντολή εξασφαλίζει ότι το CLI μπορεί να αλληλεπιδράσει με το αποθετήριο.
      
#### Command Usage
```bash
dignacli check-repo-connection
```

Μετά την επιτυχή εκτέλεση, η εντολή εμφανίζει μια επιβεβαίωση της σύνδεσης, μαζί με λεπτομέρειες για το αποθετήριο: Έκδοση αποθετηρίου, Host, Database και Schema.  
  
Εάν η σύνδεση με το αποθετήριο δεν είναι επιτυχής, ελέγξτε το αρχείο config.toml για σωστές ρυθμίσεις διαμόρφωσης.


### version

#### Example Output

### logging options
  
Κατά προεπιλογή, η έξοδος στην κονσόλα των εντολών του ***digna*** είναι σχεδιασμένη να είναι μινιμαλιστική. Οι περισσότερες εντολές προσφέρουν τη δυνατότητα παροχής πρόσθετων πληροφοριών, χρησιμοποιώντας τις παρακάτω επιλογές:  
  
-- verbose (-v)  
-- debug (-d)  
-- logfile (lf)  
 
Οι επιλογές “verbose” και “debug” ορίζουν το επίπεδο λεπτομέρειας, ενώ η επιλογή “logfile” επιτρέπει την ανακατεύθυνση της εξόδου σε αρχείο αντί στην κονσόλα.

## User Management

### add-user
  
Η εντολή add-user στο CLI του ***digna*** χρησιμοποιείται για την προσθήκη ενός νέου χρήστη στο σύστημα του ***digna***.
  
#### Command Usage
```bash
dignacli add-user [OPTIONS] USER_NAME USER_FULL_NAME USER_PASSWORD
```
  
#### Arguments

- **USER_NAME**: Το όνομα χρήστη για τον νέο χρήστη (υποχρεωτικό).
- **USER_FULL_NAME**: Το πλήρες όνομα του νέου χρήστη (υποχρεωτικό).
- **USER_PASSWORD**: Ο κωδικός πρόσβασης για τον νέο χρήστη (υποχρεωτικό).

#### Options

- `--is_superuser`, `-su`: Σημαία για να καθορίσετε τον νέο χρήστη ως διαχειριστή.
- `--valid_until`, `-vu`: Ορίζει ημερομηνία λήξης για τον λογαριασμό χρήστη στη μορφή `YYYY-MM-DD HH:MI:SS`. Εάν δεν οριστεί, ο λογαριασμός δεν έχει ημερομηνία λήξης.

#### Example

Για να προσθέσετε έναν νέο χρήστη με username `jdoe`, πλήρες όνομα `John Doe` και κωδικό `password123`:

```bash
dignacli add-user [OPTIONS] USER_NAME USER_FULL_NAME USER_PASSWORD
```
  
Για να προσθέσετε έναν νέο χρήστη και να ορίσετε ημερομηνία λήξης για τον λογαριασμό:
```bash
dignacli add-user jdoe "John Doe" password123 --valid_until "2024-12-31 23:59:59"
```

### delete-user
  
Η εντολή `delete-user` στο CLI του ***digna*** χρησιμοποιείται για την αφαίρεση ενός υπάρχοντος χρήστη από το σύστημα του ***digna***.
  
#### Command Usage
```bash
dignacli delete-user USER_NAME
```
  
#### Arguments
- **USER_NAME**: Το όνομα χρήστη του χρήστη που θα διαγραφεί (υποχρεωτικό). Αυτό είναι το μόνο όρισμα που απαιτεί η εντολή.

#### Example
```bash
dignacli delete-user jdoe
```
  
Η εκτέλεση αυτής της εντολής θα αφαιρέσει τον χρήστη `jdoe` από το σύστημα του ***digna***, ανακαλώντας την πρόσβασή του και διαγράφοντας τα συσχετισμένα δεδομένα και δικαιώματά του από το αποθετήριο.

### modify-user

Η εντολή `modify-user` στο CLI του ***digna*** χρησιμοποιείται για την ενημέρωση των στοιχείων ενός υπάρχοντος χρήστη στο σύστημα του ***digna***.

#### Command Usage
  
```bash
dignacli modify-user <USER_NAME> <USER_FULL_NAME> [options]
```
  
#### Arguments
  
- **USER_NAME**: Το όνομα χρήστη του χρήστη που θα τροποποιηθεί (υποχρεωτικό).
- **USER_FULL_NAME**: Το νέο πλήρες όνομα για τον χρήστη (υποχρεωτικό).
  
#### Options  
  
- `--is_superuser`, `-su`: Ορίζει τον χρήστη ως superuser, παραχωρώντας αυξημένα προνόμια. Αυτή η σημαία δεν απαιτεί τιμή.  
- `--valid_until`, `-vu`: Ορίζει ημερομηνία λήξης για τον λογαριασμό του χρήστη στη μορφή YYYY-MM-DD HH:MI:SS. Εάν δεν δοθεί, ο λογαριασμός παραμένει έγκυρος επ’ αόριστον.  
  
#### Example
  
Για να τροποποιήσετε το πλήρες όνομα του χρήστη `jdoe` σε “Johnathan Doe” και να ορίσετε τον χρήστη ως superuser:
```bash
dignacli modify-user jdoe "Johnathan Doe" --is_superuser
```

Η εντολή `modify-user-pwd` στο CLI του ***digna*** χρησιμοποιείται για την αλλαγή του κωδικού πρόσβασης ενός υπάρχοντος χρήστη στο σύστημα του ***digna***.
  
#### Command Usage

#### Arguments

- **USER_PWD**: Ο νέος κωδικός πρόσβασης για τον χρήστη (υποχρεωτικό).
  
#### Example
  
Για να αλλάξετε τον κωδικό για τον χρήστη `jdoe` σε `newpassword123`:
```bash
dignacli modify-user-pwd jdoe newpassword123
```

### list-users

Η εντολή `list-users` στο CLI του ***digna*** εμφανίζει λίστα με όλους τους χρήστες που έχουν εγγραφεί στο σύστημα του ***digna***.

#### Command Usage

```bash

```

Η εκτέλεση αυτής της εντολής στο CLI του ***digna*** θα συνδεθεί με το αποθετήριο του ***digna*** και θα εμφανίσει όλους τους χρήστες, δείχνοντας το ID τους, το username, το πλήρες όνομα, το αν είναι superuser και τα timestamps λήξης.

## Repository Management

### upgrade-repo
  
Η εντολή `upgrade-repo` στο CLI του ***digna*** χρησιμοποιείται για την αναβάθμιση ή την αρχικοποίηση του αποθετηρίου του ***digna***. Αυτή η εντολή είναι απαραίτητη για την εφαρμογή ενημερώσεων ή τη ρύθμιση της υποδομής του αποθετηρίου για πρώτη φορά.
  
#### Command Usage

```bash
dignacli upgrade-repo [options]
```
  
#### Options
  
- `--simulation-mode`, `-s`: Όταν ενεργοποιηθεί, αυτή η επιλογή εκτελεί την εντολή σε λειτουργία προσομοίωσης, εμφανίζοντας τις εντολές SQL που θα εκτελούνταν χωρίς να τις εφαρμόζει πραγματικά. Αυτό είναι χρήσιμο για την προεπισκόπηση αλλαγών χωρίς τροποποίηση του αποθετηρίου.  

  
#### Example
  
Για να αναβαθμίσετε το αποθετήριο του ***digna***, μπορείτε να εκτελέσετε την εντολή χωρίς επιλογές:
  
```bash
dignacli upgrade-repo
```  
Για να τρέξετε την αναβάθμιση σε λειτουργία προσομοίωσης (για να δείτε τις δηλώσεις SQL χωρίς να τις εφαρμόσετε):
  
```bash
dignacli upgrade-repo --simulation-mode
```
  
Αυτή η εντολή είναι κρίσιμη για τη συντήρηση του συστήματος ***digna***, εξασφαλίζοντας ότι το σχήμα της βάσης δεδομένων και άλλα στοιχεία του αποθετηρίου είναι ενημερωμένα με την τελευταία έκδοση του λογισμικού.

## Data Management

### clean-up

Η εντολή `clean-up` στο CLI του ***digna*** χρησιμοποιείται για την αφαίρεση προφίλ, προβλέψεων και δεδομένων του συστήματος σηματοδότησης (traffic light system) για μία ή περισσότερες πηγές δεδομένων εντός ενός καθορισμένου έργου. Αυτή η εντολή είναι απαραίτητη για τη διαχείριση του κύκλου ζωής των δεδομένων, βοηθώντας στη διατήρηση ενός οργανωμένου και αποδοτικού περιβάλλοντος δεδομένων μέσω της εκκαθάρισης παρωχημένων ή μη απαραίτητων δεδομένων.

#### Command Usage

```bash
dignacli clean-up <PROJECT_NAME> <FROM_DATE> <TO_DATE> [options]
```
  
#### Arguments
  
- **PROJECT_NAME**: Το όνομα του έργου από το οποίο θα αφαιρεθούν δεδομένα (υποχρεωτικό). Η χρήση της λέξης-κλειδί `all-projects` σε αυτό το όρισμα δίνει εντολή στο ***digna*** να επαναλάβει την εντολή σε όλα τα υπάρχοντα έργα.
- **FROM_DATE**: Η ημερομηνία και ώρα έναρξης για την αφαίρεση των δεδομένων. Επιτρεπτές μορφές περιλαμβάνουν %Y-%m-%d, %Y-%m-%dT%H:%M:%S, ή %Y-%m-%d %H:%M:%S (υποχρεωτικό).
- **TO_DATE**: Η ημερομηνία και ώρα λήξης για την αφαίρεση των δεδομένων, με τις ίδιες μορφές όπως το FROM_DATE (υποχρεωτικό).
  
#### Options
  
- `--table-name`, `-tn`: Περιορίζει τη λειτουργία clean-up σε έναν συγκεκριμένο πίνακα εντός του έργου.
- `--table-filter`, `-tf`: Φίλτρο για να περιοριστεί η εκκαθάριση σε πίνακες που περιέχουν το συγκεκριμένο υποσύνολο χαρακτήρων στο όνομά τους.
- `--timing`, `-tm`: Εμφανίζει τη διάρκεια εκτέλεσης της διαδικασίας clean-up μετά την ολοκλήρωση.
- `--help`: Εμφανίζει πληροφορίες βοήθειας για την εντολή clean-up και τερματίζει.
  
#### Example
  
Για να αφαιρέσετε δεδομένα από το έργο `ProjectA` μεταξύ 1 Ιανουαρίου 2023 και 30 Ιουνίου 2023:
  
```bash
dignacli clean-up ProjectA 2023-01-01 2023-06-30
```
  
Για να αφαιρέσετε δεδομένα μόνο από έναν συγκεκριμένο πίνακα με όνομα `Table1`:
  
```bash
dignacli clean-up ProjectA 2023-01-01 2023-06-30 --table-name Table1
```
  
Αυτή η εντολή βοηθά στη διαχείριση του αποθηκευτικού χώρου και στη διασφάλιση ότι το αποθετήριο περιέχει μόνο σχετικές πληροφορίες.

### inspect

Η εντολή `inspect` στο CLI του ***digna*** χρησιμοποιείται για τη δημιουργία προφίλ, προβλέψεων και δεδομένων του συστήματος σηματοδότησης (traffic light system) για μία ή περισσότερες πηγές δεδομένων εντός ενός συγκεκριμένου έργου. Αυτή η εντολή βοηθά στην ανάλυση και παρακολούθηση των δεδομένων για μια καθορισμένη περίοδο. Μετά την ολοκλήρωση της επιθεώρησης, επιστρέφεται η τιμή του υπολογισμένου traffic light system:  
- 0: OK  
- 1: INFO  
- 2: WARNING

#### Command Usage

```bash
dignacli inspect <PROJECT_NAME> <FROM_DATE> <TO_DATE> [options]
```
  
#### Arguments
  
- **PROJECT_NAME**: Το όνομα του έργου για το οποίο θα γίνει επιθεώρηση δεδομένων (υποχρεωτικό). Η χρήση της λέξης-κλειδί `all-projects` σε αυτό το όρισμα δίνει εντολή στο ***digna*** να επαναλάβει την εντολή σε όλα τα υπάρχοντα έργα.
- **FROM_DATE**: Η ημερομηνία και ώρα έναρξης για την επιθεώρηση δεδομένων. Επιτρεπτές μορφές περιλαμβάνουν %Y-%m-%d, %Y-%m-%dT%H:%M:%S, ή %Y-%m-%d %H:%M:%S (υποχρεωτικό).
- **TO_DATE**: Η ημερομηνία και ώρα λήξης για την επιθεώρηση δεδομένων, με τις ίδιες μορφές όπως το FROM_DATE (υποχρεωτικό).
  
#### Options

- `--table-name`, `-tn`: Περιορίζει την επιθεώρηση σε έναν συγκεκριμένο πίνακα εντός του έργου.
- `--table-filter`, `-tf`: Φιλτράρει ώστε να επιθεωρηθούν μόνο πίνακες που περιέχουν το συγκεκριμένο υποσύνολο χαρακτήρων στο όνομά τους.
- `--enable_notification`, `-en`: Ενεργοποιεί την αποστολή ειδοποιήσεων σε περίπτωση alerts.
- `--bypass-backend`, `-bb`: Παράκαμψη του backend και εκτέλεση της επιθεώρησης απευθείας από το CLI (μόνο για δοκιμές!).

  
#### Example
  
Για να επιθεωρήσετε δεδομένα για το έργο `ProjectA` από 1 Ιανουαρίου 2024 έως 31 Ιανουαρίου 2024:
  
```bash
dignacli inspect ProjectA 2024-01-01 2024-01-31
```
  
Για να επιθεωρήσετε μόνο έναν συγκεκριμένο πίνακα και να αναγκάσετε επανυπολογισμό των προβλέψεων:
  
```bash
dignacli inspect ProjectA 2024-01-01 2024-01-31 --table-name Table1 --force-prediction
```
Αυτή η εντολή είναι χρήσιμη για τη δημιουργία ενημερωμένων προφίλ και προβλέψεων, την παρακολούθηση της ακεραιότητας των δεδομένων και τη διαχείριση συστημάτων ειδοποιήσεων εντός ενός καθορισμένου χρονικού διαστήματος του έργου.

### inspect-async

Η εντολή `inspect-async` στο CLI του ***digna*** χρησιμοποιείται για τη δημιουργία προφίλ, προβλέψεων και δεδομένων του συστήματος σηματοδότησης για μία ή περισσότερες πηγές δεδομένων εντός ενός συγκεκριμένου έργου. Αυτή η εντολή βοηθά στην ανάλυση και παρακολούθηση των δεδομένων για μια καθορισμένη περίοδο. Σε αντίθεση με την εντολή `inspect`, αυτή δεν περιμένει την ολοκλήρωση της επιθεώρησης.
Αντ’ αυτού, επιστρέφει το request id για το υποβληθέν αίτημα επιθεώρησης. Για να ελέγξετε την πρόοδο της διαδικασίας επιθεώρησης, χρησιμοποιήστε την εντολή `inspect-status`.

#### Command Usage

```bash
dignacli inspect-async <PROJECT_NAME> <FROM_DATE> <TO_DATE> [options]
```
  
#### Arguments
  
- **PROJECT_NAME**: Το όνομα του έργου για το οποίο θα γίνει επιθεώρηση δεδομένων (υποχρεωτικό). Η χρήση της λέξης-κλειδί `all-projects` σε αυτό το όρισμα δίνει εντολή στο ***digna*** να επαναλάβει την εντολή σε όλα τα υπάρχοντα έργα.
- **FROM_DATE**: Η ημερομηνία και ώρα έναρξης για την επιθεώρηση δεδομένων. Επιτρεπτές μορφές περιλαμβάνουν %Y-%m-%d, %Y-%m-%dT%H:%M:%S, ή %Y-%m-%d %H:%M:%S (υποχρεωτικό).
- **TO_DATE**: Η ημερομηνία και ώρα λήξης για την επιθεώρηση δεδομένων, με τις ίδιες μορφές όπως το FROM_DATE (υποχρεωτικό).
  
#### Options

- `--table-name`, `-tn`: Περιορίζει την επιθεώρηση σε έναν συγκεκριμένο πίνακα εντός του έργου.
- `--table-filter`, `-tf`: Φιλτράρει ώστε να επιθεωρηθούν μόνο πίνακες που περιέχουν το συγκεκριμένο υποσύνολο χαρακτήρων στο όνομά τους.
- `--enable_notification`, `-en`: Ενεργοποιεί την αποστολή ειδοποιήσεων σε περίπτωση alerts.

  
#### Example
  
Για να επιθεωρήσετε δεδομένα για το έργο `ProjectA` από 1 Ιανουαρίου 2024 έως 31 Ιανουαρίου 2024:
  
```bash
dignacli inspect-async ProjectA 2024-01-01 2024-01-31
```

### export-ds

Η εντολή `export-ds` στο CLI του ***digna*** χρησιμοποιείται για τη δημιουργία εξαγωγής των πηγών δεδομένων από το αποθετήριο του ***digna***. Από προεπιλογή, όλες οι πηγές δεδομένων ενός συγκεκριμένου έργου θα εξαχθούν.

#### Command Usage
  
```bash
dignacli export-ds <PROJECT_NAME> [options]
```

#### Arguments
- **PROJECT_NAME**: Το όνομα του έργου από το οποίο θα εξαχθούν οι πηγές δεδομένων.

#### Options

- `--table_name`, `-tn`: Εξάγει μια συγκεκριμένη πηγή δεδομένων από ένα έργο.
- `--exportfile`, `-ef`: Καθορίζει το όνομα αρχείου για την εξαγωγή.
    
#### Example
  
Για να εξάγετε όλες τις πηγές δεδομένων από το έργο με όνομα `ProjectA`:
  
```bash
dignacli export-ds ProjectA
```
  
Αυτή η εντολή εξάγει όλες τις πηγές δεδομένων από το `ProjectA` ως έγγραφο JSON που μπορεί να εισαχθεί σε άλλο έργο ή αποθετήριο του ***digna***.


### import-ds

Η εντολή `import-ds` στο CLI του ***digna*** χρησιμοποιείται για την εισαγωγή πηγών δεδομένων σε ένα στοχευόμενο έργο και για τη δημιουργία αναφοράς εισαγωγής.

#### Command Usage
  
```bash
dignacli import-ds <PROJECT_NAME> <EXPORT_FILE> [options]
```

#### Arguments
- **PROJECT_NAME**: Το όνομα του έργου στο οποίο θα εισαχθούν οι πηγές δεδομένων.
- **EXPORT_FILE**: Το όνομα αρχείου της εξαγωγής πηγών δεδομένων που θα εισαχθεί.

#### Options

- `--output-file`, `-o`: Αρχείο για αποθήκευση της αναφοράς εισαγωγής (εάν δεν καθοριστεί, εκτυπώνεται στο τερματικό σε μορφή πίνακα).
- `--output-format`, `-f`: Μορφή αποθήκευσης της αναφοράς εισαγωγής (json, csv).
    
#### Example
  
Για να εισάγετε όλες τις πηγές δεδομένων από το αρχείο εξαγωγής `my_export.json` στο `ProjectB`:
  
```bash
dignacli import-ds ProjectB my_export.json
```
  
Μετά την εισαγωγή, αυτή η εντολή θα εμφανίσει επίσης μια αναφορά των εισαχθέντων και παραλειφθέντων αντικειμένων. Μόνο νέες πηγές δεδομένων θα εισαχθούν στο `ProjectB`. Για να μάθετε ποια αντικείμενα θα εισαχθούν και ποια θα παραλειφθούν, μπορείτε να χρησιμοποιήσετε την εντολή `plan-import-ds`.

### plan-import-ds

Η εντολή `plan-import-ds` στο CLI του ***digna*** χρησιμοποιείται για την ανάλυση μιας εξαγωγής πηγών δεδομένων και τη δημιουργία ενός σχεδίου εισαγωγής (import plan).

#### Command Usage
  
```bash
dignacli plan-import-ds <PROJECT_NAME> <EXPORT_FILE> [options]
```

#### Arguments
- **PROJECT_NAME**: Το όνομα του έργου στο οποίο θα εισαχθούν οι πηγές δεδομένων.
- **EXPORT_FILE**: Το όνομα αρχείου της εξαγωγής πηγών δεδομένων που θα αναλυθεί πριν την εισαγωγή.

#### Options

- `--output-file`, `-o`: Αρχείο για αποθήκευση της αναφοράς εισαγωγής (εάν δεν καθοριστεί, εκτυπώνεται στο τερματικό σε μορφή πίνακα).
- `--output-format`, `-f`: Μορφή αποθήκευσης της αναφοράς εισαγωγής (json, csv).
    
#### Example
  
Για να ελέγξετε ποιες πηγές δεδομένων θα εισαχθούν και ποιες θα παραλειφθούν από το αρχείο εξαγωγής `my_export.json` όταν εισαχθεί στο `ProjectB`:
  
```bash
dignacli plan-import-ds ProjectB my_export.json
```
  
Αυτή η εντολή θα εμφανίσει μόνο ένα σχέδιο εισαγωγής των αντικειμένων που θα εισαχθούν και θα παραλειφθούν.

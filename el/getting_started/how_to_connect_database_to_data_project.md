### Βήματα

1. **Άνοιγμα του έργου σας**  
   Από την αριστερή πλοήγηση, κάντε κλικ στο **Projects** και επιλέξτε το επιθυμητό έργο.

2. **Προσθήκη σύνδεσης**  
   Μεταβείτε στο **Connections** και κάντε κλικ στο **Add Connection**.

3. **Επιλέξτε τύπο βάσης δεδομένων**  
   Επιλέξτε τη βάση δεδομένων που θέλετε να συνδέσετε (π.χ. PostgreSQL, MySQL, SQL Server, Oracle, Snowflake, Teradata).

4. **Εισαγάγετε λεπτομέρειες σύνδεσης**  
   Παρέχετε **Name**, **Host**, **Port**, **Database/Service**, και **Credentials** (username/password ή SSO, όπου ισχύει).

5. **Δοκιμή & Αποθήκευση**  
   Κάντε κλικ στο **Test**. Εάν είναι επιτυχές, κάντε κλικ στο **Save**. Η σύνδεση θα εμφανιστεί στο **Connections** για το έργο.

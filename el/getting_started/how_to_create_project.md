### Βήματα

1. **Άνοιγμα της ενότητας Έργων**
   - Από την αριστερή πλοήγηση, κάντε κλικ στο **Έργα**.

2. **Δημιουργία νέου έργου**
   - Κάντε κλικ στο κουμπί **Νέο Έργο**.

3. **Εισαγωγή λεπτομερειών έργου**
   - Παρέχετε ένα **Όνομα Έργου**.  
   - (Προαιρετικά) Προσθέστε μια **Περιγραφή** για το πλαίσιο.

4. **Αποθήκευση του έργου**
   - Κάντε κλικ στο **Δημιουργία** για να ολοκληρώσετε.  
   - Το έργο θα εμφανιστεί τώρα στη **λίστα Έργων** σας.

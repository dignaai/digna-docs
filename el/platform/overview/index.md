# *digna* Modules — Technical Overview
<h1 style="display:none;">Modules for Data Quality, Quality of Data, and Observability of Data – digna Platform</h1>

*digna* είναι μια πλατφόρμα AI-powered **Data Quality & Observability Platform** σχεδιασμένη για **in-database execution**.  
Λειτουργεί απευθείας μέσα στο περιβάλλον δεδομένων σας και εξασφαλίζει **εμπιστοσύνη στα δεδομένα σας** — χωρίς να απαιτείται χειροκίνητος κωδικός κανόνων ή μετακίνηση δεδομένων.

Συνδυάζοντας αυτοματοποιημένη ανίχνευση ανωμαλιών, έλεγχο με κανόνες και παρακολούθηση δομής δεδομένων, το digna βελτιώνει διαρκώς τόσο την **ποιότητα των δεδομένων** όσο και την **παρατηρησιμότητα των pipelines δεδομένων**.

---

## Module Summary

| Module | Focus Area | Key Capabilities |
|--------|-------------|------------------|
| **Data Anomalies** | Αυτόματη ανίχνευση ανωμαλιών | Μαθαίνει την «κανονική» συμπεριφορά των δεδομένων, εντοπίζει αποκλίσεις σε **όγκο, κατανομή ή πρότυπα τιμών**, και σηματοδοτεί ασυνήθιστες κινήσεις δεδομένων ή κενά |
| **Data Analytics** | Τάσεις & μεταβλητότητα | Αναλύει μακροπρόθεσμα **μετρικές, σταθερότητα και πρότυπα αλλαγής** για να εντοπίσει drift στην ποιότητα των δεδομένων με την πάροδο του χρόνου |
| **Data Validation** | Έλεγχοι βάσει κανόνων | Επιβάλλει **ακριβείς τιμές, εύρη, thresholds ή λίστες αναφοράς** — με πλήρες audit trail και επαναληπτότητα |
| **Data Timeliness** | Παρακολούθηση παράδοσης | Χρησιμοποιεί AI-learned **αναμενόμενους χρόνους άφιξης** και προγραμματισμούς ορισμένους από τον χρήστη για να εντοπίσει **καθυστερημένα ή ελλείποντα δεδομένα** |
| **Data Schema Tracker** | Παρακολούθηση δομής | Εντοπίζει **schema drift**, όπως νέες ή αφαιρεθείσες στήλες, μετονομασίες πεδίων ή αλλαγές τύπων δεδομένων |

---

## Πώς συνεργάζονται τα Modules

Κάθε module του digna καλύπτει μια συγκεκριμένη διάσταση της **ποιότητας των δεδομένων** και της **παρατηρησιμότητας των συστημάτων δεδομένων**, αλλά ενσωματώνονται άψογα σε μια ενιαία πλατφόρμα.  

- **Data Anomalies** και **Data Analytics** παρέχουν insights με AI και ενημέρωση για τάσεις.  
- **Data Validation** διασφαλίζει την ορθότητα μέσω επιβολής κανόνων.  
- **Data Timeliness** προστατεύει την παράδοση και τη φρεσκάδα των δεδομένων.  
- **Data Schema Tracker** διαφυλάσσει τη δομή και την ακεραιότητα των μεταδεδομένων.  

Μαζί, δημιουργούν ένα πλήρες **Πλαίσιο Παρατηρησιμότητας και Ελέγχου Ποιότητας Δεδομένων** που λειτουργεί εξολοκλήρου μέσα στο περιβάλλον σας — **on-premises ή private cloud**.

## Οφέλη της Μοντελοποιημένης Προσέγγισης

- **Κλιμακώσιμο** – ξεκινήστε με ένα module και επεκταθείτε όπως χρειάζεται  
- **Ενιαίο Interface** – ίδια UI και API για όλα τα modules  
- **AI-Assisted Configuration** – ελάχιστη ρύθμιση, γρήγορο onboarding  
- **Cross-Module Insights** – ανιχνεύστε σχέσεις ανάμεσα σε timeliness, schema drift και ανωμαλίες  
- **Enterprise Integration** – λειτουργεί με Teradata, Snowflake, Databricks και άλλες enterprise πλατφόρμες δεδομένων  

---

**digna** προσφέρει ένα **modular, AI-driven πλαίσιο για Ποιότητα Δεδομένων και Παρατηρησιμότητα** —  
χτισμένο στην Ευρώπη για οργανισμούς που απαιτούν **data sovereignty**, **απόδοση** και **εμπιστοσύνη**.  
Όλα τα modules συνεργάζονται για να παρέχουν πλήρη ορατότητα στο οικοσύστημα δεδομένων σας, διασφαλίζοντας ότι κάθε insight είναι **ακριβές, εξηγημένο και αξιόπιστο**.

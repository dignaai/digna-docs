### QueryMode – Ευέλικτη Στρατηγική Εκτέλεσης SQL

Ρυθμίστε τη στρατηγική εκτέλεσης ερωτημάτων: **Single** ή **Combined** mode

**Single Mode**: Κάθε στατιστικό υπολογίζεται με ένα ξεχωριστό SQL query

  - Ιδανικό για μεγάλα datasource όπου οι περιορισμοί μνήμης αποτελούν πρόβλημα  
  - Αποτρέπει εξάντληση πόρων σε συνδυασμένα queries (out of memory, spool limits)  
  - Μεγαλύτερος αριθμός queries αλλά μικρότερο αποτύπωμα μνήμης ανά query

**Combined Mode**: Όλα τα στατιστικά υπολογίζονται σε ένα ενιαίο SQL query

  - Μειώνει το συνολικό πλήθος queries και το network overhead  
  - Βελτιστοποιεί την απόδοση όταν τα datasource είναι διαχειρίσιμα στη μνήμη  
  - Πιο αποδοτικό για συχνές, παράλληλες εκτελέσεις

**Επίδραση:** Δίνει στους χρήστες λεπτομερή έλεγχο πάνω στην εκτέλεση ερωτημάτων για να ισορροπήσουν απόδοση, χρήση πόρων και ασφάλεια μνήμης ανάλογα με τα χαρακτηριστικά του datasource τους.

# Changelog – Release 2025.04

Με την Έκδοση 2025.04, η digna κάνει ένα μεγάλο βήμα μπροστά στο να καταστήσει την ποιότητα δεδομένων και την παρατηρησιμότητα πιο εύκολη στη διαχείριση, πιο διαφανή για τις ομάδες και προσβάσιμη σε χρήστες παγκοσμίως.  
Αυτή η έκδοση συνδυάζει **ισχυρά νέα χαρακτηριστικά**, **βελτιώσεις αυτοματισμού ροών εργασίας** και **βελτιώσεις στην εμπειρία χρήστη**.  

---

## New Features

### Inspection Hub – A New Command Center
Το **Inspection Hub** είναι πλέον διαθέσιμο ως το κεντρικό σημείο διαχείρισης όλων των εργασιών επιθεώρησης. Αντί να μεταπηδάτε ανάμεσα σε διαφορετικά modules ή να βασίζεστε αποκλειστικά στην εκτέλεση από τη γραμμή εντολών, τώρα μπορείτε να παρακολουθείτε και να ελέγχετε τις επιθεωρήσεις σας από μία ενοποιημένη διεπαφή.  

Κύριες δυνατότητες:  
- Επιθεωρήσεις κατά ζήτηση: Ξεκινήστε νέες εργασίες άμεσα όποτε χρειάζεστε φρέσκα αποτελέσματα.  
- Ιστορικό επιθεωρήσεων: Δείτε ένα χρονολόγιο των επιθεωρήσεων — τι εκτελέστηκε, ποιος το ενεργοποίησε και πότε.  
- Παρακολούθηση κατάστασης: Οι εργασίες επισημαίνονται καθαρά ως ολοκληρωμένες, σε εξέλιξη ή σε εκκρεμότητα.  
- Πληροφορίες για τον εκκινήτη: Ελέγξτε γρήγορα αν μια επιθεώρηση ενεργοποιήθηκε από χρήστη, από scheduler ή από το CLI.  
- Εργαλεία καθαρισμού: Διαγράψτε παλιές ή μη απαραίτητες εργασίες για να διατηρείτε το workspace καθαρό.  
- Αναλυτικά logs: Εμβαθύνετε σε κάθε εργασία για να δείτε πόσο κράτησε, ποιες πηγές συμπεριλήφθηκαν και πώς εφαρμόστηκαν τα thresholds.  

Το Inspection Hub παρέχει στις ομάδες **ορατότητα και έλεγχο end-to-end**, καθιστώντας τις επιθεωρήσεις πιο εύκολες στη διαχείριση σε μεγάλα έργα.  

---

### Multi-language Support – digna Speaks Your Language
Η digna είναι πλέον έτοιμη για διεθνείς ομάδες με την εισαγωγή της **πολυγλωσσικής υποστήριξης**.  

Σε αυτή την έκδοση μπορείτε να ορίσετε τη **γλώσσα διεπαφής προτίμησής σας** απευθείας στις Προτιμήσεις Χρήστη. Οι υποστηριζόμενες γλώσσες περιλαμβάνουν:  
- English (UK, US, CA, AU)  
- German (DE, AT, CH)  
- Polish (PL)  

Αυτό καθιστά τη digna πιο εύχρηστη για πολυγλωσσικούς οργανισμούς και εξασφαλίζει ομαλότερη υιοθέτηση σε ομάδες που εργάζονται σε διαφορετικές περιοχές. Περισσότερες γλώσσες θα προστεθούν σε μελλοντικές εκδόσεις.  

---

### Import & Export of Data Sources – Configuration Made Simple
Η συνέπεια μεταξύ περιβαλλόντων είναι απαραίτητη σε enterprise deployments. Με την 2025.04, η digna εισάγει την **εισαγωγή/εξαγωγή πηγών δεδομένων** μέσω του **dignacli**, του εργαλείου γραμμής εντολών για προχωρημένους χρήστες.  

Οφέλη:  
- Εξάγετε μια ρύθμιση πηγής δεδομένων μία φορά και επαναχρησιμοποιήστε την σε Development, Test και Production.  
- Εξαλείψτε τις χειροκίνητες επανα-διαμορφώσεις και αποφύγετε δαπανηρά σφάλματα.  
- Υποστηρίξτε αυτοματοποιημένες ροές εργασίας και CI/CD pipelines με απλές εντολές CLI (`export-ds` και `import-ds`).  
- Αντιγράψτε γρήγορα πηγές δεδομένων μεταξύ projects για ευκολότερη συνεργασία.  

Αυτή η λειτουργία διασφαλίζει ότι οι ομάδες μπορούν να αναπτύσσονται με εμπιστοσύνη, γνωρίζοντας ότι οι ρυθμίσεις είναι συνεπείς σε κάθε περιβάλλον.

### Module Analytics (v1) – From Detection to Understanding
Η digna ξεκίνησε ως πλατφόρμα για ανίχνευση ανωμαλιών και παρακολούθηση ποιότητας δεδομένων. Με την Έκδοση 2025.04, εξελίσσεται περαιτέρω με την **πρώτη έκδοση του Module Analytics**.  

Το Module Analytics βοηθά τους χρήστες να **κατανοήσουν τα δεδομένα τους** αντί απλώς να αντιδρούν σε προβλήματα. Με αυτό το νέο module μπορείτε να:  
- Παρακολουθείτε μακροπρόθεσμες τάσεις στα datasets σας.  
- Εντοπίζετε και παρακολουθείτε τη μεταβλητότητα για να κατανοήσετε τις διακυμάνσεις.  
- Εξερευνείτε τη συμπεριφορά των δεδομένων με το χρόνο για βαθύτερο πλαίσιο.  

Για παράδειγμα, η digna μπορεί αυτόματα να επισημάνει ότι *«ο αριθμός γραμμών αυξήθηκε κατά 15.8% από την αρχή του έτους.»*  
Χωρίς SQL queries, χωρίς χειροκίνητους ελέγχους — απλώς **ενεργές πληροφορίες με μια ματιά**.  

Αυτή είναι η βάση του ταξιδιού της digna προς προχωρημένη ανάλυση δεδομένων, επιτρέποντας στις ομάδες δεδομένων να μεταβούν από αντιδραστική σε προδραστική παρακολούθηση.

### Dashboard Improvements – A Smoother User Experience
Πέρα από τα κύρια χαρακτηριστικά, η Έκδοση 2025.04 περιλαμβάνει αρκετές **βελτιώσεις στο dashboard** σχεδιασμένες για να κάνουν τη digna πιο διαισθητική και ευχάριστη στη χρήση:  
- Γρηγορότερη πλοήγηση μεταξύ projects και inspections.  
- Καθαρότερη διάταξη για τα inspection logs και τις υποβολές εργασιών.  
- Διακριτικές σχεδιαστικές προσαρμογές που σας βοηθούν να βρίσκετε πληροφορίες πιο γρήγορα.  

Αυτές οι βελτιώσεις βασίζονται άμεσα σε feedback πελατών και δείχνουν τη συνεχή δέσμευσή μας να κάνουμε τη digna **μια πλατφόρμα φτιαγμένη για καθημερινή χρήση**.

## General Improvements
- Βελτιστοποιήσεις απόδοσης για εργασίες επιθεώρησης σε μεγάλα σύνολα δεδομένων.  
- Ενισχυμένη διαχείριση σφαλμάτων στο dignacli για πιο σαφές feedback.  
- Βελτιώσεις σταθερότητας για projects με πολλές ταυτόχρονες εργασίες.  
- UI βελτιώσεις για φιλτράρισμα logs εργασιών και διαχείριση έργων.

## Summary
Η Έκδοση 2025.04 αφορά τον **έλεγχο, την προσβασιμότητα και την κατανόηση**.  

- Το νέο **Inspection Hub** δίνει στους χρήστες πλήρη ορατότητα στις εργασίες επιθεώρησης.  
- Η **πολυγλωσσική υποστήριξη** εξασφαλίζει ότι η digna μπορεί να χρησιμοποιηθεί από παγκόσμιες ομάδες.  
- Η **λειτουργία εισαγωγής/εξαγωγής** απλοποιεί τη διαχείριση ρυθμίσεων μεταξύ περιβαλλόντων.  
- Το **Module Analytics (v1)** μετατοπίζει το επίκεντρο από την ανίχνευση στην κατανόηση, με παρακολούθηση τάσεων και μεταβλητότητας.  
- Οι **βελτιώσεις στο dashboard** τελειοποιούν τη συνολική εμπειρία χρήστη.  

Μαζί, αυτές οι ενημερώσεις κάνουν τη digna πιο ισχυρή, φιλική προς τον χρήστη και έτοιμη για διεθνή χρήση περισσότερο από ποτέ.

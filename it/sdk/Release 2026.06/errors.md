# Errori SDK Python digna 2026.06

Questa pagina documenta la gerarchia delle eccezioni esposta dall'SDK Python ***digna***. Questi errori coprono i fallimenti dell'API, i problemi di autenticazione e autorizzazione e i casi di risorsa non trovata.

Tutti gli errori sollevati dall'SDK derivano da `DignaError`.

### Steps

1. **Open uw project**  
   Klik in de linker navigatie op **Projects** en selecteer het gewenste project.

2. **Voeg een Datasource toe**  
   Ga naar **Datasources** en klik op **Add Datasource**.

3. **Kies het type Datasource**  
   Selecteer het databasetype: Table of View.

4. **Zoek uw Datasource in de lijst**  
   Selecteer uw Datasource in de lijst.

5. **Definieer de Snapshot Query**  
   Definieer de Snapshot Query. De Snapshot Query bepaalt hoe *digna* één dag van uw gegevens zal benaderen.

6. **Preview**  
   Klik op Preview om te controleren of de Snapshot Query correct is gedefinieerd.

7. **Maak de Datasource aan**  
   Als alles correct is geconfigureerd, kunt u uw configuratie opslaan.

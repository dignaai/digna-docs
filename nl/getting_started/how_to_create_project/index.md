### Stappen

1. **Open the Project Section**
   - Vanuit de navigatie aan de linkerkant, klik op **Projects**.

2. **Create a New Project**
   - Klik op de knop **New Project**.

3. **Enter Project Details**
   - Voer een **Project Name** in.  
   - (Optioneel) Voeg een **Description** toe voor context.

4. **Save the Project**
   - Klik op **Create** om te voltooien.  
   - Het project verschijnt nu in je **Projects list**.

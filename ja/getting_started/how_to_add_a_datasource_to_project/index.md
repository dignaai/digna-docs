### 手順

1. **Open Your Project**  
   左側のナビゲーションから **Projects** をクリックし、対象のプロジェクトを選択します。

2. **Add a Datasource**  
   **Datasources** に移動し、**Add Datasource** をクリックします。

3. **Choose Datasource Type**  
   データソースの Type を選択します：Table または View。

4. **Find your Datasource on the list**  
   リストから対象の Datasource を選択します。

5. **Define Snapshot Query**  
   Snapshot Query を定義します。Snapshot Query は *digna* が1日分のデータにアクセスする方法を定義します。

6. **Preview**  
   プレビューをクリックして、Snapshot Query が正しく定義されているか確認します。

7. **Create datasource**  
   設定が正しければ、構成を保存できます。
